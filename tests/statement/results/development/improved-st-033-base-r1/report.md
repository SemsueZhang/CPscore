## f1 · [Fatal −10] 两次二值询问无法保证定位八个隐藏值

**原文位置：** [material.md 第 3 行](/tmp/cp-statement-n65n205t/material.md:3)。

> 交互器固定隐藏整数 $h\in[1,8]$。

> 每次只能这样询问，最多询问两次。

> 必须对每个隐藏值都正确，不能随机失败。

**核验依据：** 正常询问只有 $0$、$1$ 两种回复。任何自适应策略都可表示为深度至多为 $2$ 的二叉决策树，因此最多有 $2^2=4$ 个叶子。每个叶子对应一个最终答案；要保证八个不同的隐藏值全部被正确识别，至少需要八个叶子，矛盾。

允许提前结束不会增加叶子数，随机化也不能满足“对每个隐藏值都正确”的保证。`-1` 表示违规，文件结束要求立即结束，均不能作为合法的额外信息渠道。

**实际影响：** 规则虽可理解，但不存在满足全部要求的通用交互策略，属于任务可行性上的实质矛盾。按同一根因扣分一次。

| 方案 | 精确原文 | 建议替换 |
| --- | --- | --- |
| A：保留八个隐藏值 | `每次只能这样询问，最多询问两次。` | `每次只能这样询问，最多询问三次。` |
| A：同步标题 | `# 两问定位` | `# 三问定位` |
| B：保留两次询问 | `交互器固定隐藏整数 $h\in[1,8]$。` | `交互器固定隐藏整数 $h\in[1,4]$。` |
| B：同步数据范围 | `隐藏整数为 $1$ 至 $8$，整次交互不变。` | `隐藏整数为 $1$ 至 $4$，整次交互不变。` |

**修订复核：**

- 方案 A：依次将候选区间按 $8\to4\to2\to1$ 二分，三问足够；所需询问均在现有合法范围内。
- 方案 B：先询问 $x=2$，再按回复询问 $x=1$ 或 $x=3$，两问即可定位。原有询问范围 $1\le x\le8$ 可以保留，不妨碍正确性。
