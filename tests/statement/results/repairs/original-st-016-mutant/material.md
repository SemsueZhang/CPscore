# 奇偶回执

隐藏二进制串为 $b_1b_2\cdots b_n$，长度为 $n$，下标从 $1$ 开始，交互开始前固定。一次询问输出 `? k i1 ... ik` 并刷新，其中下标两两不同，均在 $[1,n]$ 内，$1\le k\le n$。交互器回复所选位的异或值，即 $b_{i_1}\mathbin{\operatorname{xor}}\cdots\mathbin{\operatorname{xor}}b_{i_k}$。至多询问 $n$ 次。最后输出 `! b`，刷新并立即退出，没有最终回复。收到 `-1` 或文件结束时立即退出。

## 输入格式

初始输入整数 $n$。每次询问后读取一行，正常回复为 $0$ 或 $1$，异常回复为 $-1$。

## 输出格式

按协议输出询问及隐藏串。询问合法且次数不超限、最终串完全正确时接受。

## 数据范围

$1\le n\le2000$。隐藏串仅含字符 `0`、`1`。

## 说明

可分别询问每一个下标，本题不要求输出唯一的询问序列。
