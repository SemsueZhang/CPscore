# 逆序拼图

给定整数 $n,k$，构造一个 $1$ 至 $n$ 的排列，恰好有 $k$ 个逆序对。逆序对是满足 $i<j$ 且 $a_i>a_j$ 的下标对。若不存在则输出 `NO`。存在时允许输出任意合法排列。

## 输入格式

输入一行，两个整数 $n,k$。

## 输出格式

若不存在符合要求的排列，输出一行 `NO`。否则第一行输出 `YES`，第二行输出 $n$ 个整数，表示所构造的排列。判定器接受任意符合逆序对数量的排列。

## 数据范围

$1\le n\le2\times10^5$，$0\le k\le n^2$。

## 样例输入

```text
3 1
```

## 样例输出

```text
YES
1 3 2
```
