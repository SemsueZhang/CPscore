# 三城通行

有 $n$ 个城市和 $m$ 条道路。每条道路连接输入给出的两个端点，通行代价为正整数。保证任意两个城市都可以互相到达。每条道路均为单向道路，输入中的 $u,v,w$ 表示只能从城市 $u$ 前往城市 $v$，通行代价为 $w$。求从城市 $s$ 到城市 $t$ 的最短通行代价。

## 输入格式

第一行输入四个整数 $n,m,s,t$。随后 $m$ 行，每行输入三个整数 $u,v,w$。

## 输出格式

输出一行，一个整数，表示最短通行代价。

## 数据范围

$3\le n\le10^5$，$n\le m\le2\times10^5$，$1\le u,v,s,t\le n$，$1\le w\le10^6$，$s\ne t$。

## 样例输入

```text
3 3 1 2
1 2 1
2 3 1
3 1 1
```

## 样例输出

```text
1
```
