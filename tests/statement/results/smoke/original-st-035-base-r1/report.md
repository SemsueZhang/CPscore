**[Fatal −10] 同时发生的收入与支出缺少余额判定顺序**

原文位置：[material.md 第 3 行](/tmp/cp-statement-_o2xnhpc/material.md:3)。

> 每天收到一笔收入并尝试支付一笔支出，两个事件发生在同一时刻。

题面没有确定：检查支出能否支付时，当天收入是否已经计入余额。这直接影响失败次数和最终余额。

例如，合法输入：

```text
1 0
1 1
```

两种合理的结算规则产生不同结果：

| 结算规则 | 过程 | 输出 |
| --- | --- | --- |
| 先计入收入，再检查支付 | 余额变为 1，支付成功 | `0 0` |
| 按当天收入到账前的余额检查支付，再计入收入 | 支付失败，收入到账后余额为 1 | `1 1` |

正式样例中，初始余额已经足够支付，因此两种规则都输出 `0 4`，不能消除歧义。
