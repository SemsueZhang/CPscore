# 浮标中心

平面上有 $n$ 个浮标，第 $i$ 个位置为 $(x_i,y_i)$，权重为 $w_i$。求加权中心 $(X,Y)$，其中 $X=\sum_iw_ix_i/\sum_iw_i$，$Y=\sum_iw_iy_i/\sum_iw_i$。保证总权重为正。

## 输入格式

第一行输入整数 $n$。随后 $n$ 行，每行输入三个整数 $x_i,y_i,w_i$。

## 输出格式

输出一行，两个有限实数 $\widehat X,\widehat Y$。每个坐标分别满足 $|\widehat z-z|\le10^{-6}\max\{1,|z|\}$ 时接受，其中 $z$ 为对应的精确坐标。

## 数据范围

$1\le n\le2\times10^5$，$-10^6\le x_i,y_i\le10^6$，$0\le w_i\le10^6$，$\sum_iw_i>0$。

## 样例输入

```text
2
0 0 1
4 2 3
```

## 样例输出

```text
3.000000 1.500000
```
