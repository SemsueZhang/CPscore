# 轮转窗口

有 $n$ 份任务，任务 $i$ 在整数时刻 $a_i$ 到达，需要 $p_i$ 个时间片。系统只有一个先进先出队列和一个处理器，每片长 $1$。在时刻 $t$，先把该时刻到达的任务按编号递增加入队尾，再把上一时间片尚未完成的任务加入队尾，最后取队首执行到 $t+1$。若执行后剩余需求为零，则记录完成时刻，不再入队。空队列时处理器空闲。初始时刻为 $0$。

## 输入格式

第一行输入整数 $n$。随后 $n$ 行，每行输入两个整数 $a_i,p_i$。

## 输出格式

输出一行，$n$ 个整数，依次表示每份任务的完成时刻。

## 数据范围

$1\le n\le2000$，$0\le a_i\le10^6$，$1\le p_i\le100$。

## 样例输入

```text
2
0 2
1 1
```

## 样例输出

```text
3 2
```
