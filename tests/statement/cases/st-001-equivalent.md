# 山谷预约

山谷有 $n$ 个营地，第 $i$ 个营地最多容纳 $c_i$ 人。按输入顺序处理 $m$ 份预约。预约 $(l,r,d)$ 要求编号在闭区间 $[l,r]$ 的每个营地各空出 $d$ 个名额。若任一营地的剩余名额不足，则这份预约失败，立即停止处理后续预约；否则扣除相应名额。求第一份失败预约的输入编号，若全部成功则输出 $0$。


## 输入格式

第一行输入两个整数 $n,m$。第二行输入 $n$ 个整数 $c_i$。随后 $m$ 行，每行输入三个整数 $l,r,d$。


## 输出格式

输出一行，一个整数，表示第一份失败预约的输入编号，或 $0$。

## 数据范围

$1\le n,m\le 2\times10^5$，$0\le c_i\le10^9$，$1\le l\le r\le n$，$1\le d\le10^9$。

## 样例输入

```text
3 3
3 2 4
1 2 1
2 3 2
1 3 1
```

## 样例输出

```text
2
```
