# 次序摘要

公开整数 $n$。发送方只知道一个 $1$ 至 $n$ 的排列 $p$，接收方只知道两个不同整数 $u,v$。发送方必须一次发送恰好 $n-1$ 位二进制消息，接收方判断 $u$ 在排列中是否出现在 $v$ 之前。双方预先约定确定性算法，不共享随机数、文件或运行状态，不能反向通信。消息必须在发送方不知道 $u,v$ 的情况下确定。

## 输入格式

提交函数 `encode(p)` 和 `decode(n,message,u,v)`，分别在独立进程运行，仅能读取列出的实参。$n$ 为公开参数，排列内容只对发送方可见。

## 输出格式

编码函数返回恰好 $n-1$ 位的二进制串，解码函数返回布尔值，表示 $u$ 是否位于 $v$ 之前。对每个合法排列和有序数对均须正确。无需读写标准流。

## 数据范围

$3\le n\le8$，$1\le u,v\le n$，$u\ne v$。排列包含 $1$ 至 $n$ 各一次。
