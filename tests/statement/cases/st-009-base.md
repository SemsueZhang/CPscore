# 枝条配额

给定 $n$ 个顶点及每个顶点要求的度数 $d_i$。构造一棵简单无向树，使所有顶点度数恰为给定值。无解时输出 `NO`，有解时可输出任意一棵。

## 输入格式

第一行输入整数 $n$。第二行输入 $n$ 个整数 $d_i$。

## 输出格式

无解输出一行 `NO`。有解时第一行输出 `YES`，随后 $n-1$ 行，每行两个整数表示一条边。判定器检查树及全部度数，不限制边的输出顺序。

## 数据范围

$2\le n\le2\times10^5$，$0\le d_i<n$。

## 样例输入

```text
3
1 2 1
```

## 样例输出

```text
YES
1 2
2 3
```
