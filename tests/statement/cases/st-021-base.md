# 同步机器人

有 $n$ 个机器人位于整数数轴的不同位置。每轮先根据该轮开始时的状态，让全部活动机器人同时向自己的方向移动一个单位。随后所有落在同一位置的机器人同时失效并移除，不再移动。两个机器人若在移动过程中交叉但最终位置不同，不视为碰撞。进行 $T$ 轮后，按初始编号输出仍活动机器人的位置。

## 输入格式

第一行输入两个整数 $n,T$。随后 $n$ 行，每行输入一个整数 $x_i$ 和一个字符 `L` 或 `R`。

## 输出格式

第一行输出活动机器人数量 $k$。随后按初始编号递增输出 $k$ 行，每行两个整数，表示编号与最终位置。$k=0$ 时只有第一行。

## 数据范围

$1\le n\le200$，$0\le T\le1000$，$-10^6\le x_i\le10^6$。初始位置两两不同。

## 样例输入

```text
3 1
0 R
2 L
5 L
```

## 样例输出

```text
1
3 4
```
