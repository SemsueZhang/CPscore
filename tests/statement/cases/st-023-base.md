# 回廊传送

给定 $n\times m$ 网格，字符 `#` 为障碍，`.` 为普通可通行格，`S`、`T` 分别为唯一的起点和终点，小写字母为传送点。每次可走到上下左右相邻可通行格，代价为 $1$；也可从某字母格传送到任意同字母格，代价为 $0$。传送不限次数。不允许走出网格。求从 `S` 到 `T` 的最小代价，不可达输出 $-1$。

## 输入格式

第一行输入两个整数 $n,m$。随后 $n$ 行，每行一个长度为 $m$ 的字符串。

## 输出格式

输出一行，一个整数，表示最小代价或 $-1$。

## 数据范围

$1\le n,m\le1000$，$nm\ge2$。合法字符如题意，恰有一个 `S` 和一个 `T`。

## 样例输入

```text
2 4
Sa#T
#a.a
```

## 样例输出

```text
2
```
