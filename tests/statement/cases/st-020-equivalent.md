# 仓库日终

仓库初始库存为 $S$。共进行 $d$ 天，第 $i$ 天先接收入库 $a_i$ 件，再尝试发出 $b_i$ 件。如果库存不少于 $b_i$ 则扣除，否则该次发货失败且不扣库存。之后清点：若库存超过容量 $C$，超出的物品立即丢弃。丢弃仅在每日发货尝试后发生，不影响当天是否发货成功。求失败天数和最后库存。


## 输入格式

第一行输入三个整数 $d,S,C$。随后 $d$ 行，每行输入两个整数 $a_i,b_i$。


## 输出格式

输出一行，两个整数，依次为失败天数和最后库存。

## 数据范围

$1\le d\le2\times10^5$，$0\le S\le C\le10^9$，$0\le a_i,b_i\le10^9$。

## 样例输入

```text
2 1 3
5 4
0 3
```

## 样例输出

```text
1 2
```
