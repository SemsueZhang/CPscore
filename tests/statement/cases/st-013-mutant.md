# 终止试验

有编号为 $1$ 至 $n$ 的状态。从状态 $1$ 开始，每次试验消耗 $1$ 单位时间。在状态 $i$，以 $p_i/q_i$ 的概率转移到状态 $b_i$，否则立即终止。若 $i=n$，本次试验后一定终止，此时输入的 $p_n=0$、$b_n=n$。对 $i<n$ 保证 $b_i>i$，各次随机选则独立。求终止前消耗时间的期望。

## 输入格式

第一行输入整数 $n$。随后 $n$ 行，每行输入三个整数 $p_i,q_i,b_i$。

## 输出格式

输出一行，一个有限实数 $y$。设期望为 $E$，当 $|y-E|\le10^{-6}\max(1,|E|)$ 时接受。

## 数据范围

$1\le n\le2\times10^5$，$0\le p_i\le q_i\le10^6$，$q_i\ge1$，$1\le b_i\le n$。其余保证如题目描述。

## 样例输入

```text
2
1 2 2
0 1 2
```

## 样例输出

```text
1.500000
```

## 说明

第一次试验一定进行，以 $1/2$ 的概率还需在状态 $2$ 进行一次试验。
