# 边数探针

交互器在开始前固定一张有 $n$ 个顶点的简单无向图，图的边对程序不可见。顶点编号为 $1$ 至 $n$。你可以输出 `? u v` 并刷新，其中 $u\ne v$，询问两点间是否有边。交互器回复 $1$ 表示有边，$0$ 表示无边。一次交互至多询问 $n(n-1)/2-1$ 次，重复询问也计入次数。最后输出 `! m`，其中 $m$ 是隐藏图的总边数，刷新并立即结束，无最终回复。

程序必须使用确定性策略，对每一张合法隐藏图都正确。收到 `-1` 或文件结束时立即结束，`-1` 仅表示协议违规。

## 输入格式

初始输入一行整数 $n$。每次询问后读取一行整数，正常为 $0$ 或 $1$，异常为 $-1$。输入中不提供边集。

## 输出格式

按上述协议输出询问与最终边数。所有询问合法且不超限，最终边数正确时通过。

## 数据范围

$3\le n\le100$，$1\le u,v\le n$，$u\ne v$。隐藏图无自环、重边，可以为空图或完全图，并在整次交互中保持不变。

## 说明

这是交互题，不提供静态输入输出样例。若 $n=3$ 且只有边 $(1,2)$，询问 `? 1 3` 会得到回复 `0`。
