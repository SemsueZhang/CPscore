# 共同接驳点

数轴上有 $n$ 名旅客，第 $i$ 名初始位置为 $a_i$，速度为 $v_i$。选择任意实数位置 $x$，所有旅客同时出发，可沿数轴向任一方向行走，到达后可等待。求所有旅客都能到达 $x$ 的最短时间，即 $\min_x\max_i|x-a_i|/v_i$。

## 输入格式

第一行输入整数 $n$。随后 $n$ 行，每行输入两个整数 $a_i,v_i$。

## 输出格式

输出一行，一个有限实数 $y$，表示最短时间。设精确答案为 $T$，当 $|y-T|\le10^{-7}\max(1,|T|)$ 时接受。

## 数据范围

$1\le n\le2\times10^5$，$-10^9\le a_i\le10^9$，$1\le v_i\le10^6$。

## 样例输入

```text
2
0 1
10 3
```

## 样例输出

```text
2.500000000
```
