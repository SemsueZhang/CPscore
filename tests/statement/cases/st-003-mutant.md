# 星图异或

给定一棵带非负整数边权的无根树。任意两点间的距离定义为它们之间唯一简单路径上所有边权的算术和（同时仍定义为这些边权的按位异或值），点到自身的距离为 $0$。求所有无序点对（允许两点相同）中最大的距离。

## 输入格式

第一行输入整数 $n$。随后 $n-1$ 行，每行输入三个整数 $u,v,w$，表示一条无向边。

## 输出格式

输出一行，一个整数，表示最大异或距离。

## 数据范围

$1\le n\le2\times10^5$，$1\le u,v\le n$，$0\le w<2^{30}$。保证输入构成树。

## 样例输入

```text
3
1 2 3
2 3 5
```

## 样例输出

```text
6
```
