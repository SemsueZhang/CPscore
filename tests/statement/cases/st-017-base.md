# 单向索引信

这是双程序通信任务。发送方只知道长度为 $n$ 的二进制串 $s$，接收方只知道 $n$ 和下标 $j$。发送方一次发送恰好 $n$ 位二进制消息，接收方必须返回 $s_j$。双方可事先约定确定性算法，不共享随机数、文件、内存或运行状态，不能反向通信。消息内容可自行编码，不要求等于原串。

## 输入格式

提交两个函数：`encode(s)` 返回消息串，`decode(n,message,j)` 返回一个字符。评测器给发送方的实参只有 $s$，给接收方的实参只有所列三项；每次调用使用独立进程。

## 输出格式

`encode` 必须返回恰好 $n$ 位二进制串；`decode` 返回字符 `0` 或 `1`。对每一组合法 $s,j$ 都必须正确，否则不通过。无需读写标准流。

## 数据范围

$1\le n\le2\times10^5$，$1\le j\le n$。消息只允许字符 `0`、`1`。

## 说明

例如 $s=$ `101`、$j=2$ 时，若发送方发送 `101`，接收方应返回 `0`。这只是合法协议的一次执行，不限定其他编码。
