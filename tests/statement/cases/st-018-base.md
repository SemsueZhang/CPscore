# 模数便笺

公开正整数 $k$。发送方只知道 $x$，接收方只知道 $y$，其中 $x,y\in[0,2^k)$。发送方发送恰好 $k$ 位二进制消息，接收方返回 $(x+y)\bmod2^k$。双方预先约定确定性算法，仅通信一次，不共享运行状态或随机源，不能反向通信。

## 输入格式

提交函数 `encode(k,x)` 和 `decode(k,message,y)`。两函数分别在独立进程运行，仅可访问实参。$k$ 为公开参数。

## 输出格式

编码函数返回长度恰为 $k$ 的二进制串，解码函数返回一个整数，须等于 $(x+y)\bmod2^k$。所有合法输入均须正确。无需读写标准流。

## 数据范围

$1\le k\le30$，$0\le x,y<2^k$。

## 说明

一种可行编码为 $x$ 的定长二进制表示。$k=3,x=6,y=5$ 时发送 `110`，返回 $3$。
