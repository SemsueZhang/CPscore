# 寻址问答

交互器预先固定隐藏整数 $h\in[1,N]$。程序首先读入整数 $N$。可以输出 `? x` 并刷新输出，其中 $x$ 是 $[1,N]$ 内整数。回复 `-1` 表示 $h<x$，`0` 表示 $h=x$，`1` 表示 $h>x$。最多询问 $\lceil\log_2N\rceil+1$ 次。确定后输出 `! h`，刷新并立即结束，无最终回复。读到 `-2` 或文件结束时立即结束；`-2` 表示协议违规。隐藏值在一次交互中不变。

## 输入格式

初始输入一行整数 $N$。其后每次询问读取一行比较结果。

## 输出格式

按上述协议输出询问与最终答案。所有询问合法、次数不超限且最终答案正确时通过。

## 数据范围

$1\le N\le10^9$。隐藏整数满足 $1\le h\le N$。

## 说明

本题为交互题，没有静态输入输出样例。对于 $N=4,h=3$，询问 `? 2` 得 `1`，询问 `? 3` 得 `0`，最后输出 `! 3` 是一段合法交互。
