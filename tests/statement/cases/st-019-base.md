# 连通摘要

公开顶点数 $n$。发送方拥有一张简单无向图，接收方只拥有两个顶点 $u,v$。发送方发送恰好 $nL$ 位二进制消息，其中 $L=\lceil\log_2(n+1)\rceil$。接收方判断图中 $u,v$ 是否连通。双方只能使用事先约定的确定性算法，没有共享状态或随机源，不能反向通信。点到自身视为连通。

## 输入格式

提交 `encode(n,edges)` 和 `decode(n,message,u,v)` 两个函数。分别运行于独立进程，接收方没有边集。顶点编号为 $1$ 至 $n$。

## 输出格式

编码函数返回恰好 $nL$ 位二进制串，解码函数返回布尔值。对每一张合法图及顶点对均须正确，不要求固定编码。无需读写标准流。

## 数据范围

$1\le n\le200$，$0\le m\le n(n-1)/2$，$1\le u,v\le n$。图无自环、重边。

## 说明

可将每个顶点所在连通块的最小编号分别用 $L$ 位编码，接收方比较对应编号。
