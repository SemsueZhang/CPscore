# 铭文嵌入

给定两个非空小写字母串 $s,t$。选择严格递增的下标 $i_1<\cdots<i_{|t|}$，使 $s_{i_j}=t_j$。不同下标序列视为不同方案，即使选出的字符串相同。求方案数对 $10^9+7$ 取模的结果。

## 输入格式

第一行输入字符串 $s$。第二行输入字符串 $t$。

## 输出格式

输出一行，一个整数，表示方案数对 $10^9+7$ 取模的结果。

## 数据范围

$1\le |s|\le2\times10^5$，$1\le |t|\le50$。字符均为小写英文字母。

## 样例输入

```text
ababa
aba
```

## 样例输出

```text
4
```
