# 信号链

给定有 $n$ 个顶点、$m$ 条边的有向无环图，顶点编号为 $1$ 至 $n$，每条边有正整数权值。求从 $1$ 到 $n$ 的最长路径长度，以及具有该长度的路径条数对 $998244353$ 取模的结果。路径按经过的边序列区分。不存在路径时输出 `-1 0`。允许长度为零的路径，因此 $n=1$ 时答案为 `0 1`。

## 输入格式

第一行输入两个整数 $n,m$。随后 $m$ 行，每行输入三个整数 $u,v,w$，表示边 $u\to v$ 及其权值。

## 输出格式

输出一行，两个整数，依次为最长长度与最长路径条数对 $998244353$ 取模的结果。无路径时按题目约定输出。

## 数据范围

$1\le n\le2\times10^5$，$0\le m\le4\times10^5$，$1\le u,v\le n$，$1\le w\le10^6$。保证图无环、无重边。

## 样例输入

```text
4 4
1 2 3
1 3 2
2 4 4
3 4 5
```

## 样例输出

```text
7 2
```

## 说明

两条最长路径分别为 $1\to2\to4$ 和 $1\to3\to4$，长度均为 $7$。
