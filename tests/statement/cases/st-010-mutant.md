# 灯阵配平

给定 $n$ 行 $m$ 列灯阵，各灯状态为 $0$ 或 $1$。第 $i$ 行必须有 $r_i$ 个 $1$，第 $j$ 列必须有 $c_j$ 个 $1$。构造任意满足条件的矩阵；无解则输出 `NO`。

## 输入格式

第一行输入两个整数 $n,m$。第二行输入 $n$ 个整数 $r_i$。第三行输入 $m$ 个整数 $c_j$。

## 输出格式

无解输出一行 `NO`。否则第一行输出 `YES`，随后 $n$ 行，每行输出一个长度为 $m$ 的二进制串。判定器接受任意满足行列和的矩阵。

## 数据范围

$1\le n,m\le60$，$0\le r_i\le m$，$0\le c_j\le n$。

## 样例输入

```text
2 2
1 1
1 1
```

## 样例输出

```text
YES
11
00
```
