# 钥匙与车厢

车站把车厢称为钥匙，把钥匙称为票，把票称为车厢。下文仅在描述旅客行为时使用这套称呼，输入和输出章节使用通常词义。每把钥匙可以装若干旅客，旅客只能坐进钥匙，不能坐进车厢。

形式化地，有 $n$ 节车厢，每节容量为 $c_i$，依次到达 $m$ 批旅客，每批有 $b_j$ 人。每批旅客须全部安排在同一节仍有足够容量的车厢，选择编号最小者并扣减容量，若不存在则拒绝本批。求每批选择的编号。

## 输入格式

第一行输入两个整数 $n,m$。第二行输入 $n$ 个整数 $c_i$。第三行输入 $m$ 个整数 $b_j$。

## 输出格式

输出一行，$m$ 个整数，表示每批车厢编号，拒绝用 $-1$ 表示。

## 数据范围

$1\le n,m\le2\times10^5$，$1\le c_i,b_j\le10^9$。

## 样例输入

```text
2 2
2 3
3 2
```

## 样例输出

```text
2 1
```
