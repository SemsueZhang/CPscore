# 待查重新题：代币系统

给出若干正整数代币面值，每种可用无限张。求用最少面值种数的另一个正整数系统，使所有非负金额的可表示性与原系统相同，新面值不要求来自原集合。T≤20，n≤100，面值≤25000。

解法：排序扫描，用完全背包维护已选面值能组成的金额。当前面值已可达则删去，否则选入并更新。被选面值不可由更小原面值组成。若等价系统不含这个面值，其表示中的更小正面值可展开为更小原面值，从而矛盾，所以所有被选面值必选，得到最小种数。时间O(nM+n log n)，空间O(M)。
