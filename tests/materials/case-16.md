# 货币系统受限摘编

来源模型：[洛谷 P5020 / NOIP 2018 货币系统](https://www.luogu.com.cn/problem/P5020)。本文件是人工编写的自足受限版本，不是官方题面全文。

给定 n 个两两不同的正整数面额 a_i，每种货币可以使用任意多张。金额 x 可表示，是指存在 t_i 属于非负整数，使 x=sum(a_i*t_i)。两种系统等价，是指它们对每一个非负整数金额的可表示性完全一致。新系统的面额可以是任意正整数，不要求预先来自原系统。求等价系统的最少面额种数。

输入第一行 T。每组先读 n，再读 n 个面额。满足 1<=T<=5，1<=n<=20，1<=a_i<=100，且同组面额两两不同。每组输出一行最少种数。

样例输入：
```text
1
3
4 6 9
```
样例输出：
```text
3
```

## 待审核题解

# 货币系统题解

设 M=max(a)。从小到大扫描所有面额，维护保留面额能表示的所有 0..M 金额。初始只有0可表示。如果当前面额可表示则跳过，否则保留它。保留面额 c 时按金额递增顺序更新 reachable[s] |= reachable[s-c]，这是标准完全背包。

每个删去的面额都能由保留面额组成，因此任何原系统金额都可用保留面额组成。反过来，保留面额来自原系统，因此两个系统等价。

还需说明种数最少。每个被保留的 c 都不能由原系统中比 c 小的面额组成，因为更小的已删面额也能由已保留面额组成。对任意等价正整数面额系统 B，c 能由 B 表示。如果 B 不含 c，这个表示使用的每个正面额 b 都严格小于 c。每个这样的 b 也能由原系统表示，其中所用的原面额不大于 b，因而严格小于 c。将这些表示代入便用小于 c 的原面额表示了 c，矛盾。所以任何等价系统必须包含每个保留面额。我们的系统恰好由这些面额组成，因此种数最小。

排序 O(n log n)，背包 O(nM)，数组空间 O(M)。逐组重新初始化背包。

补充例子：若目前仅保留面额4，表示金额8所需张数的计算为 8/4。此处计算结果为3，理由略。这个例子不参与上述最优性论证。
