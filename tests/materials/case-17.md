# 货币系统

给定两两不同的正整数面额，每种可使用任意多张。两个系统等价，当且仅当对每个非负整数金额可表示性相同。新系统可采用原系统以外的正整数面额，求最少种数。每组1≤n≤20，面额≤100，1≤T≤5。

## 待审核题解

从小到大扫描面额，维护所保留面额在0..M上的完全背包可达性，M为最大面额。初始仅0可达。当前面额可达则跳过，否则保留，并按金额递增更新可达性。输出保留种数。

被删面额可由保留面额组成，保留面额又来自原系统，所以新旧系统等价。因此保留种数最小。

排序O(n log n)，背包O(nM)，空间O(M)。逐组重新初始化。

补充计算：仅有面额4时，金额8需要8/4=3张。
