# 整套赛题评价协议

## 逐题档次

按考点价值、可发现性、证明与实现负担、解题反馈及题位作用判档，不取材料分项的最低档。

| 档次 | 判据 |
| --- | --- |
| 推荐 | 思考或题位作用有价值，发现、证明与实现协调，目标选手体验良好。入口题和压轴题均可。 |
| 合格 | 成立且适合使用，但思考收益、发现路径、实现负担或组合配合一般。 |
| 不合格 | 有不适用于本场的实质缺陷，如无法正确判定、误伤合理正确解、严重理解歧义或明显失衡的无效负担。须有具体依据。 |

材料分数与题目质量等级是证据，逐题档次还需结合本场题位、目标选手和赛制判断。质量等级的用途如下：

- A+、A、B+ 是正式比赛候选；逐题是否推荐仍取决于本场体验与组合效果。
- B、C 面向训练，按训练目标、梯度与题位价值判断使用效果。
- D、F 不推荐作为原创赛题；明确复用的训练赛可评价其训练价值。
- S 是高度原创且有研究价值、但严重不适合竞赛的研究问题，不因原创性高而推荐入场。

旧版新颖度 A/B/C/C+/D/F 不能按字母套入新等级，须按现行原创性与设计标准重评。普通文风、排版、注释、常规省略和模板知识不构成否决理由。抄用或实质重复须分析其对公平与独立考点的影响，通用算法相同不判差，未检索不宣称原创。

算法错误须有合法反例或有效反驳，证明缺漏分别判断。数据漏网须同时证错并核实原集额外收益，正常部分分不算漏洞。已核验的替代路线可用于重评设计，题解一条路线有缺口不直接否定题目，建议也不算修复证据。

## 整套判定

设全套N题，推荐R题、仅合格Q题、不合格U题，完整评价满足R+Q+U=N。合格占比为Q/N，不含推荐题，不按分值或考点加权，不删低档题或未审题改变分母。

按顺序判定：

1. U>0，或有具体路线与负担依据预测整体区分度不佳、整体做题体验极差，直接不合格。
2. 无否决情形且5Q>2N（合格占比大于40%），判合格。
3. 无否决情形且5Q≤2N，同时区分度好、做题体验优秀，判推荐，否则合格。

正好40%进入第3步，使用整数比较避免舍入。整体否决须关联具体选手层次、题目组合及比赛影响，不从局部缺点推出整体极差。重复考点、负担集中和题间依赖须追踪其对区分度与体验的影响，高推荐占比不能抵消这些问题。

## 证据与评价范围

区分设计评价、解法核验、程序数据审计与实测成绩。缺std、原数据或交互器不自动阻止设计评价或降低档次，未审计范围如实说明。

会改变逐题档次、占比或总评的缺口须补读、推导或检索，仍未解决时列明未知题并给条件性结论，不默认推荐或合格。未知题可能提供关键过渡路线时，不能先认定整套存在难度断层。已有充分的赛前材料依据触发否决时可确定不合格并保留未完成范围。没有现场成绩是赛前评价的正常条件，不是材料缺口，不等待比赛结束或额外组织盲测才能交付。
