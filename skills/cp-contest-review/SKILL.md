# 比赛总评

默认依据赛前材料评价题目组合。读取完整题面、参考解法、已有设计评审与比赛要求，先确认目标选手、赛制、时长和计分规则，必要假设明确写出。使用宿主已有工具，不依赖其他技能。

## 流程与 Reference

1. 按[赛前预测方法](references/prediction.md)确定结果信息边界，核对旧评审版本与结论依据。仅用户明确要求复盘时使用本场实际成绩；已经暴露结果的分析须按该 Reference 处理。
2. 理解可通过路线，重建各层选手的可行题组、共享电脑排程、剩余时间与后续机会，比较顺利、通常及受阻情形。优先补齐可能改变梯度的未知解法，依该 Reference 分析区分度、体验与整体质量。
3. 按[整套判定](references/assessment.md)给逐题档次、计算占比及检查整体否决条件。提出组合调整时重查受影响的过渡路线与排程，不把建议当作完成调整。

## 交付

默认在对话输出 Markdown，仅用户要求保存时写报告。先给赛前总评与决定性理由，再说明目标选手、比赛条件、材料范围及结果暴露情况。以逐题简表和分层摘要支持判断：可能完成的题组、后续候选、剩余时间与瓶颈、不同情形下的变化。

列明三档题数、占比和触发条件，最后给调整优先级。未知项保留为未知，不为凑齐占比强行定档。正文围绕决定结论的断层或有效过渡展开，不堆叠内部表格。预测标为预测，实测注明来源，不编造通过率或反馈，具体未完成项就地说明。
