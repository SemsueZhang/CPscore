# 阅读与修订

## 首次阅读路径分析（Reader-path Analysis）

按文本出现顺序模拟目标选手首次阅读。记录“读到哪里、当时已知什么、还缺什么、必须回到哪里”，不要用看过的解法替读者补桥。普通的总述后细化和紧邻定义不自动构成障碍。

| 阅读位置 | 实际判断方法 |
| --- | --- |
| 对象、符号与指代 | 首次使用时能否确定含义及指向。代词列出可能对象，术语变化核对是否同一对象，长句检查否定、条件与量词的作用范围。 |
| 规则与例外 | 沿操作走一遍，检查前提、顺序、同时更新、截断和结束是否容易找到。定位需跨段拼接的具体依赖，而非仅说“组织混乱”。 |
| 背景与模型 | 将人物、行为和目标对应到数学对象，指出牵强转换、无关叙事或规则脱节如何增加理解步骤。虚构、陌生、无背景或篇幅长本身不是缺陷。 |
| 样例解释 | 检查是否帮助理解题目特有的顺序、失败状态或上下限。指出读者卡住的具体规则，不要求每题逐步复算、配图或覆盖全部边界。 |
| 公式、图示与版本 | 检查上下标、图例、断行、样例分隔和复制是否可用，正文与图示、勘误及多语言版本是否一致。 |

能唯一确定模型仍可能有显著阅读负担，但须给原句与受阻步骤。模型本身复杂、求解所需洞察和表达额外制造的困难分别判断。关键字段只能结合全局保证作非平凡论证才能补出时，说明为何这是建模说明负担，而非选手应发现的算法性质。

真实反馈或赛时澄清先核对版本与原句。少数人读懂不能否定具体障碍，出现提问也不自动证明歧义。不得把模拟阅读写成实测读题时间、误读率或选手反馈，无需额外组织盲测。

## 表达与格式要求

以下为本协议的检查条款。明确格式违规至少按 Major 判级，严重影响核心题意或判定辨认的可为 Fatal，具体扣分见评分协议。

| 项目 | 要求 |
| --- | --- |
| 标点与文字 | 中文行文使用全角中文标点，句末有完整标点。检查错漏字、重复字、拼写和语法，例如图的性质应写“连通”。正确的单数 they 等正常语言用法不算错误。 |
| 数学排版 | 运算、参与运算的常数和变量用 LaTeX 表示。普通英文词、人名、算法名和题名不套数学模式。公式、上下标和样例分隔应正确显示并可辨认。 |
| 间距 | 中文与英文、数字或公式之间留半角空格，中文标点与这些内容之间不额外加空格。 |
| 输入与输出 | 同类句式保持统一，不忽而写“输入／输出”忽而省略。并列输入变量放在同一数学环境中，固定输出字符串用行内代码。输入序号使用中文属于建议。 |
| 范围展示 | 类型放在输入说明，范围通常集中在说明或提示中。有效位较少且不小于 $10^5$ 的数使用科学计数法。不同范围分成公式并用全角逗号隔开，相同范围可合并。没有部分分时，某变量的范围也可写在输入格式中。 |
| 子任务展示 | 捆绑测试应加粗写明“本题采用捆绑测试”。百分比或依赖难以表达清楚时可改用表格，Subtask 使用无序列表属于建议，不强制一种样式。 |
| 背景与组织 | 背景中的对象、行为和目标应能对应任务，避免无关内容增加规则理解负担。需要时补形式化说明，不能用样例解释代替正文规则。 |
| 译文 | 术语前后一致，每种语言均完整可读。不影响题意的人名或自创词可保留原文并作说明，专有名词可附原文。远程评测题标题通常保留原文，被知名书籍引用且翻译的情况可例外。使用 AI 辅助翻译时应声明，并经人工校对。 |

按材料语言和发布形式核对要求，纯排版偏好不当作规范违规。译文完整性及翻译过程的核验依赖相应材料，仅有单一版本不能宣称已完成对照，也不能从文风推定使用 AI 或未经校对。

## 最小修改与复核（Minimal Repair & Recheck）

对已确认的语义、表达或规范问题，给出可直接替换的句子、公式或局部移位方案，保留原本明确的任务。按根因补定义、消歧指代、集中规则、调整先后或修正样例，避免因局部问题重写整篇。

出题意图不确定时分别写“若允许 A，则改为……；若仅允许 B，则改为……”，指出需作者决定的规则，不擅自缩小合法输入域或选定一种答案。

将候选修订放回原段落，重走原区分实例及相关边界，检查：原问题是否消失，是否引入新歧义或矛盾，合法输入域和原已明确的任务是否改变，与其他段落、样例及交叉材料是否冲突。纯表达修订应保持原输入—输出关系，修正规格缺口或实质错误时说明所选规则及影响。存在多语言版本时列出需同步的位置。

复核针对修改后的规则与文本，不把建议写成已应用，也不把修改后的评分当成原题面评分。纯可选润色无需包装成缺陷。
