# 易读性检查

先以首次接触题目的选手为视角，只凭题面建立任务模型，再用题解、程序或其他材料核对。不要把知道做法后能够解释原文当作易读性的依据，也不要把做题所需的洞察当成阅读障碍。分级与扣分按[评分协议](scoring.md)执行。

## 检查内容

| 方面 | 具体检查 |
| --- | --- |
| 语言与指代 | 主谓、单复数、代词和术语是否有明确对象。条件、否定、量词及“每个”“任意”“至少”“同时”等词的作用范围是否清楚。检查错别字、漏字、拼写及语法词法错误，区分真实错误与正确但陌生的用法。 |
| 背景自然性 | 叙事中的对象、行为和目标能否稳定对应数学模型，是否存在牵强的背景逻辑、与规则脱节的设定或无意义的术语转换。指出具体对应关系，避免把题材偏好或虚构设定当成缺陷。 |
| 信息组织 | 初始状态、合法操作、执行顺序、同时结算、截断、结束条件和例外是否便于按流程理解。关键规则是否散落、埋在无关叙事中或依赖反复跳读，符号是否先用后定义或反复变更。 |
| 首次阅读体验 | 能否仅依据题面准确复述输入代表什么、能做什么、要求输出什么。若需回读，定位需要来回拼接的句子与条件。不能借题解、标程、样例输出或游戏常识替作者补上基本规则。 |
| 样例的解释作用 | 样例和说明能否帮助理解题目特有规则，尤其是顺序、并发、上限下限、失败状态及反常直觉。存在常见读法冲突时检查是否得到有效澄清，避免只复算数字正确就结束审核。 |
| 材料可用性 | 公式、图示、下标、字体、断行、样例复制及术语是否实际妨碍读取和使用。提供多种语言、多个版本或勘误时，核对对应规则的一致性，不把排版偏好作为扣分理由。 |

## 定位阅读障碍

对实际发现的问题说明原句或位置、具体误读或阅读负担，以及最小的说明或组织修正。代词问题指出可能对应的对象，顺序问题列出需要区分的结算先后，背景问题解释牵强的映射，样例问题说明缺少哪个关键解释。审查者能够猜出正确意思不表示原文易读。

区分题意模型本身复杂、算法难以发现与表达造成的额外负担。只有具体的表达、背景或材料问题参与题面扣分，不以“不喜欢这个故事”“英文看不惯”“题太长”代替分析。

有真实读者反馈或赛时澄清时，核对反馈对应的版本和具体句子，用于定位阅读障碍。反馈不自动证明题面有歧义，也不能以少数人读懂否定已经定位的障碍。自行推测的阅读困难不能写成实测读题时间、误读率或选手反馈。不要求每次审核开展盲测或外部检索。

规格与易读性分别完成核验后再形成总分。报告可以围绕实际问题展开，无问题时简述关键核验，不机械输出空表。
