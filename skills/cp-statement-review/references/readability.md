# 易读性检查

以首次接触题目的选手为视角，只凭题面建立任务模型，再用其他材料核对。能用已知做法解释原文不代表易读，求解所需洞察也不算阅读障碍。分级见[评分协议](scoring.md)，明确格式要求另按[洛谷规范核对表](luogu-standard.md)检查。已确认的格式违规至少为 Major，严重的可为 Fatal，不能因“不影响阅读”略过或降为 Minor。

## 检查内容

| 方面 | 具体检查 |
| --- | --- |
| 语言与指代 | 主谓、单复数、代词和术语的对象，条件、否定、量词的作用范围，以及错漏字、拼写和语法词法错误。 |
| 背景自然性 | 对象、行为与目标能否稳定对应模型，有无牵强逻辑、规则脱节或无意义的术语转换。 |
| 信息组织 | 初始状态、操作、顺序、并发、截断、结束和例外是否便于梳理，有无规则散落、反复跳读或符号先用后定义。 |
| 首次阅读 | 能否复述输入含义、合法操作与输出目标。定位需回读拼接的条件，不借题解、样例答案或游戏常识补规则。 |
| 样例解释 | 能否澄清特殊规则、结算顺序、上下限、失败状态及常见误读，不能只复算答案。 |
| 材料可用性 | 公式、图示、下标、断行和样例复制是否可用，多语言、版本及勘误的规则是否一致。 |

## 定位阅读障碍

给出原句或位置、具体误读或负担及最小修正。代词指出候选对象，顺序列出结算先后，背景解释牵强映射，样例指出缺少的关键解释。区分模型本身复杂、算法难想到与表达额外增加的负担，不以题材、语言或篇幅偏好代替分析。

真实反馈或赛时澄清须核对版本与原句，既不自动证明歧义，也不能以少数人读懂否定已定位的问题。推测不写成实测读题时间、误读率或反馈，无需额外开展盲测或检索。
