# 阅读与修订

以具备先修知识、未知解法的选手为基准，记录已知、缺口及回读位置。等级见[评分](scoring.md)，排版见[格式](format.md)。

## 任务叙述与推导：每篇必查

检查规则、状态、数量关系和样例推导的定义、前提及论据。报告原句、读者已知和实质缺失或跳步造成的断点，核心依据须重新发现才能建立时适用 Fatal。

题面无公开解法、动机、证明义务；无推导时查定义、任务与操作，推导项不适用。模型复杂、难想到、常规省略、总述后细化或紧邻定义本身不算障碍。

| 方面 | 核查机制 |
| --- | --- |
| 对象与指代 | 首次使用的含义、代词候选，以及条件、否定和量词的作用范围。 |
| 规则与组织 | 核对操作生效时刻、状态更新和执行顺序，确定实际规则是否一致，关键字段须非平凡论证才能补出时说明建模缺口。 |
| 背景映射 | 人物、行为与目标如何对应模型，是否存在牵强转换或无关叙事。 |
| 样例与展示 | 解释能否澄清规则，公式、图例、样例分隔及复制是否可用，是否与正文、勘误一致。 |

## 冗余、文风与投稿内容

检查全文首尾、标题、背景、附注、图片文字和代码注释中的闲聊、求赞、求通过、自我介绍、广告及无关叙事；删除线、折叠和代码块均纳入范围。

文风按入口逐类对照[分类](ai-style-patterns.md)。循环说明、信息倒置在此裁定，记录读者已知、叙述依赖和来回转引、回读或重组信息的位置与影响。局部明确的模式即可确认，定级与去重见评分协议。

可疑冗余作删除／合并测试，保留规则、背景映射和理解帮助，确认删除后阅读更顺畅，再给可删范围与保留信息。

投稿内容按评分协议区分正常背景、历史、教育及抽象概率游戏，不按敏感词命中。来源资格凭直接证据另判。

## 局部修订

另查错漏字、语法、搭配、指代与衔接，给具体病句及缺词／混用／歧义，不以“阅读不顺”概括；影响否定、量词、边界、顺序、目标或接受关系时转[规格核验](specification.md)，同根因合并。

给保留全部规则的最小改法，意图不明只指缺口，不代选规则、缩范围或补证明。原稿与建议分开，仅要求修订才改，规则变化说明须同步的语言版本。局部修订后的复核核对受影响上下文。审核步骤未展开／建议未采纳本身不扣稿件分。
