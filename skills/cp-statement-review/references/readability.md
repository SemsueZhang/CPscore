# 阅读与修订

## 局部问题一次定级

对已确认的错漏字、标点、间距、数学模式等局部问题，按现有条款一次记录位置、依据、级别、根因和改法，合并同一根因的多处表现。修订只核对原句及受影响上下文，不为此额外检索、枚举或反复重判等级。

若问题可能改变否定、量词、边界、顺序、目标或接受条件，转入规格核验深入裁定。已完成的局部判断只有出现改变其影响或适用条款的新证据时才重开，最终汇总仅做去重、计分及完成状态检查。

## 内容

沿目标选手的阅读顺序记录“已知什么、还缺什么、须回到哪里”，不用已知解法替读者补规则。普通的总述后细化和紧邻定义不自动构成障碍。

| 方面 | 检查重点 | 扣分对应 |
| --- | --- | --- |
| 对象与指代 | 首次使用能否确定含义，代词有哪些候选对象，条件、否定和量词作用于哪里。 | 核心含义不确定 Fatal；显著回读 Major；局部障碍 Minor。 |
| 规则与组织 | 沿操作走一遍，定位散落、回溯或次序不明的具体依赖。 | 顺序或规则不确定 Fatal；显著拼接负担 Major；局部衔接问题 Minor。 |
| 背景映射 | 人物、行为和目标如何对应模型，有无牵强转换或无关叙事增加理解步骤。 | 与模型冲突致题意不确定 Fatal；显著负担 Major；局部负担 Minor。 |
| 样例与展示 | 解释是否澄清特殊规则，公式、图例、断行、样例分隔及复制是否可用，与正文、勘误是否一致。 | 样例实错或核心内容不可还原 Fatal；展示格式违规至少 Major；其余理解障碍按影响 Major / Minor。 |

区分模型复杂、算法难想到与表达增加的负担。关键字段须非平凡论证才能补出时，说明为何属于建模说明缺口。阅读问题给原句及受阻步骤，不只写“组织混乱”。

## 格式

| 项目 | 要求 | 扣分对应 |
| --- | --- | --- |
| 文字与标点 | 检查错漏字、重复字、拼写和语法。中文使用全角标点，句末标点完整。 | 普通字词、语法错误 Minor；标点格式违规至少 Major；改变核心语义按影响升级。 |
| 数学与记号 | 运算、相关常数和变量用 LaTeX，普通词、人名、算法名和题名不套数学模式。同一对象的名称、变量大小写一致，公式及上下标正确显示。 | 明确格式违规至少 Major；核心内容不可辨认 Fatal。 |
| 间距 | 中文与英文、数字或公式间留半角空格，中文标点旁不额外加空格。 | Major。 |
| 输入输出 | 同类句式统一，并列输入变量放在同一数学环境，固定输出字符串用行内代码。中文序号属于建议。 | 明确格式违规至少 Major；未用中文序号不扣。 |
| 范围展示 | 类型放在输入说明，范围通常集中在说明或提示。有效位较少且不小于 $10^5$ 的数用科学计数法，不同范围分公式并用全角逗号隔开，相同范围可合并。无部分分时，某变量的范围可放在输入格式中。 | 明确格式违规至少 Major；允许的合并或位置例外不扣。 |
| 子任务展示 | 加粗声明“本题采用捆绑测试”。表格和 Subtask 无序列表属于建议。 | 捆绑声明格式违规至少 Major；未用表格或无序列表不扣。 |

以上等级对应[评分协议](scoring.md)中的 Fatal −10、Major −2、Minor −1。格式损坏严重到影响核心规则时升级为 Fatal，纯偏好或未证实问题不扣分。

## 修订与复核

按根因给可直接替换的句子、公式或局部移位方案。意图未定时列条件性改法并交作者选择，不擅自缩小输入域或选定答案。

把修订放回上下文，重查区分实例、相关边界、样例及其他材料，确认问题消失且未引入冲突。纯表达修订保持原接受关系，修正规格时说明规则变化，列出需同步的语言版本。

修订与复核是审核方法，不另扣题面分，也不把修订后的得分当作原稿得分。
