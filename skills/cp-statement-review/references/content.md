# 规格核验

## 重建任务与选择边界

仅据原稿建立合法输入域 $D$ 与接受关系 $R(x,y)$，核验声明的前提、依据、有效性和用途，复述定义、量词、顺序、端点、操作、终止及保证。惯例可解释常规符号，不补题目特有规则、约束、证明或意图。

| 项目 | 核验要求 |
| --- | --- |
| 对象与操作 | 初始状态、操作前提、执行顺序、同时或顺次更新、终止与失败后行为明确，模型不依赖样例才能建立。 |
| 序列与字符串 | 子串／子序列的连续性、空对象是否参与统计、“本质不同”的含义，以及允许的最小长度、空区间、端点、重复和零值。 |
| 图与树 | 有向性、自环、重边、连通性与根的作用；有关时核对孤立点、单点、链和星形。 |
| 输入与范围 | 类型、每行数量与含义、必要上下界、字符集、实数小数位完整且一致。多测明确组数、组内结构及适用的总规模限制，原则上给出全部数据范围。 |
| 目标与输出 | 目标值／方案区分，无解约定或有解保证；多解、浮点、特殊判题的接受条件，以及交互询问、回复、次数、结束和异常协议。 |
| 取模与部分分 | 模数与对象一致，子任务条件、分值和依赖明确；可省已继承范围，区分累计覆盖与额外数据。重复展示要求交格式审核。 |
| 多语言 | 各版本独立完整，规则、术语一致，无重要缺译或无关内容。人名／自创词可说明后保留，专名可附原文；AI 辅助翻译须声明并核对原文，由 LLM 核验。题名展示交格式审核。 |
| 时空限制 | 原则上不低于参考程序最坏资源用量的 1.5 倍，不宜明显过紧或过宽。依据随附的资源说明或已有实测核对环境、计量口径、最坏情况及合理例外。普通样例的一次运行不足以证明裕量。 |

核对正文等式、数量关系、计数、取整、下标、作用域及中间数值；聚合量须明确集合与每项，熟悉 `sum` 不替代操作数定义，已明确符号无须复述。题面不承担解法／证明义务。

按对象／操作选择相关边界，定义已推出、输入域已排除或属于求解洞察的内容不要求额外声明。等级见[量规](rubric.md)，启用文风时另核验叙述带来的阅读负担，展示规范按任务范围加载[格式](format.md)。

## 附件获取与停止

集中获取附件，每批默认总限 30 秒，每个失败附件至多一次有依据的回退且不超总限；大文件可先定其他有限时限，同批完成等待／回退，不反复轮询。

最终失败停止探测，记附件、原因与受影响范围，不输出异常栈或推断内容错误／未定义；核心规格依赖未得附件则审核未完成。

## 疑点与样例核验

疑点先用上下文消歧，仍不明给两种合理解释，以合法手工小例或推导比较接受结果，构造题比输出集合。过程不同而判定相同不算实质歧义，猜中意图不算核验。

逐个手算正式样例、正文举例、图示和操作序列：初始状态与输入合法性、每步前提、状态更新、中间值及最终结果均与原文对照。多解不必与自算输出相同，但过程须合法；最终输出或 std 一致不能替代过程核验。未给过程时核验输出，不强制补简单步骤，未验完范围如实注明。

指出准确缺口与后果，不代写证明或修好任务。

## 附件代码

仅在用户明确要求时静态对照附件代码的文字、边界、初始化、类型、分支、中间计算及多测总资源，疑点／空项定向回查。未经要求不编译、运行、造数据、对拍或写样例运行脚本，格式脚本除外；静态不证明 AC。

## 任务叙述与阅读路径

以具备先修知识、未知解法的选手为基准，记录已知、缺口及回读位置。等级见[评分](rubric.md)，排版见[格式](format.md)。

### 任务叙述与推导

检查规则、状态、数量关系和样例推导的定义、前提及论据。报告原句、读者已知和实质缺失或跳步造成的断点，核心理解障碍按[内容量规](rubric.md#内容定级)定级。

题面无公开解法、动机、证明义务；无推导时查定义、任务与操作，推导项不适用。模型复杂、难想到、常规省略、总述后细化或紧邻定义本身不算障碍。

| 方面 | 核查机制 |
| --- | --- |
| 对象与指代 | 首次使用的含义、代词候选，以及条件、否定和量词的作用范围。 |
| 规则与组织 | 核对操作生效时刻、状态更新和执行顺序，确定实际规则是否一致，关键字段须非平凡论证才能补出时说明建模缺口。 |
| 背景映射 | 核对人物、行为与目标如何对应规则。牵强转换或无关叙事的阅读影响在文风启用时核验。 |
| 样例与展示 | 解释能否澄清规则，公式、图例、样例分隔及复制是否可用，是否与正文、勘误一致。 |

## 内容对象与记录

按[入口对象协议](../SKILL.md#审核对象与记录)为上述规格维度、重要声明、每个样例、附件和资源声明分别建项。正向由定义建立合法输入域与接受关系，逆向从输出、样例和边界反查规则，记录实质依据。已启用的文风与格式任务各自记录结果，覆盖检查发现空项后定向补查。

内容按对应核验 Reference 给每种做法或规格对象安排适用维度，分别记录定义、数学结论、依据、输入／操作边界、成本、数值及样例。采用正向与逆向路线互补，重要声明各自有结论。无附件／无某类结构等有依据时记不适用。

平台设有 AI 辅助创作资格或披露要求时，对照适用条款和作者声明、生成记录等直接证据核验来源合规。
