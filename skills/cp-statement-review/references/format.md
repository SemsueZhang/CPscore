# 格式协议

先确定语言、源码／发布形式及适用平台规范；图床等平台专属要求仅在适用时检查。此处只审排版，数学语义、规格、教学、文风和来源资格交内容审核。

## 文字与 Markdown

| 对象 | 要求 |
| --- | --- |
| 标点与空格 | 中文叙述用全角中文标点，完整句补句末标点。中文与英文、数字、行内公式间留一个半角空格；中文标点旁不加空格，中文词内不插多余空格或全角空格。缺空格、多空格分别核对。 |
| 数学模式 | 数学量、式、运算符及参与运算的常数用 LaTeX，普通词语、人名、题名、算法名不用。同一式放同一环境，独立公式用行间环境；说明用 `\text`，字符串用 `\texttt`，合法中文说明不一律判错。 |
| 标题与列表 | 一至四级非空标题组织章节，不堆砌强调、步骤或无关内容；同组同级同用途标题统一句末标点。列表标记后留空格，有序标记用数字加点，核对嵌套、缩进、顺序和归属。 |
| 代码与链接 | 程序片段、字符串用行内代码，成段代码用代码块，不用代码样式强调普通叙述。核对链接／图片语法、分隔与可用性、强调及容器定界。 |

长代码折叠仅建议，不计错误、未确认范围或扣分，也不改归其他类别；已有折叠块仍核验语法与闭合。代码／样例／字符串空格、列表缩进、表格对齐、行尾硬换行、TeX 内部空白及渲染器数学间距不算冗余。`结论 $x$ 。` 应删标点前空格，`中文  English` 应合并边界空格。

## 数学记号

下表适用于公式，不套用于代码中的合法语法。定义、量词、取整含义、边界及论证交内容审核，同根因不重复扣分。

| 对象 | 要求 |
| --- | --- |
| 赋值、推导与判定 | 赋值用 `\gets`／`\to`，推出用 `\Leftarrow`／`\Rightarrow`，比较用数学关系符，不照搬程序判等。艾佛森括号真假值明确，单向推出不写成等价。 |
| 除法、取整、取模 | 区分分数、整数商和上下取整；取整覆盖整个所需表达式，分母非零。余数用 $a\bmod b$，同余用 $a\equiv c\pmod b$。 |
| 集合与结构 | 区分属于／包含、空集／零、开闭端点；分量用上下标，不用程序成员访问。位运算用 `\operatorname{and}`／`or`／`xor`，改用集合语言仅建议。 |
| 上下标与大数 | 多字符下标、指数正确分组，大数用科学计数法，变量名和大小写一致。 |
| 复杂度 | 时空大 $O$ 省去固定乘法因子；$O(2n)$、$O(3n\log n)$ 即使随后化简仍违规。操作次数推导可留常数；$O(1)$、$O(n^2)$、$O(2^n)$ 合法。变化的值域／字符集用参数保留真实开销。 |
| 函数与大型运算符 | 加减、乘除、比较、整除记号正确；约定函数用 `\gcd`、`\max`、`\min`、`\log`、`\det` 等正体，其他函数用 `\operatorname`。求和、乘积、并交用大型运算符，哑变量、范围、被作用项和多层依赖明确。 |
| 结构与定界 | 分数、根号、上划线、集合括号用相应命令；分组、作用域、定界匹配，不改变含义。区分绝对值、范数、整除、条件分隔，允许等价合法写法。 |
| 省略与多行 | 用 `\dots`／`\cdots`／`\ldots`、矩阵方向 `\vdots`／`\ddots`、波浪线 `\sim`。连等用 `aligned`，分段用 `cases`，矩阵用 `bmatrix`；检查闭合、换行、对齐、维度、条件和边界。 |

## 按材料用途适用的展示要求

仅核验材料实际包含的内容，不强求题解重抄题面：

- 远程评测题名通常保留原文，知名书籍译名可例外。
- 输入输出同类句式统一，并列输入变量放同一数学环境，固定输出字符串用行内代码；中文序号仅建议。
- 完整题面的取模要求在描述和输出说明两处写明且一致；缺一处重复展示算格式，模数或是否取模不明交规格审核。
- 类型放输入说明，范围通常集中于说明／提示；无部分分时可在输入格式写范围。有效位少且不小于 $10^5$ 的数用科学计数法，不同范围分公式并用全角逗号隔开，相同范围可合并。
- 实际捆绑测试须加粗声明“本题采用捆绑测试”；表格、Subtask 无序列表仅建议。计分方式未知记待核验，不自行指定。

已有规范类别优先使用，其余展示违规用 `document_layout` 提交。字段缺失、范围错误、计分歧义交规格审核；缺失声明以应出现处的标题或邻近原文绑定位置，不伪造摘录，同一缺失只算一处。

## 格式计数与定级

以合并后的 `format_assessment` 计分，不另设格式满分，类别按脚本 `CATEGORIES`：

| 同篇同类已确认独立位置数 | 定级 |
| --- | --- |
| 0，无未确认范围 | 不扣分 |
| 1～2 | Major −2，一次 |
| 至少 3 | Fatal −10，一次，不叠加 Major |

正文／公式边界缺空格同类，缺与多空格不同类；同一边界多分支命中只算一次，公式两侧各缺则算两处。不同文章、同路径重复传入不累计凑数。

Warning、未支持语法及未验证范围不算 Confirmed；排除候选不计分。无法核实的必查范围标“未通过：无法确认”，每类一次 Major，同类已有 Confirmed 定级不额外扣。工具不可用时不安装依赖，LLM 按相同规则核验可得材料，仅剩余必查缺口记 Major，工具故障本身不扣稿件分。

## 全文覆盖与候选裁定

保留候选裁定和按规范类别的覆盖表，后者记范围、依据及“已核验／未核验／不适用”，不向工具 JSON 增字段。无候选不等于类别通过；已有拒绝理由也继续全文补查。

1. 逐项阅读候选上下文。排除须说明对象、归属和允许依据，不只写“不影响理解”“独立段落”或复用无关理由。
2. 按以上所有规范补查原文，区分数学量／普通词、完整句／短标签和必要空白。图片文字、复杂宏、HTML 及渲染支持须实际取得并核查；摘录只绑定来源，不证明显示事实。
3. 补齐覆盖空项，无法取得才留未核验。记录全部发现的独立位置，达到 Fatal 后继续查其余位置和类别；工具补充项提交后合并计数。

列表归属检查前一标记、当前块和下一同级条目。`- [题目 A](链接)` 后讲 A 的“前置知识／代码讲解”及代码属于该项，应缩进或把题名改为章节；空行不改变这一关系。列表结束后真正独立的结论无需缩进，排除理由须说明归属。

同组同级同用途标题补查句末标点一致性，用 `heading` 记录偏离位置，同时引用该标题和对照标题，经 `additional_findings` 合并。

## 格式工具的覆盖与边界

Python 3.8+ 标准库脚本不编辑、不联网、不运行模型，只计算格式扣分。无 Markdown 源码不声称源码合规；源码检查也不等于页面实测。使用工具时读取[扫描、裁定与合并接口](format-tool.md)。

## LLM 格式复核接口

候选裁定与补充发现按[接口](format-tool.md#来源绑定与合并)提交，静态 Confirmed 不能经裁定撤销；内容同根因仅在最终总分去重，不改原始扫描。

规范依据为仓库已核对的《洛谷主题库题解规范》格式条款（2026-11-13）及项目排版一致性要求，按材料和发布环境适用。
