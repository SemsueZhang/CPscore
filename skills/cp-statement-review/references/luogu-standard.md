# 洛谷规范核对表

依据：[洛谷主题库题目规范](https://help.luogu.com.cn/rules/academic/problem-standard)。本表核对于 2026-11-13，原页面标注版本为 2025-07，用于把适用条款转为审核项目，扣分见[评分协议](scoring.md)。用户要求最新规范或发现差异时核对原页面，说明采用的版本。

原规范面向洛谷主题库及公开赛。审核其他场景时说明平台和语言差异，不把洛谷的栏目名称机械套到其他题面。反馈工单、投题途径属于平台流程，不计入题面质量分。

## 核对项目

| 原规范章节 | 审核内容与适用条件 |
| --- | --- |
| 基本规范 | 中文标点用全角，句末标点完整。数学表达用 LaTeX，普通词语、人名、算法名等不套数学模式。中文与英文、数字、公式间留半角空格，中文标点旁不额外加空格。 |
| 题目背景 | 背景应帮助理解，避免无关叙事干扰规则。需要时补形式化说明，既不强求有故事，也不强求每题另设形式化段落。 |
| 题目描述 | 正文独立说清任务，不能依赖样例猜规则。遇到子串、子序列须说明连续性，涉及全部子串或子序列须说明空对象是否计入，使用“本质不同”须定义等价关系。检查错字及变量大小写一致性。 |
| 输入格式 | 交代数据类型、多测结构、各行数量和含义，并列变量放在同一公式中，行文形式统一。用中文写序号是建议，不以未采纳扣分。 |
| 输出格式 | 固定输出文本用行内代码。多解及浮点输出说明特殊判题，给出可执行的接受条件，浮点题说明误差标准。需要取模时，在描述与输出两处交代。行文形式统一。 |
| 数据范围 | 检查各输入量的上下界、字符集合、实数输入的小数位数，类型与范围不得矛盾。默认给出覆盖全部数据的范围。有效位较少且达到 $10^5$ 的数用科学计数法。不同范围分别写公式，以中文逗号分隔，相同范围允许合并。 |
| 部分分与捆绑 | 百分比和子任务约束应无歧义，依赖关系可省去已继承的范围。捆绑测试需加粗声明，实际分值与条件须对应。表格及 Subtask 无序列表是推荐呈现方式。没有部分分时，某变量的范围可放在输入格式中。 |
| 时空限制 | 时空上限原则上不低于 std 最坏情况资源用量的 1.5 倍，避免明显过紧或过宽。需核对环境、计量口径及最坏情况依据，单次普通样例运行不能证明裕量充足。区分裕量不足与已证实无法通过限制，后者按实质影响判级。 |
| 多语言 | 各语言版本均应完整、独立可读，术语一致，不能只译形式化摘要或夹带无关内容。不影响理解的自创词、人名可按原规范保留并说明。专有名词可附原文。RemoteJudge 标题通常保留原文，核对被知名书籍引用且翻译的例外。已确认使用 AI 辅助翻译时应有声明并经人工校对，不凭文风推断使用 AI 或未校对。 |

“特殊判题”一项中，说明误差、接受条件及核对实现是 CPScore 对判定确定性的细化。时空核验和译文对照依赖材料，只报告已有证据支持的范围。

## 要求与建议

明确格式要求违反后，即使语义仍清楚，也至少判 Major −2。严重排版错误使核心题意、合法输入或判定无法可靠辨认时，可判 Fatal −10。建议项只作改进建议，原则性条款先核对合理例外。没有适用对象的条款记为不适用，例如整数唯一输出不检查浮点误差，单语言原创题不检查翻译声明。

按独立根因计分，不能把一处遗漏同时以“违反规范”和“影响理解”重复扣分。规范符合程度也不能替代题意唯一性、正式样例和首次阅读的实质核验。
