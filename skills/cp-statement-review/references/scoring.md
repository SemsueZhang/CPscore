# 分级与评分

评分覆盖规格正确性、完整性、适用格式规范和易读性。以下分值为 CPScore 的机制，并非洛谷官方评分。

## 缺陷等级与影响判据

| 等级 | 已确认的影响 |
| --- | --- |
| **Fatal −10** | 影响任务或接受关系且上下文不能消除的歧义、必要约束缺失、定义矛盾、输出或判定不确定，正式样例输入、输出或解释的实质错误。语言、公式、下标或样例分隔严重损坏，核心对象、条件、否定、量词、顺序或合法输入无法可靠还原，也可判此级。 |
| **Major −2** | 模型最终可确定，但题目特有规则、背景映射、术语、组织、图示或样例解释造成显著理解负担；关键字段需非平凡论证才能补全。适用的明确格式要求未满足至少为此级，即使语义清楚，包括取模要求只在描述与输出一处说明。译文重要内容缺失、须借另一语言理解，或有依据确认资源裕量不足、明显误伤合理正确实现但未证实实质超限，也在此判断。 |
| **Minor −1** | 已确认的错漏字、拼写错误及可轻易恢复的局部符号、语法、定义、指代或展示缺陷，且不构成明确格式违规或更高等级影响。明确文字错误即使不影响答案也扣分。 |
| **不扣分** | 未采纳建议、原则性条款有合理例外、允许的等价写法、正常省略、求解所需算法性质，以及题材、文风、篇幅和纯排版偏好。未证实疑点及纯可选优化不扣分。 |

按实际影响而非遗漏字段数量或修复难易定级。一个错字改变否定或边界也可能为 Fatal，能猜到意图或容易修改不降低级别。范围、空串、模数、多解或精度约定的遗漏，须区分判定不确定、说明负担和语义完整但违反明确格式要求。

样例实质错误与解释不足分别判断，后者不自动为 Fatal。未覆盖全部边界、缺图、未逐步讲解本身不扣分。背景只有造成具体理解障碍才扣分，核心规则因此不确定时按 Fatal。

## 计分与去重

`评分 = 10 − 10×Fatal数 − 2×Major数 − Minor数`，允许负分。

只扣已确认的独立根因。同一错误的语义、阅读及规范后果按最高级别扣一次。同一排版规则多处违反合并一项，列代表位置与范围，不按字符或出现次数累计。不同根因需要分别修复时独立计分，不能将所有语言问题一并合并。

## 档次与完成状态

关键核验完成后：9～10分为“优秀，具备推荐资格”，6～8分为“尚可，值得打磨”，5分及以下为“不合格，存在重大问题”。无确认问题允许10分，不为体现审核价值强行扣分。

关键材料未读完或有未决正确性疑点时说明具体缺口。6～10分首行写“暂定评分x/10，审核未完成，档次待定”；已确认分数≤5可判不合格并保留未完成范围。疑点本身不扣分。

仅缺少资源裕量、译文来源等附加对照材料，不自动否定已完成的题面审核，也不能宣称这些项目已通过。缺口涉及核心题意或判定时按关键核验未完成处理。
