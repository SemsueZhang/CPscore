# 题面审核

判断任务是否明确、规则是否易懂，并检查适用的格式要求。

## 审核流程

1. **独立阅读**：只凭题面，按[规格核验](references/specification.md)重建任务然后按[阅读与修订](references/readability.md)记录阅读障碍。
2. **主动核验**：按阅读与修订中的规则一次定级局部问题，深入复核可能影响任务或判定的疑点，并独立检查正式样例。附件按规格核验中的获取与停止规则处理。
3. **评议**：按[评分协议](references/scoring.md)汇总级别、去重和判断完成状态，根据上下文给出修改意见。

按材料语言、发布形式及用户指定要求判断条款是否适用。

## 交付

- 输出模式：默认在对话中输出结果，仅在用户要求时写文档。不自主更改原题面。以 `# CPScore · 题面审核` 开头，先给评分、档次和完成状态，模型内部思考流程不输出。
- 扣分项：每项列级别与扣分、原文位置、依据、影响、局部修订及复核结果。语义问题给区分实例或推导，阅读问题指出受阻步骤，格式问题注明违反的要求。
- 建议：可选建议与未决问题单列，后者说明已做检查和所缺材料。无扣分项时概述关键核验及范围。未复核的建议如实标记，不把建议写成已修复。
- 账本：最后列审核账本，即真实 token 开销。宿主未提供用量时注明不可得，不估算。
