# 题面审核

独立判断题面是否定义了可判定的任务，以及目标选手能否据此理解规则。使用宿主已有工具，不依赖其他技能。

## 流程与 Reference

1. **独立阅读**：只读完整题面，按[规格核验](references/specification.md)在内部重建合法输入域与输入—输出关系，选择相关边界。按[阅读与修订](references/readability.md)顺序记录首次阅读中的具体障碍，不先看题解、std 或生成器。
2. **主动核验**：针对疑点尝试两种合理解释及最小合法区分实例，用上下文、推导或必要的小程序裁定，并独立检查正式样例。将确认的规格问题、纯阅读障碍、未决疑点与正常省略分开。
3. **交叉核对与修改**：完成独立核验后，才读用户提供的题解、程序、判定器、生成器或译文。材料冲突须追查来源，不默认题面有错，也不用作者意图补齐正文缺口。按阅读与修订中的“最小修改与复核”提出局部修订，最后读取[评分协议](references/scoring.md)定级、去重并判定完成状态。

规格与阅读 Reference 分别用于语义和表达检查，评分 Reference 仅用于裁定。平台条款按适用场景和语言核对，用户指定其他规范时说明差异，不加载无关材料。

## 证据与交付

默认在对话输出 Markdown，仅用户要求保存时写报告。只要求审核时不改原题面，不创建审核台账。内部规格不必完整抄入报告。

用 `# CPScore · 题面审核` 开头，先给评分、档次及完成状态。每项写“[级别及扣分] 问题”、原文位置、核验依据、实际影响、可直接采用的局部修订及复核结果。语义问题展示区分实例或推导，阅读问题说明受阻步骤，规范问题注明条款及适用条件。条件性方案明确待作者选择，未复核的建议如实标记。

可选优化与扣分项分开。未决问题写清具体命题、已做检查和所缺材料，不伪造实测或把有限检验当作证明。无扣分项时概述关键核验及未完成范围，不输出空清单。
