# 题面审核

判断任务是否明确、规则是否易懂。内容审核与格式审核分别完成、分别报告，再合并评分；由审核 LLM 负责脚本未覆盖的部分，不设人工复核或独立子 Agent。

## 审核流程

1. **内容审核**：固定目标读者，只凭原稿按[规格核验](references/specification.md)还原任务，检查实质声明的前提、依据与整个输入域，逐步手算正式样例及文字演示。按[阅读与修订](references/readability.md)检查人类思维、表达缺陷及全文题外内容；多类显著机械化迹象共同出现时，报告“本文大概率由 AI 生成”及文本依据。
2. **主动核验**：定位影响任务、接受条件或理解的疑点，指出失效处或缺失规则，不替作者补条件、修正文意或代写证明。按规格核验记录覆盖状态，附件按有限获取规则处理；如附代码，只作一次静态对照，默认不编译、运行或造小数据。不用格式发现代替内容判断。
3. **格式审核**：另按[共用格式协议](references/format.md)运行下节脚本。LLM 既核验候选和跳过范围，也主动检查脚本没有报告的原文，允许新增及重新归类发现，经来源绑定接口交脚本统一计分。候选为空不视为全文通过，发现足以拒绝的错误后仍完成其余适用项。
4. **评议**：收尾核对覆盖空项、证据和结论变化，分别报告内容与格式结论，再按[评分协议](references/scoring.md)合并同根因和总分。重审说明新增、撤销或改级理由，不增加重复审判或多轮投票。适用必查项不能严格确认合规时判不合规，未完成核验须明示。

按材料语言、发布形式及用户指定要求判断条款是否适用。

## 格式检查与机器复核

先确认命令执行能力和已有 Python 3，解析到本 Skill 目录后运行：

```sh
python3 scripts/format_lint.py --check
python3 scripts/format_lint.py /path/to/statement.md
# 需要 LLM 复核时，生成临时 JSON 后合并：
python3 scripts/format_lint.py --decisions /tmp/review.json /path/to/statement.md
```

仅用 Python 3.8+ 标准库，不联网、不调用模型、不安装依赖、不修改原文。多个 Markdown 可一次传入，逐文件定级；`--rules` 查看类别。脚本与格式协议由题面、题解共用源打包，单独复制本技能即可使用。

读取 `status`、`errors`、`files_checked`、`linter_version`、`render_model` 和 `format_assessment`。同篇同类 Confirmed 的独立位置数为 1～2 时 Major −2，至少 3 时 Fatal −10，同类只扣一次。脚本只算格式扣分，最终总分按评分协议汇总。

Warning、图片文字、复杂 HTML 等范围由审核 LLM 按[复核接口](references/format.md#llm-格式复核接口)实际核验。脚本校验文件、摘要、候选和精确摘录，统一合并补充发现；未确认项不凑成三处 Fatal，不能经接口撤销静态 Confirmed。输入输出、范围和子任务展示同样按共用协议的适用要求复核，不将语义或范围缺失重复算格式错误。

没有 Python 或脚本失败时，不安装环境，由 LLM 继续核验已有材料并按相同类别和独立位置规则计分。工具故障本身不扣分，剩余格式核验缺口按共用协议处理。只有 PDF／截图不能证明源码合规，源码扫描也不等于目标页面实测。工具边界见[共用格式协议](references/format.md#格式工具的覆盖与边界)。

## 交付

- 输出模式：默认在对话中输出结果，仅在用户要求时写文档。不自主更改原题面。以 `# CPScore · 题面审核` 开头，先给评分、档次和完成状态，模型内部思考流程不输出。
- 扣分项：总结果后分开列内容审核与格式审核。每项列级别、位置、短摘录、失效依据、影响和最小修改方向；语义问题指出区分实例或准确缺口，不代写完整规则或证明。人类思维检查给受阻步骤或支持通过的阅读依据，样例列实际手算过程。AIGC 倾向按阅读协议报告，不能作为独立重复扣分或来源确证。格式引用合并后的类别、Confirmed 次数、级别及代表位置，区分静态证据、LLM 裁定与无法确认范围。
- 建议：可选建议与未决问题单列，后者说明已做检查和所缺材料。无扣分项时概述关键核验及范围。未复核的建议如实标记，不把建议写成已修复。
- 账本：最后列审核账本，即真实 token 开销。宿主未提供用量时注明不可得，不估算。
- 核验范围：注明实际材料、脚本版本和运行／失败范围，源码规则检查与目标页面实际渲染分别说明。
