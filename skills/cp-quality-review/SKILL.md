# 题目质量评分（Problem Quality Rating）

理解用户提供的人类题解，评价其中的核心考点、原创性和算法设计质量。使用宿主已有工具，独立安装即可运行。

本技能理解和评价已有解法，不独立解题、寻找更优算法、创造额外路线或要求重新发现关键观察。必要核对限于影响理解和评级的结论、条件及逻辑关系，不开展完整正确性审计。题解缺少核心算法或关键观察时，列明所缺信息，暂不确定评级。

## 流程与 Reference

1. **理解题解**：阅读完整题面、约束和人类题解，整理其主要算法、明确描述的关键观察、数学转化、技术依赖、推导联系与复杂度。多种给定解法分别理解和比较，注明评级所依据的路线。
2. **检索先例**：读取[检索与材料整理](references/retrieval.md)，围绕题解中的模型、观察和算法检索 CPRet、arXiv 与普通网页。阅读接近来源，比较适用条件、可复用步骤与剩余独立亮点。论文命中后，先按[评级协议](references/rating.md)判断重合结论的重要性和赛时可推导性，仅将选手难以在赛时独立推导的重要结论计入与论文重复。已有 Python 时可使用[检索辅助脚本](retrieve.py)。
3. **评价质量**：读取[评级协议](references/rating.md)，按重要核心观察的原创性和设计质量定级，重点判断 A / B 是否达到加号标准，以及研究型题目是否满足 S。
4. **交付报告**：按[报告协议](references/report.md)给出质量等级、用途、先例比较、决定性设计理由和必要修改建议。
