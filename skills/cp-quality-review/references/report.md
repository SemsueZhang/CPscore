# 质量评分报告

默认对话 Markdown，要求保存才写文件。每题独立，聚焦决定评级的依据。

**改变结论的另解放在标题后、等级前**：路线、核实依据、被绕过／改变的考点与评级影响。未核实则标“待核实”、缺口及条件，不当成立；无影响可在正文简述。

正文建议包含：

1. **质量等级与用途**：A+、A、B+、B、C、D、F 或 S，以及决定性理由。材料或检索不足时写“待定”及具体缺口。
2. **核心考点**：简述给定解法及影响结论的已核实替代路线中的重要观察、技术路线和思考价值，注明所评路线及来源。
3. **先例比较**：说明任务与条件对应、可复用的非平凡步骤、剩余独立亮点，附实际读到的来源。涉及论文时，先说明重合结论的重要性、赛时可推导性及是否计入考点重复，区分背景文献与影响评级的实质先例。
4. **设计质量**：围绕考点、发现动机、推导联系、技术依赖和收益负担说明关键判断。A / B 重点解释是否达到加号标准；S 说明研究价值与竞赛障碍。
5. **修改建议**：只针对实际设计问题提出简洁、可执行的建议。

不复述完整题解、探索过程或机械五项打分。决定性另解给足算法、正确性与成本依据；就近引用实际读过的原题／题解／论文章节，版本和日期记一次。

题解写作与算法设计分开，检索限制就地说明，不编造先例、动机或推导以凑等级或强行降级。
