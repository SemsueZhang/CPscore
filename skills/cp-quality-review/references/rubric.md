# 题目质量评级协议

## 八种等级

| 等级 | 定义 | 推荐用途 |
| --- | --- | --- |
| A+ | 大部分重要核心观察具有独立创新性，设计优秀，考点清晰，推导自然且循序渐进。 | 正式比赛，优先推荐 |
| A | 大部分重要核心观察具有独立创新性，题目设计合理。 | 正式比赛 |
| B+ | 多数核心观察已有先例，但仍有实质独立亮点，整体设计优秀。 | 正式比赛 |
| B | 大部分核心观察已有类似做法，但还保留少量有价值的独立亮点。 | 训练题 |
| C | 核心观察基本都有类似先例，主要价值在于已有思想的组合与应用。 | 训练题 |
| D | 构成实质先例的题目或论文方法经过常规调整即可直接套用。 | 不推荐作为原创赛题 |
| F | 与已有题目实质相同，主要是背景、名称或普通参数变化。 | 不推荐作为原创赛题 |
| S | 高度原创且具有独立研究价值，但整体设计严重不适合算法竞赛。 | 研究问题 |

S 是独立研究型分类，不在 A+ 之上。字母表达原创性与设计质量的组合，不能换算为材料的 10 分制。

## 替代解法检查

从给定题解与约束主动检查朴素方法、步骤简化、常见转化和绕过核心的具体路线；无新线索即结束，不穷举、无限优化或宣称已排除另解。

候选须核实完整算法、正确性、全范围成本及实现条件才纳入；局部测试仅补证。快或短不等于易发现。注明用户、检索或审核推导来源，审核新推导不自动成为先例。

已核实另解绕过考点时，重评实际观察、独立亮点及收益负担；直接套用成熟方法须核对先例，自然有价值另解也可改善设计。多解本身不加减分，不取路线最低评级。

未核实候选可能改变等级或关键理由时给条件性结论／待定，不直接升降级；报告前置说明另解影响。

## 原创性判断

以给定题解及已核实替代路线的核心观察和技术路线为对象，说明各观察对完整算法的作用，再与先例比较：

- 任务、关键约束与目标是否实质相同。
- 已有方法在当前条件下能否直接解决问题，所需调整是否常规。
- 哪些非平凡观察已有实质类似做法，哪些仍有独立价值。
- 新旧观察的联系是否产生了新的思考价值。

比较原题／论文的任务、约束、算法、复杂度及条件，逐步对应；算法名、数据结构、模型或检索相似度仅线索，基础工具相同不等于核心观察有先例。

“大部分／少量”按观察重要性，不按数量。D 为方法可直接套用，F 为题目实质相同，C 重组合应用，B／B+ 须有实质独立亮点；各路线同口径说明先例关系。

未核实先例写“本轮检索未核实到实质先例”及范围，不宣称全球原创或预设等级倒选证据。

### 论文先例门槛

论文命中须同时满足以下条件，才计入竞赛考点重复：

1. **结论重要**：它承担完整解法中的关键转化、算法成立条件或复杂度保证，对核心考点有实质作用。
2. **赛时难以独立推导**：以预期参赛选手、赛制、常用竞赛知识和本题线索为背景，说明发现该结论的关键障碍，判断选手不预先阅读论文时是否仍有合理的赛时发现与推导路径。

两项同时成立才纳入 A／B／C／D 的先例覆盖。赛时可独立推出的结论仅作背景，不据论文降原创性或计入多数先例；这也不代表学术首创。

依题目线索、推导与发现障碍判断是否依赖预读论文；生僻出处／术语不证明依赖，事后短证明不证明易发现。具体绕过候选须核实，证据不足说明未知，不凭命中降级。

此门槛仅针对论文；已核实竞赛题先例仍按任务、约束、观察和解法比较，包括同一结论另有竞赛先例时。

## A+ 与 B+ 的共同优秀设计标准

| 标准 | 评价内容 |
| --- | --- |
| 核心考点清晰 | 关键思想有独立思考价值，相关技术服务于明确考点，无关技巧没有淹没主线。 |
| 发现路径自然 | 结合题目条件和所评的已核实路线，说明考虑该方向的动机、原方法的障碍、关键观察的作用，以及特殊结构提供的线索。 |
| 推导循序渐进 | 算法步骤与重要观察之间有清楚联系，主要转折有动机，避免依赖猜测的巨大跳跃。一个清晰的关键观察也可构成优秀题目。 |
| 技术依赖合理 | 必要知识与题目线索相称。高级、陌生或论文中的技术，只要能自然引导理解或推出相关性质，便可合理使用。 |
| 思考收益与负担协调 | 洞察价值与必要证明、实现和分类工作相称，条件与特判服务于统一考点。 |

发现自然性据题目线索和已核实路线，不要求未知答案时重做，也不以易证明替代。文风、排版、详略属题解写作，仅核心思路无法理解时记材料缺口。

A+／B+ 须上述方面整体优秀，区别在原创性，不逐项算分／平均。A 只需高原创与合理设计，B 不要求 B+ 标准。高级技术、长证明、高难、多解、代码长度和复杂度数字本身不扣质量。

## 定级与完成状态

说明决定等级的观察、先例和设计。S 须兼有高度原创、独立研究价值及严重竞赛适配障碍，不收纳一般设计不佳。

高原创但设计不合理且不满足 S 时，给改法、暂不定级，不借先例等级替代设计判断；待定是状态，不是第九级。

缺算法、关键观察、条件或检索依据时明确缺口，不猜补原稿。审核推导另解经核实可支撑评价，但保留原稿缺口与来源；决定性路线未核实仍给条件结论／待定。
