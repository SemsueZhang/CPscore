# 题目质量评级协议

## 等级

| 等级 | 定义 | 推荐用途 |
| --- | --- | --- |
| A+ | 达到 A 的原创性标准，整体设计优秀。 | 正式比赛，优先推荐 |
| A | 大部分重要核心观察具有独立创新性，题目设计合理。 | 正式比赛 |
| B+ | 达到 B 的原创性标准，整体设计优秀。 | 正式比赛 |
| B | 理解先例解法能显著推进本题的部分关键步骤。完成本题仍需独立推出有分量的关键观察。 | 训练题 |
| C+ | 达到 C 的原创性标准，整体设计优秀。 | 训练题，优先推荐 |
| C | 理解先例解法后，能从本题线索自然想到所需转化或组合，并沿用完整的算法主干。 | 训练题 |
| D | 能读懂代码的选手，即使两题都未独立做出，对照两份题面和旧题实现也能直接看出对应关系，靠常规调整完成本题。 | 不推荐作为原创赛题 |
| F | 去掉背景和记号差异后，两题的任务、有效约束和输出目标实质一致，对照题面即可识别。 | 不推荐作为原创赛题 |
| S | 高度原创且具有独立研究价值，但整体设计严重不适合算法竞赛。 | 研究问题 |

S 是独立研究型分类，不在 A+ 之上。字母表达原创性与设计质量的组合，不能换算为材料的 10 分制。

## 替代解法检查

从给定题解与约束主动检查朴素方法、步骤简化、常见转化和绕过核心的具体路线；无新线索即结束，不穷举、无限优化或宣称已排除另解。

候选须核实完整算法、正确性、全范围成本及实现条件才纳入；局部测试仅补证。快或短不等于易发现。注明用户、检索或审核推导来源，审核新推导不自动成为先例。

已核实另解绕过考点时，重评实际观察、独立亮点及收益负担；直接套用成熟方法须核对先例，自然有价值另解也可改善设计。多解本身不加减分，不取路线最低评级。

未核实候选可能改变等级或关键理由时给条件性结论／待定，不直接升降级；报告前置说明另解影响。

## 原创性判断

以给定题解及已核实替代路线为对象，逐步对照先例的任务、约束、算法和复杂度。明确先例提供的步骤、题面提示的联系，以及选手仍需独立推出的观察。按观察对完整解法的分量判断。算法名、基础工具及检索相似度仅用于定位候选。

- **F／D**。先核对题面能否直接识别为同一任务。任务有实质变化时，按 D 的参照条件检查输入、状态、转移和输出的对应是否显然，以及常规调整后的算法能否覆盖全部约束。只有题解时，可用能复原实现的描述作对照。
- **D／C**。检查选手如何发现转化。照着两份题面和旧实现即可完成的调整支持 D。若要从旧题解法联想到一个有内容的建模或组合，完成后即可沿用算法主干，支持 C。用题面线索说明发现过程，勿凭改动行数、状态表相同或猜测的赛时用时定级。
- **C／B**。核对先例能否接续成完整路线。可以合用多个已核实的先例，并检查连接它们所需的推导。若关键转化或后续步骤仍有须独立解决的算法障碍，计入 B 的独立观察。区分 B 与 A 时，按这些观察在整条路线中的分量判断。

牛客《Bit Compression》直接给出 01 串。若变式仍直接给 01 串，只去掉 XOR 并按 AND 次数统计，照代码修改可判 D。P17903《樱花任务》还须把取值展开成真值表，推出每层量词在所有外层取值分支上使用同一运算，才可沿用逐层压缩的核心算法，符合 C 的先例关系。 [牛客原题](https://ac.nowcoder.com/acm/problem/17486) · [P17903](https://www.luogu.com.cn/problem/P17903)

未核实先例写“本轮检索未核实到实质先例”及范围，不宣称全球原创或预设等级倒选证据。

### 论文先例门槛

论文命中须同时满足以下条件，才计入竞赛考点重复：

1. **结论重要**：它承担完整解法中的关键转化、算法成立条件或复杂度保证，对核心考点有实质作用。
2. **赛时难以独立推导**：以预期参赛选手、赛制、常用竞赛知识和本题线索为背景，说明发现该结论的关键障碍，判断选手不预先阅读论文时是否仍有合理的赛时发现与推导路径。

两项同时成立才纳入 A／B／C／D 的先例覆盖。赛时可独立推出的结论仅作背景，不据论文降原创性或计入多数先例；这也不代表学术首创。通过门槛的方法用其算法描述或实现检查 D／C／B 边界。

依题目线索、推导与发现障碍判断是否依赖预读论文；生僻出处／术语不证明依赖，事后短证明不证明易发现。具体绕过候选须核实，证据不足说明未知，不凭命中降级。

此门槛仅针对论文；已核实竞赛题先例仍按任务、约束、观察和解法比较，包括同一结论另有竞赛先例时。

## 加号与优秀设计

仅 A、B、C 可以加号。先依据原创性和先例关系确定基础等级，再按以下标准判断整体设计是否优秀。加号沿用该档的原创性判断。

| 标准 | 评价内容 |
| --- | --- |
| 核心考点清晰 | 关键思想有独立思考价值，相关技术服务于明确考点，无关技巧没有淹没主线。 |
| 发现路径自然 | 结合题目条件和所评的已核实路线，说明考虑该方向的动机、原方法的障碍、关键观察的作用，以及特殊结构提供的线索。 |
| 推导循序渐进 | 算法步骤与重要观察之间有清楚联系，主要转折有动机，避免依赖猜测的巨大跳跃。一个清晰的关键观察也可构成优秀题目。 |
| 技术依赖合理 | 必要知识与题目线索相称。高级、陌生或论文中的技术，只要能自然引导理解或推出相关性质，便可合理使用。 |
| 思考收益与负担协调 | 洞察价值与必要证明、实现和分类工作相称，条件与特判服务于统一考点。 |

发现自然性据题目线索和已核实路线，不要求未知答案时重做，也不以易证明替代。文风、排版、详略属题解写作，仅核心思路无法理解时记材料缺口。

综合判断设计质量，不逐项算分或平均。高级技术、长证明、高难、多解、代码长度和复杂度数字本身不扣质量。

## 定级与完成状态

说明决定等级的观察、先例和设计。S 须兼有高度原创、独立研究价值及严重竞赛适配障碍，不收纳一般设计不佳。

高原创但设计不合理且不满足 S 时，给改法、暂不定级，不借先例等级替代设计判断。待定表示材料或判断尚未完成。

缺算法、关键观察、条件或检索依据时明确缺口，不猜补原稿。审核推导另解经核实可支撑评价，但保留原稿缺口与来源；决定性路线未核实仍给条件结论／待定。
