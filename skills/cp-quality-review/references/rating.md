# 题目质量评级协议

## 八种等级

| 等级 | 定义 | 推荐用途 |
| --- | --- | --- |
| A+ | 大部分重要核心观察具有独立创新性，设计优秀，考点清晰，推导自然且循序渐进。 | 正式比赛，优先推荐 |
| A | 大部分重要核心观察具有独立创新性，题目设计合理。 | 正式比赛 |
| B+ | 多数核心观察已有先例，但仍有实质独立亮点，整体设计优秀。 | 正式比赛 |
| B | 大部分核心观察已有类似做法，但还保留少量有价值的独立亮点。 | 训练题 |
| C | 核心观察基本都有类似先例，主要价值在于已有思想的组合与应用。 | 训练题 |
| D | 构成实质先例的题目或论文方法经过常规调整即可直接套用。 | 不推荐作为原创赛题 |
| F | 与已有题目实质相同，主要是背景、名称或普通参数变化。 | 不推荐作为原创赛题 |
| S | 高度原创且具有独立研究价值，但整体设计严重不适合算法竞赛。 | 研究问题 |

S 是独立研究型分类，不在 A+ 之上。字母表达原创性与设计质量的组合，不能换算为材料的 10 分制。

## 原创性判断

以人类题解已经明确的核心观察和技术路线为对象，说明各观察对完整算法的作用，再与先例比较：

- 任务、关键约束与目标是否实质相同。
- 已有方法在当前条件下能否直接解决问题，所需调整是否常规。
- 哪些非平凡观察已有实质类似做法，哪些仍有独立价值。
- 新旧观察的联系是否产生了新的思考价值。

核对原题或论文中的任务、约束、算法、复杂度及适用条件。相同算法名、数据结构、模型或检索相似度只提供线索，不能代替步骤对应。基础工具的使用不等于核心观察已有先例。

按观察的重要性判断“大部分”和“少量”，不统计数量比例。D 强调方法可直接套用，F 强调题目实质相同；C 的价值在组合与应用，B / B+ 还须有实质独立亮点。多条人类给定路线采用同一比较口径，并说明各路线的先例关系。

未找到先例写为“本轮检索未核实到实质先例”，原创性判断注明检索范围，不宣称全球原创。不预设等级后反向选择证据。

### 论文先例门槛

本评级关注竞赛中的考点原创性，不以学术文献中是否出现过相同结论直接定级。找到论文后，先判断重合部分是否同时满足：

1. **结论重要**：它承担完整解法中的关键转化、算法成立条件或复杂度保证，对核心考点有实质作用。
2. **赛时难以独立推导**：以预期参赛选手、赛制、常用竞赛知识和本题线索为背景，说明发现该结论的关键障碍，判断选手不预先阅读论文时是否仍有合理的赛时发现与推导路径。

仅当两项均成立，才将对应结论计入“考点与论文重复”，纳入 A / B / C / D 等级中的先例覆盖判断。若结论虽见于论文，但选手能根据题目条件在赛时独立推出，则可作为背景文献引用，不以该论文命中降低原创性等级，也不计入“多数核心观察已有先例”。这不表示该结论具有学术首创性。

判断重点是题目是否实际依赖预先读过论文才能完成关键突破。不能因论文出处生僻或术语高级就认定存在这种依赖，也不能仅因事后证明简短就认定赛时容易发现。依据人类题解中的线索、推导联系和发现障碍作必要判断，不另行开展独立算法探索。证据不足时说明不确定性，不仅凭论文命中降低评级。

这一门槛针对论文先例。已核实的竞赛题先例仍按任务、约束、关键观察与解法对应正常比较，同一结论同时存在竞赛题先例时也如此。

## A+ 与 B+ 的共同优秀设计标准

| 标准 | 评价内容 |
| --- | --- |
| 核心考点清晰 | 关键思想有独立思考价值，相关技术服务于明确考点，无关技巧没有淹没主线。 |
| 发现路径自然 | 结合题目条件和人类题解，说明考虑该方向的动机、原方法的障碍、关键观察的作用，以及特殊结构提供的线索。 |
| 推导循序渐进 | 算法步骤与重要观察之间有清楚联系，主要转折有动机，避免依赖猜测的巨大跳跃。一个清晰的关键观察也可构成优秀题目。 |
| 技术依赖合理 | 必要知识与题目线索相称。高级、陌生或论文中的技术，只要能自然引导理解或推出相关性质，便可合理使用。 |
| 思考收益与负担协调 | 洞察价值与必要证明、实现和分类工作相称，条件与特判服务于统一考点。 |

根据人类题解评价发现动机与逻辑联系，不要求智能体在未知答案时重做题目，也不以“结论容易证明”代替发现自然性的判断。表达文风、排版和讲解详略属于题解写作质量；仅当核心思考无法理解时，列为材料缺口。

A+ 与 B+ 均须在上述方面整体优秀，区别在原创性程度；不对五项机械打分或求平均。A 确认高原创性和合理设计即可，B 不要求满足 B+ 的优秀标准。高级技术、长证明、高难度、多解、代码长度或复杂度数值本身不构成负面评价。

## 定级与完成状态

给出决定等级的核心观察、先例覆盖与设计理由。S 必须同时说明实质原创性、独立研究价值和严重竞赛适配障碍，不能收纳所有设计不佳的题目。

高原创但设计不合理、又不满足 S 时，说明需要调整的设计，暂不定级；不要改用表示先例覆盖程度的等级代替设计判断。“待定”是完成状态，不是第九种等级。

题解缺少算法、关键观察或必要条件，或检索尚不足以支持等级时，指出具体缺口。核对影响评级的结论和逻辑关系即可；需要新增关键观察、完整证明或独立算法探索才能补全时，保留未决状态，不自行补出解法后确定评级。
