# 新颖度审核

读取题目或 idea、解题报告与约束，独立判断先例关系、合适度与质量，不依赖其他技能。

## 流程与 Reference

1. 梳理任务、关键约束、观察、算法和复杂度，兼顾其他可通过路线。关键条件不清时针对性读题或推导，不直接采信作者评价。新题查重寻找公开先例，原场题回顾比较此前独立工作，原题自身和转载只用于理解当前题。
2. 检索时读取[检索与材料整理](references/retrieval.md)，按其中的来源覆盖、原文核实及回退规则收集证据。可用时使用[可选辅助脚本](retrieve.py)，不增加安装要求。
3. 按[评级协议](references/rating.md)比较先例与剩余独立思考，核验影响质量判断的推导。对具体疑点补证、反驳或局部修复，再确定等级。
4. 交付时读取[报告协议](references/report.md)，逐题给出完整分析和实际来源。汇总保留各题结论、关键依据及全部确认问题，按需回读，不重复输出全文。
