# 新颖度审核

读取题目或 idea、解题报告与约束，按[评级协议](references/rating.md)独立判断先例关系、合适度与质量，逐题给出等级及依据。

## 材料与范围

记下题名、材料链接或文件、版本与评审日期。新题查重寻找已公开先例，原场题回顾比较此前独立工作，原题自身及转载用于理解当前题。

梳理任务、关键约束、观察、算法及复杂度，兼顾其他可通过路线的推导与实现成本。关键条件不清时针对性读题、推导或补查，不直接采信材料中的作者评价。

## 检索与先例比较

首次检索前按[检索说明](references/retrieval.md)检测环境，可用时以[辅助脚本](retrieve.py)整理候选与缓存正文，否则使用宿主工具，不增加安装要求。

使用宿主搜索与浏览能力，每题覆盖[CPRet](https://www.cpret.online)、[arXiv](https://arxiv.org/search/)和普通网页，围绕模型、关键观察及转化查询，按疑点补查自然特例或变体。CPRet 可用时展开候选及相关组内成员，必要时读摘要或题意。复用有效结果，结果重复且无新线索时结束。

阅读最接近的原题、题解或论文正文，核对任务、约束、转化、算法、复杂度、随机性及误差等适用条件。题名、分数和服务分组只作线索，核实别名，正文错配时转查官方来源或独立镜像。

先按评级协议明确基础知识与各路线的关键推导，再比较先例。判 C 须说明适用条件、替代的非平凡步骤及剩余独立思考，不能仅凭相同构造或贪心路径评级。

来源不可访问时，在先例比较中说明实际范围并用可访问来源补查，不把检索失败写成未找到先例。无网络时可分析给定材料，不能宣称完成外部查重。只引用实际读到的内容。

## 错误定位与解法核验

定位断言、上下文与影响，排除误读并尝试局部修复。补证、纠正符号或拼接后核心算法与复杂度不变的，写出修复推导并据此评价。若需要新关键引理、算法或条件，明确新增工作，不当作已完成修复。反驳须给具体推导或反例。

分别判断证明、结论、算法和题目质量。文字或证明错误不自动阻止 C+/F，拒绝升级前检查已知替代路线能否绕过缺口。未补出的命题不算已证伪，无需穷尽算法或审计全部代码。

## 交付

按[报告协议](references/report.md)逐题加载材料并交付完整分析与来源。汇总保留各题结论、关键依据和全部确认问题，按需回读，不重复输出全文。
