读取题目或 idea、解题报告与约束，独立交付 `novelty.md` 及证据附件。最终判断由用户裁决。常规只加载本文件；已有检索与阅读工具时直接使用。需脚本参数或接口排错时，安装后按需读 `.cpscore/novelty.md`（相对本文件 `../../../.cpscore/novelty.md`），源码中读 `docs/novelty.md`。

## 材料与范围

记录材料版本、来源和评审时点。新题查重寻找已公开先例；评审原场题时，其自身发布、题解及转载只作当前题来源，比较此前独立工作。解法或关键条件不足时说明影响，不假设已掌握整解。预期做法兼顾复杂度与实现成本，其他可通过算法也参与评级；沿用已有查错范围，不把未查出错误当作正确性证明。

## 检索与先例比较

每题覆盖CPRet、arXiv和普通网页。查询围绕模型、关键观察和核心转化，不足时按疑点补查自然特例或变体。CPRet默认保留60条及全部组内成员，浏览完整索引后展开相关候选；题名不足以判断时读摘要或题意。相同参数复用成功缓存。

阅读最接近的原题、题解或论文相关正文，核对任务、关键约束、转化、算法、复杂度及适用条件，包括随机性与误差。回答“读过先例的人，还需独立发现什么”，给出覆盖步骤、新增思考、原文版本与位置。分数、服务分组和通用工具同名只作线索，别名须核实。正文错配或占位时转查官方来源或独立镜像，未展示内容不算已读，摘要与失败按实际范围记录。

## 等级判定

| 等级 | 判据 |
|---|---|
| A，原题 | 核心任务、关键约束及所需思考实质等价，主要是背景或常规参数变化。 |
| B，做法可套用 | 已有题目或论文的方法经常规调整即可覆盖整解，条件与可通过性成立。 |
| C，想法类似有帮助 | 先例的关键想法有实质帮助，仍需新的重要观察、转化或组合。 |
| C+，推导自然，推荐正式比赛 | 满足C的先例关系与新增思考要求，合适度和质量均有具体正面依据，关键推导自然、独立考点有价值，因此推荐用于正式比赛。 |
| D，完全新颖 | 本轮暂未找到经核实的实质性相似先例，按新颖判断，合适度或质量未达到F的要求，包括不能确认推导思维链足够好。 |
| F，又新颖又好 | 达到D的新颖性要求，并通过下述合适度与质量核验，适合竞赛出题，发现路径自然、考点鲜明，模型、证明和实现负担协调。 |

先按先例关系确定A、B、C或D，再对C/D进行合适度与质量核验，决定是否升为C+/F。原E已改为F，当前不设E级。C→C+、D→F保留原有新颖度关系，升级依据是合适度和质量。C+与F使用同一套核验标准，两者区别在于与先例的关系；C+的新颖度仍属于C，“+”表示有依据的正式比赛推荐。

两个方向采用不同的默认判断：**暂时没找到相似先例，就按新颖，以D为基础评级；不能确认推导思维链足够好，就按质量不足，不升为C+或F。** 不用“待定”替代这两项判断。

有已核实先例时，按最直接覆盖关系评为A/B/C，另说明有价值的新算法贡献。转化本身非平凡时计入新增思考，共用通用工具不足以降级。只有未核实的相似线索时，仍以D为基础，附线索及缺口。检索或阅读不完整本身不改判为待定，也不自动降低推导质量。仍执行约定检索，如实记录实际覆盖、失败和未读内容，不能将请求失败写成成功零命中。D/F限于本轮范围、时间及证据，不宣称全球原创。已确认A/B可先交付并注明剩余检索。

每次补搜或扩大阅读针对可能改变判断的疑点，在当前上下文核对最强相反解释。必要覆盖完成且A/B整题关系、C/C+的帮助与新增关键一步已核实，即可结束相应先例比较，D/F还须核对模型、核心转化及适用自然特例。C+与F还须完成下述合适度、质量核验。结果重复且无新线索时结束，不凑调用次数或默认多轮评审。置信依据来自覆盖与数学对应，不由重复一致或搜索数量替代。

## C+与F的合适度、质量核验

合适度判断题目能否形成有意义、可逐步推导、可实现的竞赛考点；质量判断条件是否自然、观察是否有价值、推导是否连贯，以及模型与算法、证明与实现负担是否协调。两者均依据现有题目与解法作初步判断。

说明必要知识假设，以具备这些基础知识的选手为参照，从题面和约束梳理“初始尝试—遇到的障碍—关键观察—转化与证明—可实现算法”，逐个核验关键步骤。阅读解法后重建的路径须标明，不冒充实际盲解经历；无需预先指定比赛、目标选手或开展盲测。

| 维度 | 需要核对的内容 |
|---|---|
| 实际考点与独立价值 | 先例已覆盖哪些思考，剩余观察能否形成值得出题的独立考点。各步骤是否推进同一核心问题，组合是否有内在联系，是否主要靠模板堆叠、重复技巧或机械分类增加负担。基础考点本身不构成不合适的理由。 |
| 发现动机与线索 | 题面、约束、例子或先前尝试如何提示下一步，关键猜想如何形成和验证。指出缺少动机的最大跳跃；自然不等于简单，困难但有充分线索的洞察可以成立。 |
| 前置知识与模板、论文依赖 | 列出外部结论与必要知识，区分可自包含推导和必须记忆的黑盒。模板或论文是否替代了主要思考，冷门结论是否有题内发现线索。技术陌生或难度高本身不判差，依据实际依赖和负担判断。 |
| 推导衔接与完整性 | 每个核心转化的前提、方向和作用是否清楚，关键引理、边界及复杂度瓶颈是否得到解释。区分“已证明正确”和“容易自然想到”，题解行文流畅不能代替发现路径的依据。 |
| 模型与条件的协调 | 约束、特殊条件和模型是否支撑核心观察，哪些条件为正确性或效率所必需，哪些只增加人为障碍。必要的技术条件不因不够简洁而直接判差。 |
| 证明、实现与收益 | 洞察收益是否与证明长度、分类、数据结构和实现细节相称，操作是否可落实，是否被无关特判、常数调优或繁琐收尾淹没。区分复杂度分析、实测和待标定，不以渐近式冒充实际通过；未实测不自动阻止初步判断。长证明、长代码本身不判差。 |
| 替代路径与实际考点 | 比较已知其他可通过做法的推导与实现成本，保留允许通过的慢解。更直接路线绕过预期观察时，重评实际考点、新颖度关系及升级依据；存在多解本身不否定质量。不以预期解的优雅掩盖主要可行解法的缺陷，也不要求穷尽所有算法。 |

分别给出合适度和质量的初步结论，逐维度提供材料位置或具体推导、优点、问题及未知项，再指出最强负面解释和决定升级的依据。两方面均有充分正面支撑，关键推导自然、独立考点有价值、负担协调，且没有影响竞赛适用性或整体质量的关键未决问题，才升为C+或F。不凑缺点，不用总分或多数维度通过掩盖核心问题。

合适度或质量不足时保留基础等级C/D，并说明具体影响。对推导思维链好不好拿不准，或支持合适度、质量的关键证据不足，都按质量不足处理。结论写“质量不足”，理由注明不确定的关键步骤或不足的证据，不另设待定状态。这是一项评级规则，不把不确定性改写成已经证实的数学错误或具体缺陷。

缺少盲测、未指定比赛或未实测本身不构成质量证据不足，现有材料和推导能支持判断即可。难度高也不自动判差。A/B不因合适或质量好而升为C+。发现实质错误或关键正确性疑点时记录，并按不足以支持升级处理。

## 交付结果

按以下顺序交付 `novelty.md`，内容与实际核验范围一致：

1. **结论**：A、B、C、C+、D、F之一及决定评级的理由。C+明确写“推荐用于正式比赛”，F写明新颖度、合适度和质量依据。保留C/D时明确说明不足，不能确认思维链足够好时也写“质量不足”并解释原因。
2. **材料与范围**：材料版本、来源、比较时点、已核验解法和必要知识假设。
3. **先例比较**：最接近的已读来源及位置、已有方法覆盖的步骤、仍需独立发现的内容。
4. **合适度与质量**：对C/D分别给出两项结论、发现路径、上表各维度的证据与判断、最强负面解释和升级或不升级的理由。A/B说明无需进入升级核验。
5. **证据与缺口**：实际搜索、阅读范围、附件路径及未核实事项。将观察到的缺陷与证据不足分别说明，即使两者都导致质量不足。

完整响应、查询及阅读范围另存证据附件，不重复整篇解法。最终回复简要给出等级、合适度与质量结论、决定性理由和报告及附件链接，不只列文件路径。

新颖度报告独立保存。C+的正式比赛推荐和F的升级均基于本轮初步合适度与质量；具体比赛安排、赛制适配、难度定级、区分度及做题预测留待后续，不作为升级所需的额外评测。10分制打分使用独立的 `review.json`，不写入新颖度等级或这两项初步判断。

## 工具使用

需要随包工具时，用本技能目录的 `scripts/cpscore.py`，从实际技能路径定位；源码中使用 `python3 -m cpscore`。命令均在 `novelty` 下，支持 `search`、`index`、`inspect`、`read`、`usage`，可先看对应 `--help`。工具负责证据保存和用量汇总，评级由当前模型依据已读内容判断。

工具记录耗时、缓存命中、返回字节及证据位置。调用端有usage时才统计实际模型用量，缺失项保持未知，不重复计算子集；字节不等于token或费用，工具耗时之和不等于墙钟。多题只传当前题所需上下文，完整历史留在文件。
