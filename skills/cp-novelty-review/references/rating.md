# 评级协议

## 等级判定

| 等级 | 判据 |
|---|---|
| A，原题 | 核心任务、关键约束及所需思考实质等价，主要是背景或常规参数变化。 |
| B，做法可套用 | 已有题目或论文的方法经常规调整即可覆盖整解，条件与可通过性成立。 |
| C，想法类似有帮助 | 先例替代了本题的非平凡关键步骤，仍需新的重要观察、转化或组合。 |
| C+，推导自然，推荐正式比赛 | 满足C，且通过下述合适度与质量核验。 |
| D，完全新颖 | 本轮未核实到实质先例，尚未达到正式比赛推荐标准。 |
| F，又新颖又好 | 满足D的新颖性要求，且通过下述合适度与质量核验。 |

先按最直接覆盖关系定A/B/C/D，再检查C/D能否升级。**C+与F质量标准相同，只因先例关系不同。** C即使质量再好也升C+，不能升F，当前不设E。A/B保留原级，另说明有价值的新算法及质量特点。

非平凡转化计入新增思考，通用工具或未核实线索不构成实质先例。D/F写“本轮检索按新颖评定”，不宣称全球原创。

## C与D的边界

先按题目与目标选手固定基础知识，梳理各可通过路线的关键推导，再比较先例，不随来源或预期等级调整基础范围。

判C须核实方法及条件的对应、替代的非平凡推导、省去的工作和剩余新增思考。相同图类、可达边界、贪心路径或中间构造不自动构成C，须排除本题条件下的常规建模与基础应用。论文身份和证明篇幅不决定非平凡性。

先例只覆盖基础步骤时，以 D 为基础再检查能否升 F。另一方面，不要求先例覆盖最终统计目标或整解才承认 C，替代任一已核实的非平凡关键步骤即可，剩余重要观察参与新增价值判断。

不同解法沿用同一基础口径，取已核实的最直接覆盖关系。评级变化须有新来源、新对应或具体判据纠正，不随叙述路线改变步骤的重要性。

## C+与F的合适度、质量核验

分别判断合适度与质量：前者看能否形成有意义、可逐步推导且可实现的竞赛考点，后者看条件、观察、推导及模型、证明、实现负担是否协调。

声明先修知识，重建“初始尝试—障碍—关键观察—转化与证明—可实现算法”并核验关键步骤，标明这是“重建推导”。不要求预先指定比赛、选手或开展盲测。

| 维度 | 需要核对的内容 |
|---|---|
| 实际考点 | 先例之外的思考是否有独立价值，组合有无内在联系，是否靠模板、重复技巧或机械分类增加负担。基础考点本身不判差。 |
| 发现线索 | 题面、约束、例子或失败尝试如何提示猜想与下一步，最大跳跃有何动机。自然不等于简单。 |
| 知识依赖 | 列明外部结论，区分自包含推导与黑盒记忆，判断模板或论文是否替代主要思考，冷门结论有无发现线索。 |
| 推导完整性 | 转化的前提、方向和作用，关键引理、边界及复杂度瓶颈是否清楚。正确性与发现难度分别判断。 |
| 条件协调 | 模型与特殊约束是否支撑观察，哪些为正确性或效率所需，哪些仅增加人为障碍。 |
| 收益与负担 | 洞察收益是否与证明、分类和实现成本相称，有无无关细节淹没核心。 |
| 替代路线 | 比较其他可通过做法及允许的慢解。若绕过预期观察，重评实际考点、先例关系及升级依据，不要求穷尽算法。 |

只展开影响评级的推导，将线索、独立考点与成本连成分析，不机械填表或凑缺点。合适度与质量均通过，推导自然、考点有价值且负担协调，才给C+/F。

保留C/D时说明具体跳跃、条件失调或收益与负担失衡。拿不准时先补推导或读替代解法，不把审查未完成写成题目缺陷。难度高、技术陌生、长证明、长代码、未实测或多解本身不判差。

## 影响评级的疑点与修复

定位断言、上下文与影响，排除误读并尝试局部修复。补证、纠正符号或拼接后核心算法与复杂度不变的，写出修复推导并据此评价。若需要新关键引理、算法或条件，明确新增工作，不当作已完成修复。反驳须给具体推导或反例。

分别判断证明、结论、算法和题目质量。文字或证明错误不自动阻止 C+/F，拒绝升级前检查已知替代路线能否绕过缺口。未补出的命题不算已证伪，无需穷尽算法或审计全部代码。
