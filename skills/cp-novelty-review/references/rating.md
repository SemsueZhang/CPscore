# 评级协议

## 等级判定

| 等级 | 判据 |
|---|---|
| A，原题 | 核心任务、关键约束及所需思考实质等价，主要是背景或常规参数变化。 |
| B，做法可套用 | 已有题目或论文的方法经常规调整即可覆盖整解，条件与可通过性成立。 |
| C，想法类似有帮助 | 先例替代了本题的非平凡关键步骤，仍需新的重要观察、转化或组合。 |
| C+，推导自然，推荐正式比赛 | 满足C的先例关系与新增思考要求，合适度和质量均有具体正面依据，关键推导自然、独立考点有价值，因此推荐用于正式比赛。 |
| D，完全新颖 | 本轮检索按新颖评定，推导自然性、独立考点或负担协调尚未达到正式比赛推荐标准。 |
| F，又新颖又好 | 达到D的新颖性要求，并通过下述合适度与质量核验，适合竞赛出题，发现路径自然、考点鲜明，模型、证明和实现负担协调。 |

先按先例关系确定A、B、C或D，再对C/D判断合适度与质量。等级映射固定如下：

| 先例关系 | 合适度、质量均通过 | 未达到升级标准 |
| --- | --- | --- |
| A | A | A，另说明具体问题 |
| B | B | B，另说明具体问题 |
| C | C+ | C |
| D | F | D |

**C+与F使用同一套质量标准，区别只在先例关系。** 先例关系为C时，质量再好也给C+，不能因“更好”升F，也不能用“存在质量风险，所以停在C+而未到F”解释评级。当前不设E级。

有已核实先例时，按最直接覆盖关系评为A/B/C，另说明有价值的新算法贡献。转化本身非平凡时计入新增思考。仅有通用工具或未核实线索时，按D作为基础关系，再判断是否升F。D/F写“本轮检索按新颖评定”，不作全球原创断言。

补搜和扩大阅读针对可能改变判断的具体问题。A/B整题关系、C的关键复用与新增思考核实后即可结束相应比较。D/F另核对模型、核心转化与适用自然特例。结果重复且没有新线索时结束，不凑调用次数或默认多轮评审。

## C+与F的合适度、质量核验

合适度判断题目能否形成有意义、可逐步推导、可实现的竞赛考点。质量判断条件是否自然、观察是否有价值、推导是否连贯，以及模型与算法、证明与实现负担是否协调。两项分别给出明确判断和具体原因。

说明必要知识假设，以具备这些知识的选手为参照，重建“初始尝试—遇到的障碍—关键观察—转化与证明—可实现算法”，逐个核验关键步骤。阅读解法后重建的路径标明“重建推导”。具体比赛、目标选手和盲测不是前置要求。

| 维度 | 需要核对的内容 |
|---|---|
| 实际考点与独立价值 | 先例已覆盖哪些思考，剩余观察能否形成值得出题的独立考点。各步骤是否推进同一核心问题，组合是否有内在联系，是否主要靠模板堆叠、重复技巧或机械分类增加负担。基础考点本身不构成不合适的理由。 |
| 发现动机与线索 | 题面、约束、例子或先前尝试如何提示下一步，关键猜想如何形成和验证。指出缺少动机的最大跳跃；自然不等于简单，困难但有充分线索的洞察可以成立。 |
| 前置知识与模板、论文依赖 | 列出外部结论与必要知识，区分可自包含推导和必须记忆的黑盒。模板或论文是否替代了主要思考，冷门结论是否有题内发现线索。技术陌生或难度高本身不判差，依据实际依赖和负担判断。 |
| 推导衔接与完整性 | 每个核心转化的前提、方向和作用是否清楚，关键引理、边界及复杂度瓶颈是否得到解释。结合补证和替代路线评价方法，区分“已证明正确”和“容易自然想到”。 |
| 模型与条件的协调 | 约束、特殊条件和模型是否支撑核心观察，哪些条件为正确性或效率所必需，哪些只增加人为障碍。必要的技术条件不因不够简洁而直接判差。 |
| 证明、实现与收益 | 洞察收益是否与证明、分类和实现成本相称，核心是否被无关细节淹没。复杂度与实测各按实际结果判断，长证明、长代码或未实测本身不判差。 |
| 替代路径与实际考点 | 比较已知其他可通过做法的推导与实现成本，保留允许通过的慢解。更直接路线绕过预期观察时，重评实际考点、新颖度关系及升级依据；存在多解本身不否定质量。不以预期解的优雅掩盖主要可行解法的缺陷，也不要求穷尽所有算法。 |

质量分析只展开影响评级的关键推导，将发现线索、独立考点和实现成本连成分析，常规步骤概述即可。不要逐项填表或凑缺点。合适度与质量均通过，关键推导自然、独立考点有价值、负担协调，才给C+或F。

保留C/D时，直接说明关键跳跃缺少什么发现线索、哪项条件与方法不协调，或实现负担为何与收益失衡。拿不准的步骤先补推导或读替代解法，不以自身未完成的工作替代题目质量判断，不为保留基础等级编造缺陷。未指定比赛、缺少盲测、未实测、难度高或代码长，本身不判差。

A/B仍简洁分析实际考点、推导与实现特点，最终等级由已有的整题关系决定，不进入C/D升级核验。
