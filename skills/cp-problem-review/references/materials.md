# 材料分项审核

材料分项采用 `10 − 10×Fatal数 − 2×Major数 − Minor数`，允许负分，只扣已确认的独立根因。同一缺口的多个后果取最高级别扣一次，按影响而非修复难易定级，疑点不扣分。

- **Fatal −10**：题意或判定无法确定、样例实质错误、算法或实现错误，以及计分输入非法、答案错误、判定错误或实质资源违例。
- **Major −2**：关键证明有实质缺漏，或重要非致命质量问题。题解的冗余、衔接、防御性表达使读者需重建核心推导，std 缺少核心记号、状态、更新依赖、阶段或接口对应时，在此判断。
- **Minor −1**：局部文字或说明缺陷，以及不破坏核心理解的局部阅读障碍。

算法错误与证明缺漏分别判断。公认结论、合理常规省略、篇幅和文风偏好本身不扣分。数据漏网须有已证错候选及原集实际额外成绩。

## 题面要求

- 正文独立定义输入域、对象、操作、顺序和目标，背景应帮助理解，不用样例或隐藏的作者意图补规则。明确子串与子序列的连续性、空对象是否参与统计，以及“本质不同”等等价关系。
- 输入逐行或逐段交代类型、数量和含义，多测说明组数、组内结构及适用的总规模约束。必要范围有上下界，字符串有字符集，实数输入有小数位说明，类型与范围一致。
- 输出说明合法结果和判定口径，多解、无解、浮点误差及特殊判题均有明确约定。需要取模时，在描述和输出两处说明，不能只依靠样例表现推测。
- 原则上给出全部数据的范围。说明部分分条件、分值及依赖，已有继承条件可以省去重复范围，百分比不能混淆累计覆盖与另外一组。捆绑测试需加粗声明。
- 正式样例逐个核对输入合法性、输出可接受性及解释。多语言版本完整独立可读，术语、约束和判定一致，不夹带无关内容。人名或自创词可在不影响理解时保留并说明，远程评测题标题通常保留原文，已有知名书籍译名可作例外。
- 时空上限原则上至少为参考程序最坏资源用量的 1.5 倍，不宜明显过紧或过宽。结合环境与最坏情况依据判断，不能用普通样例实测代替。未提供 std、实测或译文原文时，说明对应未核验范围，不推定违规。

## 题解要求

- 解释主要算法、数据结构、关键转化及使用方式，给出重要结论的证明与完整复杂度，覆盖全部约束。合理先修知识与常规步骤可省略，核心证明缺失按 Major，算法被可靠反例或论证推翻才按算法错误处理。
- 正文完整说明核心解法，代码、注释、视频及外链只能补充，不能代替文字分析。内容应围绕题目，不完整复制题面或堆砌大量无关闲聊，长题面附简述属于建议。
- 通常给出必要代码或核心片段。纯文字已充分清晰且无额外实现说明价值时，可说明例外理由。代码应可读且与算法一致，不加入防抄袭干扰内容。
- 图示应清楚，图中文字遵守格式要求，不额外套无关跳转链接。图片随材料提供或使用稳定、可访问的地址。支持折叠的 Markdown 发布环境中，长代码用折叠块，不能只给临时云剪贴板链接。

## 表达与格式要求

| 项目 | 本协议要求 |
| --- | --- |
| 中文与间距 | 使用全角中文标点并补全句末标点。中文与英文、数字或公式之间留半角空格，中文标点旁不额外加空格。 |
| 变量与数学模式 | 数学量、运算和相关常数使用 LaTeX，普通词语、题名、人名、算法名不用数学模式。同一对象的名称、变量大小写和术语一致。 |
| 输入输出展示 | 并列输入变量写在同一数学环境，同类句式统一。固定输出字符串用行内代码，取模要求在描述与输出两处交代。 |
| 范围展示 | 类型放在输入说明，范围通常集中在说明或提示。有效位较少且不小于 $10^5$ 的数使用科学计数法，不同范围分公式并以全角逗号隔开，相同范围可合并。无部分分时，某变量的范围可放在输入格式。 |
| Markdown | 标题用于组织层次，Markdown 稿件采用一至四级标题。列表使用相应标记，字符串和行内程序片段用行内代码，成段代码用代码块，链接和图片按相应语法插入。 |
| 公式环境 | 一个数学表达式放在同一数学环境，独立公式用行间环境。公式内说明文本和字符串分别用 `\text`、`\texttt`，正确组织上下标。 |
| 数学与程序记法 | 公式中的赋值用 `\gets` 或 `\to`，推导用 `\Leftarrow` 或 `\Rightarrow`。判定使用数学关系，整数商明确取整，取模用 `\bmod`，同余用 `\equiv` 与 `\pmod`。不用程序判等、取模或结构体成员语法代替数学表达，代码块中的合法程序语法除外。 |
| 位运算与函数 | 位运算用 `\operatorname{and}`、`\operatorname{or}`、`\operatorname{xor}`。约定函数名用正体，其他函数名用 `\operatorname`。使用正确的分数、根号、集合、大型运算符、省略号及 `\sim`。 |
| 多行公式与复杂度 | 连等推导、分段函数、矩阵分别用 `aligned`、`cases`、`bmatrix`。大数用科学计数法，大 $O$ 省去常数因子，以字母表示需要讨论的值域等参数，不能省略真实变化的参数。 |

明确格式违规至少为 Major −2，即使语义可恢复也不能降为 Minor。严重排版错误使核心题意、算法、证明或判定无法可靠辨认时，可为 Fatal −10。同一格式规则多处违反合并扣一次，语义与格式后果只取最高级别。中文序号、子任务表格或无序列表、集合语言及代码前引用等建议形式，未采用不直接扣分。

## 来源与证据

引用他人的文字、图片、代码或特有推导时给出来源链接并遵守已知授权条件，公认结论和标准算法的常规使用不机械要求外链。

审核明确包含投稿来源资格时，核心思路、论证和代码不得由 GenAI 辅助产生，允许的排版、润色辅助须在文末或附录说明具体贡献，作者应核查全部内容。已证实的抄袭、侵权复制或违反核心内容来源限制为投稿资格的 Fatal，漏引用链接或允许的辅助未按要求披露为 Major，不据此宣称算法错误。该项不扩张到其他用途或审核工具。AI 辅助翻译应声明并经人工校对。

来源判断须有可靠材料，不能凭文风、相同标准公式或缺少创作记录推定违规。PDF、截图和节选能支持的显示核验与不能支持的源码、折叠、授权或创作过程核验分别说明。

## 复用与完成状态

复用评审前核对材料版本、适用规范、证据与未完成范围。旧建议不等于修复，修改后的材料须有对应复核依据。缺少执行或数据时先完成可核验部分，不把未知当作通过。
