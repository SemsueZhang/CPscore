# 汇总规则

## 汇总规则

正确性分项如需评分，从10分起，只扣已确认的独立根因：Fatal −10、Major −3、Minor −1，最低0分。算法或答案实际错误为Fatal，算法仍正确但关键论证有实质缺漏或存在重要非致命质量问题为Major，有实际影响的非关键局部问题为Minor。同一根因取最高级别扣一次，不按修复难易分级。9～10分对应推荐，6～8分对应合格，0～5分对应不合格，疑点不扣分。

新颖度A/B对应不合格，C/D对应合格，C+/F对应推荐。设计各项也分别判断推荐、合格或不合格。

**总评取所有适用审查结果和设计判断的最低档，不平均、不投票。** 关键项未完成或有未决正确性疑点时，明确总评尚未完成，不能给合格或推荐。已有确认的不合格项时可以判不合格，同时指出剩余未完成范围。不能无理由省去较低结果。

单独判断原做法是否适合竞赛。原做法不适合时，只有已核验更简单替代做法的全范围正确性、复杂度和竞赛适合度，才允许这一项判为合格，并提出更新材料的意见。这不提高其他独立不合格项，也不修改原评审结果。同一适合度问题不要在别的维度换名重复判差。
