# 解法空间与设计

- **解法空间**：分析自然尝试、障碍、更简单路线、非预期解和漏洞，核验可行路线的正确性及全范围复杂度。
- **子任务**：检查特殊条件和分值能否形成有意义的进阶，各做法可得哪些分数，有无意外跳档或错误依赖。无需部分分时说明理由。
- **满分路线与设计**：发现线索、知识、证明和实现负担是否协调，条件是否支撑有价值的观察，限制是否误伤合理正确解。难、代码长或多解本身不判差。

需要新颖度评价时，用宿主检索并阅读最接近的原题或论文，比较任务、条件、可复用步骤与剩余独立思考。未检索不算完成，也不宣称全球原创。

新颖度按先例关系定A/B/C/D：整题实质等价为A，常规调整可套整解为B，替代非平凡步骤但仍需重要新观察为C，本轮未核实实质先例以D为基础。C/D在合适度与质量均通过、推导自然、考点有价值且负担协调时分别升C+/F。两者质量标准相同，通用算法标签不构成C。

比较前明确基础知识与各可通过路线的关键推导。判C须指出先例在此基础下省去的具体非平凡推导，常规建模、相同中间构造或贪心路径不自动构成C，也不要求先例覆盖最终统计或整解。不同路线沿用同一口径，评级变化应说明新增对应关系或对原判断的纠正。

对疑点尝试补证、反驳或局部修复。未证实疑点不当作缺陷，有限测试不构成一般证明，未找到替代解不等于不存在。修订方案须保留题目原有约束与目标，若需改变关键条件则说明设计变化，不能当作原题已修复。
