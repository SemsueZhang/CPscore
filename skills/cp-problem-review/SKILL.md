# 题目总评

读取题面、全部声明正确的做法、题解、std、约束、子任务、数据及已有评审。独立审核或复用可靠评审，不依赖其他技能。

## 流程与 Reference

1. 按[材料分项审核](references/materials.md)核验规格、样例、证明、实现、数据与适用规范。复用已有评审时先核对版本、证据、修复状态及覆盖范围。
2. 按[解法空间与设计](references/design.md)分析可通过路线、子任务及思考收益与负担；需要新颖度时再展开其中的检索和评级规则。
3. 按[总评协议](references/assessment.md)汇总适用分项与设计判断，保留较低结果。针对确认问题给出局部修订及必要复核，不把更简单替代路线或修改建议视为所有问题已解决。

## 交付

默认在对话输出 Markdown，仅用户要求保存时写报告，不另建中间记录。先给题名、总评及决定性理由，再以材料问题、解法空间和设计分析支撑结论，最后给修改建议。已有分项可用简表汇总。

引用具体材料与必要推导，说明缺数据、检索或执行条件造成的具体未完成项。未决问题与可选优化分开，不伪造实测或把建议当作已修复。
