# 题解审核

读取题面、约束、完整题解及其中全部声明正确的做法，固定目标读者与适用投稿规范。只依据原稿裁定，不替作者补条件、改算法或补关键证明。全程由机器判断，不设人工步骤、其他 Skill 或独立子 Agent。

## 内容与格式分开审核

1. **内容审核**：按[数学与内容核验](references/verification.md)一次顺读，逐项检查实质声明的前提、依据、正确性及用途，确认原文能覆盖整个输入域、数值范围和总成本；逐步手算文字样例，代码只作一次静态对照。按[教学与表达审核](references/pedagogy.md)检查人类思维、表达缺陷和全文题外内容；多类显著机械化迹象共同出现时，明确报告“本文大概率由 AI 生成”及文本依据。
2. **格式审核**：另按[共用格式协议](references/format.md)运行下节脚本。LLM 负责脚本未覆盖的部分，既裁定候选，也主动检查未被报告的原文；可新增及重新归类格式发现，再由脚本合并、去重和定级。脚本没有发现或格式已足以拒绝，都不代替内容审核。
3. **分别结论后汇总**：按[覆盖记录与重审](references/verification.md#覆盖记录与重审)核对遗漏和结论变化，再按[评分协议](references/scoring.md)合并同根因、给总分和合规结论。内容至少覆盖声明与证明、全题覆盖、样例过程、人类思维、表达及题外内容；不适用项说明原因。发现足以拒绝的问题后仍完成其余适用项，不用格式发现数量表示内容覆盖程度，不增加多轮投票或重复代码验证。

## 格式检查与机器复核

先确认有命令执行能力和已有 Python 3，解析到本 Skill 目录后运行：

```sh
python3 scripts/format_lint.py --check
python3 scripts/format_lint.py /path/to/editorial.md
# 需要 LLM 复核时，按核验协议生成临时 JSON 后合并：
python3 scripts/format_lint.py --decisions /tmp/review.json /path/to/editorial.md
```

环境要求 Python 3.8+，只用标准库，不安装依赖、不要求额外配置。多个 Markdown 可一次传入，逐文件定级；需要查看规则时运行 `--rules`。题面与题解随包提供同源脚本和格式协议，使用相同规则，不依赖另一个 Skill。

读取 JSON 的 `status`、`errors`、`files_checked`、`linter_version`、`render_model` 与 `format_assessment`。其中 `groups` 已按规范类别和独立位置去重计数，1～2 处 Major、至少 3 处 Fatal，同类只扣一次。它只计算格式扣分，不编辑原文或计算最终题解总分。

`Confirmed` 可直接计分。LLM 按[复核接口](references/format.md#llm-格式复核接口)确认或排除警告、检查跳过范围，并提交有原文位置和依据的补充发现，不重复评价脚本已确定的项目。未能核实的项保持未确认，不能凑成三处 Fatal。脚本不调用模型、不接受外部指定次数或级别，也不允许通过复核接口撤销静态 Confirmed。

没有可用 Python 时，LLM 继续检查能取得的源码和可见材料，按评分协议记录证据和计数，不安装环境。只有 PDF／截图不能证明 Markdown 源码语法合规。工具故障本身不属稿件错误；剩余材料或核验缺口按严格通过规则处理。覆盖边界见[工具说明](references/format.md#格式工具的覆盖与边界)。

## 交付

默认直接回复 Markdown，仅用户要求保存时写报告；不改原稿，复核 JSON 可临时创建。以 `# CPScore · 题解审核` 开头，先给合规结论、分数及档次。

总结果后分别给出**内容审核**和**格式审核**。内容问题列级别、位置、短摘录、失效依据、影响及最小修改方向；指出到底缺哪一条件、分支或推理，不代写完整解法或证明。人类思维检查给受阻步骤或支持通过的阅读依据，样例列实际手算过程及未完成范围。AIGC 倾向与具体表达缺陷一并说明，概率判断不冒充来源确证，也不另设一项重复扣分。

格式引用合并后的类别、Confirmed 次数、级别及代表位置，区分静态证据与 LLM 裁定；未确认范围单列。不要用“数学排版不规范”等总括语代替具体结果，也不将同一格式问题再次包装成教学扣分。

无问题无需强行删改，仍概述各必查范围的依据。重审注明新增、撤销及改级理由。说明实际材料、脚本版本与执行范围；静态代码对照不代表编译、实测或评测通过，源码格式检查也不代表目标页面已实渲染。
