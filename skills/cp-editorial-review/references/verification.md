# 论证与表达核验

以题目预期的先修知识为基准。审查者能补出解释，不等于原稿已表达清楚。

- 沿算法、引理、不变量和证明的依赖检查量词、条件、必要与充分方向、归纳、边界、交换与计数。复杂度包含预处理、查询及数据结构的最坏开销。
- 对证明疑点尝试补证或反驳，区分算法被推翻、结论成立但关键证明缺漏、合理的常规省略和尚未裁定。以预期先修知识判断哪些步骤可直接补出。
- 沿阅读顺序检查定义、转化动机、推理联系及算法与证明的对应。定位冗余、无关细节、防御性表达、记号或指代如何遮蔽核心推导或妨碍局部阅读。

指出原文、受阻步骤及其核心或局部影响，建议具体到删减、合并、移位、补定义或建立联系。不按字数、句长、措辞、重复次数或修复行数定级，也不强制顺序、图示、例子或标准算法的从零推导。适用条件、边界、易混点和诚实的不确定性说明按其信息作用判断，谨慎语气本身不是赘述。删改应保留关键前提与论证。

用题面和实现交叉核对，不默认其正确。必要的小检验使用宿主工具，有限测试不替代证明。缺少规格时只能核验内部推理，未执行的检查如实说明。
