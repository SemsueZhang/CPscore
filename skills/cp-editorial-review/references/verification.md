# 数学与内容核验

按交付材料审核。未说明节选时，不因截图／从中间开始而假定前文补齐定义或主线；明确节选则限定范围。外部材料不足与原文可确认的讲解缺陷分开。

## 声明、依据与完整解法

对照原题检查稿内转述、约束、取模、复制样例和方案范围的改变／遗漏，不强求题解重抄题面。

核验各做法的性质、方法、不变量、证明、成本及优化声明的**前提、原文依据、有效性和用途**；同段独立声明分别查。公认事实、一步推导可省，题目特有联系须原文交代。

| 核查对象 | 关键核验 |
| --- | --- |
| 定义与指代 | 状态、非标准函数、聚合量各自作用于什么对象；下标、范围、更新时刻及后续用途是否一致。`sum(j)` 即使函数名常见，也须能确定对哪些对象的哪个量求和；换成求和符号不能补足对象定义。上下文已经明确时不要求重复释义。 |
| 数学结论 | 逐项核对等式、不等式、等价变形、量词、必要与充分、取整及计数，检查边界或手工反例。区分结论为假与原文未证明。 |
| 原文论证 | 归纳、交换、贪心、状态转移和不变量是否支持所声称的结论；题目特有的非平凡联系是否缺失或循环论证。 |
| 完整方法与覆盖 | 仅据原文复述状态、初始化、操作／转移与终止，对照声明范围内的全部合法输入；检查最小／最大参数、零值、重复、空对象及特殊结构等相关边界。不得代补分支、条件、初始化或更换算法后判原稿成立。 |
| 总成本与优化 | 分别计算预处理、状态数、各独立枚举、单步、全部查询和多测总量；将约束上界代入实际工作量与空间需求。核对原文给出的计数、单步代价与大 $O$ 结论是否对应。若表达式本身是有效上界，但原文声称它由某推导得到、该推导实际给出不同结果，记录为复杂度表述与推导脱节，不将其说成大 $O$ 符号或上界本身错误。仅上界较松而推导仍成立时不扣分；另一算法的性能不能替原文作依据。 |
| 数值范围 | 检查中间乘积、累加、差值、移位、取模前计算及类型转换，不能只查最终答案。查询／二分判定中即使未使用的计算，只要仍会执行，也核对数值安全。 |

部分分按声明子范围核验；超时、卡常、不能通过和附录方案仍检查数学、论证、成本与代码。明确展示的错解核验错因、反例及其余声明，不要求修成正确解。未核实的分数、通过记录及“只是卡常／仅因 TLE”标为作者自述或待核验。

数学结论、原文论证、代码及实际通过分开判断。必要时推算或手工反驳，指出缺口与后果，不代写完整解法。正文须独立讲清核心分析；实现无额外信息可不附代码，代码／注释／外链仅补充。

例如，每个 $k$ 对应 $2^k$ 个余数类，因此询问种数按 $\sum_{k=0}^{\lfloor\log_2 n\rfloor}2^k$ 计为 $O(n)$，原文却称为 $O(n\log n)$。后者仍是有效的松上界，但不是该计数推导所得的结果。若原文把它表述为推导结果，应记录为复杂度表述与推导脱节，若只是明确采用更松的上界且推导相符，则不因不紧扣分。

## 代码静态对照

静态顺读每份实现，对照状态、操作、循环／数组边界、初始化／清空、类型、异常及输出，检查作用域、容器索引和修改后结构有效性。明确片段不强求程序外壳，完整提交检查定义／语法；正确输出不消除正文／注释错误。

具体疑点与覆盖空项定向回查，溢出／漏分支与对应覆盖根因依[评分协议](scoring.md)合并。

除用户另行要求代码验证外，不编译、运行、造小数据或对拍，也不启动求解流程；格式脚本除外。

## 文字样例逐步手算

逐一手算样例解释、操作序列、图中演示及正文举例的初始条件、每步合法性、状态更新、中间值和结果，对照原文各步声称。最终输出正确不能证明过程正确；未给过程时核验结论，不强制补简单步骤。

图示或样例未取得、过程未核完时，注明受影响范围。

## 全文、图片与来源

查首尾、标题、附注、图片、代码注释中的题外话、求赞／通过、自我介绍、广告和无关叙事，删除线、折叠和围栏同审。必要引用、贡献披露、动机、边界和背景按用途保留；表达见[教学](pedagogy.md)，等级见[评分](scoring.md)。

另查错漏字、语法、搭配、指代和衔接，摘具体病句及缺词／混用／歧义；“讲解不清”不覆盖全部文字问题，与概念缺失同根因合并。

确认图片清楚且可取得；引用他人文字、图、代码或特有推导须可追溯，不从缺链接推定抄袭，标准算法不强制外链。不整篇复制长题面，检查代码可读性及防抄袭干扰。

投稿平台设有 AI 辅助创作资格或披露要求时，对照适用条款和作者声明、生成记录等直接证据核验来源合规。

## 覆盖记录与重审

按[覆盖协议](coverage.md)为每种做法的上述维度、重要声明、实现和样例分别建项。正向核对条件到结论，逆向从结论和代码反查前提、边界及反例，记录实质依据。阅读与已启用的格式任务各自交付结果，覆盖检查发现空项后定向补查。

撤销或改级保留原文证据，重复发现合并位置与影响。重审说明新增、撤销和改级依据。独立评测隔离历史结论。
