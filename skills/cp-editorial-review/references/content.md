# 数学与内容核验

按交付材料及明确的节选范围审核。截图或中途开篇，按实际可见的定义与主线核验。分别记录材料缺失和已确认的稿件缺陷。

## 声明、依据与完整解法

核对题意转述、约束、取模、引用的样例和方案适用范围。以题面作参照，允许题解省略已有说明。

按熟悉相关先修知识的竞赛读者理解全文，依据题面、上下文和竞赛惯例确定术语、指代及简写。公认事实和可确定的常规推导可省略。

从题目条件、原文定义及已有结论独立推演每个定理、性质、引理、不变量、复杂度和优化声明。同段独立声明逐条查，省略证明时仍推演。分别判断结论真假、原文推导是否有误、论证是否充分。需另行补出非显然推导时，记录原文位置、已有前提、未建立的结论及所缺依据。

核验原文操作、公式和条件的实际后果。反例遵循原文给出或可确定的步骤。审核者新增的变换、条件或分支只作修订建议。订正后复核推导，按[量规](rubric.md#内容定级)定级。

例如，P10008 的题解写用区间取 $\max$ 求最小右端点。直接取 $\max$ 会让去重判断使用错误的端点，正文定义的目标量可确定应写 $\min$。先取负再取 $\max$ 是可行的修订写法，只有原文给出取负依据时才能据此解释作者的步骤。

例如，题解描述双指针算法并直接报 $O(n)$，若线性界依赖内层循环的摊还分析，应说明右指针为何跨外层迭代不回退、其可达范围及每次推进的代价。若原文已说明外层枚举 $n$ 次、每步为常数开销，且右指针始终在 $[1,n]$ 内单调前进，则线性界可直接推出，可省略单列证明。

| 核查对象 | 关键核验 |
| --- | --- |
| 定义与指代 | 核对状态、函数、聚合量的对象，以及下标、范围、更新时间和用途。`sum(j)` 须能确定对哪些对象的哪个量求和，换符号仍须具备该定义。 |
| 数学结论 | 逐项核对等式、不等式、等价变形、量词、必要与充分、取整及计数，检查边界或手工反例。区分结论为假与原文未证明。 |
| 原文论证 | 归纳、交换、贪心、状态转移和不变量是否支持所声称的结论；题目特有的非平凡联系是否缺失或循环论证。 |
| 完整方法与覆盖 | 按原文复述状态、初始化、转移及终止，对照声明范围内的全部合法输入，包括最值、零、重复、空对象及特殊结构。逐个核验原文方案的条件、分支和初始化。 |
| 总成本与优化 | 按题面核算预处理、状态数、各独立枚举、单步、查询及多测总量。核对实际描述的操作与复杂度推导。有效松上界及复杂度简写按[量规](rubric.md#内容定级)核定。 |
| 数值范围 | 检查中间乘积、累加、差值、移位、取模前计算及类型转换，不能只查最终答案。对题解描述会执行的计算，即使结果未使用，也核对数值范围。 |

部分分按声明范围核验。超时、卡常、未通过及附录方案仍查结论、论证和成本。明确展示的错解核验错因、反例及其他声明。分数、通过与卡常等未经核实的结论记作者自述或待核验。

正文应独立讲清核心分析，代码、注释及外链可作补充。报告定位缺口与后果，给局部改法即可。数学结论、证明、实现与实测分别核验。

## 代码静态对照

仅在明确启用时静态顺读每份实现。查状态、操作、循环／数组边界、初始化／清空、类型、异常、输出、作用域、容器索引与更新后的结构有效性。片段按所示范围，完整提交也查定义和语法。正文与注释按各自证据核验。

资源开销仅核对渐进时空复杂度。报告不一致时给具体代码、合法输入及复杂度依据。递归 DFS 在链上达到 $O(n)$ 调用空间，可反驳 $O(1)$ 声明。常数、评测时限和栈容量不计作代码错误。

除用户另行要求代码验证外，不编译、运行、造小数据或对拍，也不启动求解流程；格式脚本除外。

## 文字样例逐步手算

逐一手算样例解释、操作序列、图示演示和正文举例，核对初始条件、每步合法性、状态、中间值及结果。只给输出时核验结果。图示或过程未核完，注明范围。

## 全文、图片与来源

确认图示清楚可取得。查整篇复制长题面，以及引用的文字、图、代码或特有推导能否溯源。标准算法可省引用，抄袭结论须由证据支持。启用代码审核时另查可读性和防抄袭干扰。

AI 使用或披露本身不构成 CPScore 缺陷，也不产生待核验项。平台创作资格和披露要求按[审核范围](../SKILL.md#审核标准与范围)决定是否另行核验，裁定须有作者声明、生成记录等直接证据。

## 教学与阅读路径

目标读者读过题面并掌握先修知识，对本题解法尚不熟悉。沿原文检查目标、量的含义与用途、各步推导及其如何得到答案。重点核验本题特有的联系，报告具体缺口与影响。信息组织与阅读负担按[文风](writing.md)在启用时核验。

按[对象协议](../SKILL.md#审核对象与记录)为每种方案、重要声明和样例建项。无附件或无相应结构等情况按对象给出不适用依据。
