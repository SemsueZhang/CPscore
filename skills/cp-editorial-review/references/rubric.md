# 分级与评分

## 内容定级

| 等级 | 适用情形 |
| --- | --- |
| **Fatal −10** | 核心算法或关键结论错误，关键正确性／可行性声明缺乏有效原文依据，或实际复杂度已证实不可行；遗漏合法输入、边界或数值处理（含溢出、擅自缩小参数域），或正文关键方法不明且无实现可对照；无法建立目标、方法与答案之间的解题主线，或须重新发现非平凡联系、重组信息才能理解推导。已证实的抄袭、侵权复制或有直接证据的核心内容来源资格违规也属此级。 |
| **Major −2** | 未触及 Fatal 的非核心依据、必要引用或辅助声明缺失；冗余、自辩、叙事拖延等造成显著阅读负担，或其他投稿规范违规。文风按下节影响分级。 |
| **Minor −1** | 局部错字、语言障碍、冗余、说明缺漏或非关键论证／算例错误，核心主线仍清楚，且不触及更高等级。 |
| **不扣分** | 公认事实与常规推导的合理省略、完整简洁的解法、允许写法、合理例外、可选建议及个人审美／篇幅偏好。 |

例如，已给区间排序及并集公式，但未说明 Treap 如何合并可能交错的编号，属于局部说明缺漏，计 Minor。

只有公式、数组、循环或算法名，仍不知在求什么、为何得到答案，或须重新发现非平凡联系才能理解，适用核心理解障碍 Fatal。

例如，每个 $k$ 对应 $2^k$ 个余数类，因此询问种数按 $\sum_{k=0}^{\lfloor\log_2 n\rfloor}2^k$ 计为 $O(n)$，原文却称为 $O(n\log n)$。后者仍是有效的松上界，但不是该计数推导所得的结果。若原文把它表述为推导结果，应记录为复杂度表述与推导脱节，若只是明确采用更松的上界且推导相符，则不因不紧扣分。

核心声明或覆盖缺失不按局部说明缺漏降级。理解障碍须定位受阻步骤，与算法错误分别标明。审核者能补出、已有代码或容易修复不改变其 Fatal 级别。较松但有依据的上界不因不紧受罚。

成段题外煽动或表演、低俗配图、明确涉黄／涉赌／涉毒内容，以及与题目无关的现实政治宣传、动员、攻击和影射，直接 Fatal，明确说明不能作为稿件提交；正常背景、历史语境、教育讨论、抽象概率游戏和必要引用不按敏感词处罚。简短求赞、求通过等轻微题外话通常 Minor。批评具体内容，不辱骂作者或作法律认定。

## 阅读与文风计分

按[文风与阅读问题](writing.md)定位具体机制，以实际影响定级。

| 等级 | 阅读影响 |
| --- | --- |
| **Minor −1** | 局部冗余、表达不自然或较小阅读障碍，主线仍清楚。 |
| **Major −2** | 显著冗余、主次失衡、防御性表达等增加阅读负担，需反复查找有效信息。 |
| **Fatal −10** | 关键方法或规则无法可靠理解，须重新发现重要联系或重组核心内容才能理解。 |

循环说明、信息倒置和长篇低信息密度均按实际依赖与阅读影响判定。类别用于定位，篇幅和命中类别本身不决定扣分。已确认问题直接按协议计分，同根因及其阅读后果合并，独立原因分别计。文风列入“内容问题”。

## 格式计数与定级

以合并后的 `format_assessment` 计分，不另设格式满分，类别按脚本 `CATEGORIES`：

| 同篇同类已确认独立位置数 | 定级 |
| --- | --- |
| 0，无未确认范围 | 不扣分 |
| 1～2 | Major −2，一次 |
| 至少 3 | Fatal −10，一次，不叠加 Major |

同一缺失声明只算一处。正文／公式边界缺空格同类，缺与多空格不同类；同一边界多分支命中只算一次，公式两侧各缺则算两处。不同文章、同路径重复传入不累计凑数。

Warning、未支持语法及未验证范围保留为未核验，不计已确认次数或稿件扣分。Linter 的 `Unverified` 定级仅表示待裁定状态，最终格式扣分取 `format_assessment.groups` 中 `basis=Confirmed` 的类别；有剩余必查缺口则报告审核未完成。

长代码折叠仅建议，不计错误、未确认范围或扣分，也不改归其他类别。

## 计分与去重

`评分 = 10 − 10×Fatal数 − 2×Major数 − Minor数`。

同对象、同错误机制及其数学／规格／阅读／代码／格式后果取最高级一次；不同独立原因分别计。以针对机制的**最小必要改动**判断独立修复，整段重写能消除多项不构成合并依据。同一材料缺口的未确认后果合并；先查全，合并保留各位置与影响。

例如，同段的无依据保证与后续服务邀请可独立删除，分别计分；操作转述同时造成核心理解障碍，合并一个 Fatal，另一处独立溢出仍另计。

启用格式时按[格式计数协议](#格式计数与定级)及合并的 `format_assessment`，保留原计数与静态／LLM 证据，补充项先交脚本合并。同内容根因只在最终总分去重，不改原扫描。

## 合规与完成状态

全部已启用任务及适用项核验完成且无确认缺陷时，给出本次范围内“合规”。有已确认缺陷则“不合规”，按已确认问题计分。格式未请求时注明“本次审核内容与阅读，格式未请求”。

材料未取得、歧义未核实、模型漏项或工具失败转为补查任务。剩余缺口标明对象、原因及范围，报告“审核未完成”，只给已确认问题的暂计分，完成后再定档次。已确认的原稿缺失核心规则、关键论证或合法输入处理依对应条款定级。

9～10 优秀、6～8 尚可、≤5 不合格。完成本次范围且合规、优秀者可在该范围内推荐。投稿推荐需要核实平台要求覆盖的审核范围。

独立评测隔离历史结论、固定材料与规则。

## 外部评分表

用户评分表另算正式分数，与 CPScore 分开。逐细项按对象、机制和影响映射证据，歧义解释、表外发现单列。作者来源项目仅按直接证据支持的资格／披露事实填写，证据不足记未确定，说明该项与总分的未确定范围。

外部评分表含“滥用代码块”项时，依据逐块裁定单独评分。
