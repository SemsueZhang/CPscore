# 分级与评分

## 内容定级

按全文确认内容错误与必要信息缺失。缺失项须定位受阻的操作、适用条件或推导，并说明影响。

| 等级 | 适用情形 |
| --- | --- |
| **Fatal −10** | 核心算法或关键结论错误，关键正确性或可行性缺乏原文依据。遗漏合法输入、边界或数值处理，如溢出或缩小参数域。读者无法衔接目标、方法与答案，或须自行发现关键定义、状态、不变量或非显然转移。抄袭或侵权复制须有直接证据。 |
| **Major −2** | 按原写法会改变算法判断、推导或结果的局部笔误，且据题面和上下文可确定订正，订正后推导成立。未达 Fatal 的必要依据、引用或辅助说明缺失。文风依下节定级。 |
| **Minor −1** | 局部错字、语言障碍、冗余、说明缺漏或非关键论证／算例错误，核心主线仍清楚，且不触及更高等级。 |
| **不扣分** | 术语、指代、简写和常规推导的含义可由题面、上下文或竞赛惯例确定。完整简洁的解法、允许写法、合理例外、可选建议及个人审美／篇幅偏好。 |

例如，已给区间排序及并集公式，但未说明 Treap 如何合并可能交错的编号，属于局部说明缺漏，计 Minor。

例如，P8496《众数》的 `88tq9fpt` 用链表维护序列顺序、用线段树维护投票摘要。“线段树合并”在此可按竞赛惯例理解为权值线段树合并。`ayq11drk` 写明到叶子再验频，区间计数达到阈值即为继续搜索的条件。两处均不扣分。

例如，P10008 的题解已明确输出恰好用了 $i$ 种颜色，题面给定 $c$ 种可选颜色，最终选色系数写成 $\binom{i}{c}$。由选取对象可确定应为 $\binom{c}{i}$。原式在 $i=1,c=2$ 时给出错误系数，计一处 Major。

仅列公式、数组、循环或算法名，导致读者无法确定所求量或其与答案的关系，按核心缺漏定级。审核者能补出方法、实现可供对照或容易修复，均不足以消除核心缺漏。

有效松上界可用。若声称按几何和 $\sum_{k=0}^{\lfloor\log_2 n\rfloor}2^k$ 实际数出了 $O(n\log n)$ 项，应指出该计数导出的是 $O(n)$，问题在表述与推导脱节。

复杂度简写可以接受：如莫队写 $O(n\sqrt m)$（或 $O(n\sqrt m\log n)$）而未列不可避免的 $O(m)$ 读写项、未声明 $m\le n^2$ 一类适用前提，只要该式在题目实际规模或参数同阶的约定下成立，就不按复杂度问题计；差额会改变算法可行性判断或推导结论时除外。

代码复杂度依[静态对照](content.md#代码静态对照)确认，再按影响定级。

成段题外煽动或表演、低俗配图、明确涉黄／赌／毒内容，以及无关的现实政治宣传、动员、攻击和影射，判 Fatal 并说明不能作为稿件提交。正常背景、历史语境、教育讨论、抽象概率游戏及必要引用按用途核验。简短求赞或求通过通常为 Minor。评价具体内容，避免辱骂或法律认定。

## 阅读与文风计分

启用文风时按[文风](writing.md)定位机制，以实际阅读影响定级。定义、规则、步骤或论证的错漏按内容定级。

| 等级 | 阅读影响 |
| --- | --- |
| **Minor −1** | 局部复述、空泛过渡等增加无效阅读量，或表达不自然造成较小障碍，主线仍清楚。 |
| **Major −2** | 显著冗余、主次失衡、防御性表达等使读者持续经过低信息段落、重复确认结论或回读寻找重点。 |
| **Fatal −10** | 关键方法或规则无法可靠理解，须重新发现重要联系或重组核心内容才能理解。 |

## 格式计数与定级

以合并后的 `format_assessment` 计分，不另设格式满分，类别按脚本 `CATEGORIES`：

| 同篇同类已确认独立位置数 | 定级 |
| --- | --- |
| 0，无未确认范围 | 不扣分 |
| 1～2 | Major −2，一次 |
| 至少 3 | Fatal −10，一次，不叠加 Major |

同一缺失声明只算一处。正文／公式边界缺空格同类，缺与多空格不同类；同一边界多分支命中只算一次，公式两侧各缺则算两处。不同文章、同路径重复传入不累计凑数。

格式扣分取 `format_assessment.groups` 中 `basis=Confirmed` 的类别。未裁定 Warning、`Unverified`、未支持语法和未验证范围留待补查。长代码折叠仅作建议，不进入错误或待核验计数。

## 计分与去重

`评分 = 10 − 10×Fatal数 − 2×Major数 − Minor数`。

同对象同根因的各项后果取最高级一次，独立原因分别计。以针对根因的**最小必要改动**判断是否独立，同一材料缺口的未确认后果合并。先查全，合并后保留位置与影响。

例如，同段的无依据保证与后续服务邀请可独立删除，分别计分；操作转述同时造成核心理解障碍，合并一个 Fatal，另一处独立溢出仍另计。

启用格式时按[格式计数协议](#格式计数与定级)及合并的 `format_assessment`，保留原计数与静态／LLM 证据，补充项先交脚本合并。同内容根因只在最终总分去重，不改原扫描。

## 合规与完成状态

按启用范围核验与评分。查全且无确认缺陷为“合规”，有确认缺陷为“不合规”。材料缺失、关键含义待核实、漏查和工具失败先补查。仍有缺口则报“审核未完成”，列对象、原因、范围与确认问题的暂计分，完成后再定档次。

9～10 优秀、6～8 尚可、≤5 不合格。完成本次范围且合规、优秀者可按 CPScore 推荐。投稿资格按[审核范围](../SKILL.md#审核标准与范围)另行核验。

## 外部评分表

用户评分表另算正式分数，与 CPScore 分开。逐细项按对象、机制和影响映射证据，歧义解释、表外发现单列。作者来源项目仅按直接证据支持的资格／披露事实填写，证据不足记未确定，说明该项与总分的未确定范围。

外部评分表含“滥用代码块”项时，依据逐块裁定单独评分。
