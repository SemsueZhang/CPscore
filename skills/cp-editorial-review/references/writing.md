# 文风与阅读问题

依据原文的信息组织、用途和实际阅读影响确认问题，逐类结合正常对照检查。分类用于定位机制，等级依[评分协议](rubric.md)。首尾、附注、引用、图片文字和代码块均按实际用途纳入阅读范围。

## 审核尺度

题面应明确任务、规则、约束和接受条件。题解应连接目标、关键观察、推导动机、算法与正确性依据。按照相应职责评价信息是否推进、前提是否及时给出、主次是否清楚。

标题、加粗、列表、常用引导句、数学错误、一般错字和 AI 使用披露本身不构成文风缺陷。篇幅、句长、关键词及固定出现次数不作定级阈值。术语、符号或指代有具体含义缺失时，按对应内容缺陷核验。文章来源合规凭直接证据另查。作者身份不根据篇幅、关键词或文风推断。

## 分类与正常对照

| 类别 | 确认机制与定位例子 | 正常对照 |
| --- | --- | --- |
| 助手答复残留／未整理草稿 | 面向提问者的交付、后续服务、未填模板或互相冲突的自纠草稿留在成稿中。例如文末“如果需要，我还可以继续改写”或无关问答，妨碍正式叙述。 | 为研究提示词而引用答复，导航、致谢、辅助使用披露，或有明确错因和收束的失败思路。 |
| 模板化空泛过渡 | 制式导语、价值宣告和总结反复包围具体信息。例如连续“揭示核心—宣告突破—下面展开”，读者读过一段仍未得到关系或条件。 | 一句引导后直接解释具体关系，章节沿实际依赖组织，单次有解释作用的比喻。 |
| 防御性表达 | 保证、假想质疑、自辩和免责占用篇幅，却未补充条件、动机或论据。例如已证明后反复保证“完全没有问题”，推迟后续结论。 | “零权边仍可用 Dijkstra，因为所有边权非负”给出实际适用条件，性能结论有计数或测量依据。 |
| 同义反复 | 相同结论换措辞重复，读者反复确认已知信息。例如“已经最优，换句话说达到了最优，因此就是最优答案”。 | 回顾一句连接下一步，补充新条件、边界、用途或不同角度的必要解释。 |
| 循环说明 | 概念、段落或引用来回转引，仍未提供当前所需说明。例如规则节指向例子，例子回指规则，实际定义散落在另一处。 | 双向导航同时交代所需信息，递归／归纳有明确边界和递进关系。 |
| 信息倒置 | 已按读者掌握某规则来使用它，定义却滞后且缺少可追踪引用。例如演示依赖“前述更新顺序”，顺序实际在后面章节。记录使用点和补充点。 | 先命题后证明、总述后细化、紧邻定义，或明确可追踪的前向引用。 |
| 叙事拖延 | 连续设问、吊胃口和空泛铺垫推迟必要信息。例如“关键是什么？先别急，真正重要的稍后再说”后仍没有观察或前提。 | 失败建模揭示重复计费，直接帮助理解随后为何拆状态。 |
| 模块与列表堆叠 | 并列标题、加粗或列表割裂顺承关系。例如只列“核心模块、增强模块、最终模块”，没有说明各步输入输出如何衔接。 | 合法并列操作、具备实质正文的章节和有明确依赖的步骤列表。 |
| 代码与公式的无意义复述 | 按赋值或公式逐项翻译，缺少对象含义和作用。例如连续“设零、遍历、累加、返回”，增加程序旁白而未帮助理解。 | 完整分析后的实现提示，明确操作、边界、更新顺序或推导联系的伪代码。 |
| 详略不当 | 关键难点、条件或步骤解释不足，次要细节却过度展开。沿当前读者的知识与依赖检查该详不详、该略不略，例如核心转化只留算法名，辅助循环逐行讲解。 | 困难推导充分展开，常规一步推导合理省略，必要边界与例子得到相应篇幅。 |
| 主线不突出／长篇低信息密度 | 简单观察过度展开，次要细节反复解释，核心任务、规则或方法被背景和局部说明淹没，读者须自己重组主次关系。 | 长篇证明各段承担必要引理、条件、推导或理解辅助，且依赖和结论清楚。 |

## 主线与冗余的判断方法

对可疑段落或章节执行以下检查，记录原文位置和比较依据。

1. **主旨提取（Main Point Test）** 用一句话指出该部分解决什么问题、最重要的观察／规则／结论，以及其他内容怎样服务于它。定位读者无法建立这些关系的具体段落。
2. **删除测试（Deletion Test）** 标出可删除或合并的范围，说明删除后保留哪些必要信息、条件、动机和理解帮助。
3. **局部改写比较（Local Rewrite Comparison）** 用原有信息给出紧凑的组织方案或短改写，比较重点和依赖顺序是否更清楚。引入新条件或补出证明的改写，按内容缺失另核。

报告应写出应保留的核心、遮蔽核心的内容及删减、合并、移位或突出关键观察的具体改法。短文同样检查必要信息，长文按有效推进评价。

同义反复、拖延、模块堆叠等已能解释的阅读后果按同根因合并，整体主线问题有独立成因时另列。对已定位且有依据的问题直接依影响定级。

## 题解表达与局部修改

查首尾、标题、附注、图片、代码注释中的题外话、求赞／通过、自我介绍、广告和无关叙事，删除线、折叠和围栏同审。必要引用、贡献披露、动机、边界和背景按用途保留；表达见[教学](content.md#教学与阅读路径)，等级见[评分](rubric.md)。

另查错漏字、语法、搭配、指代和衔接，摘具体病句及缺词／混用／歧义；“讲解不清”不覆盖全部文字问题，与概念缺失同根因合并。

逐类核对上述文风问题的实际影响。循环说明、信息倒置记录读者已知、当前依赖及转引／回读的位置。重点检查关键观察、推导动机、方法和正确性依据的主次关系，对可疑段落执行其中的主旨提取、删除测试和局部改写比较。

按根因给最小的删除、合并、移位或替换方向，保留全部条件；缺定义或关键推理时指出准确缺口，不代写完整解法。

## 表达审核覆盖

阅读覆盖全文各部分及主次关系，按文风分类逐类检查，给主旨、叙述依赖和表达影响的依据。题面与题解采用各自的阅读职责。

为全文各部分及其适用文风类别记录位置、主旨、已有信息、叙述依赖、阅读影响与依据，状态沿用入口的已核验、发现问题、未确定或不适用。循环说明、信息倒置另记转引、使用与补充位置，详略不当指出需要展开的难点及可压缩的次要内容。阅读结果按[入口覆盖检查](../SKILL.md#覆盖检查与补查)定向补查，评分见[量规](rubric.md)。
