# 教学与表达审核

基准读者掌握目标先修知识，但尚不知道本题解法。评价原稿实际增加的理解负担，不规定章节、例子数量或证明篇幅，不把审核者能补出的联系视为原文已有。定级、Fatal 条件和去重仅见[评分协议](scoring.md)。

## 人类思维：每篇必查

沿原文记录读者此时已知什么、下一步依赖什么：定义、状态与指代是否清楚；观察是否有来源；相邻结论靠什么联系；新公式或数据结构为何有用；关键信息是否倒置、散落或被次要内容淹没。定位跳过非平凡联系、循环说明和自辩造成的具体受阻步骤，不能只写“读不懂”。

原稿存在难以理解或无法顺着阅读顺序重建的推导时，直接按评分协议 Fatal。给原句、读者已有信息和缺失联系，区分推导难懂、结论错误及覆盖不全；修法容易或审核者知道正确推理不降级。仅因算法高级、难想到或个人文风不同，不认定难懂；常规推导可省略。没有推导时明确不适用，仍检查叙述，不凭空制造 Fatal。

## 表达缺陷与删除测试

按实际机制逐项指出，不用一个笼统的“AIGC”标签替代问题：

| 缺陷 | 检查对象 |
| --- | --- |
| 防御性表达 | 反复保证、假想质疑、自我辩护与免责声明，没有增加条件、动机或论证。 |
| 车轱辘话 | 同一意思同义反复、来回否定重述，推导没有推进。 |
| 叙事拖延 | 连续设问、吊胃口、空泛铺垫和过渡，延迟给出本应出现的信息；判断效果，不猜作者动机。 |
| 语义失联 | 符号、指代、定义和结论无法对应，换一种说法仍没解释关系。 |
| 题外表演 | 口号、煽动、闲聊或无关故事挤占讲解，和题目模型、发现动机没有联系。 |

对每条实质声明先核对其用途，对可疑段落再作删除／合并测试：删去后是否损失必要数学信息、前提、发现动机或理解帮助？没有损失且增加明显阅读负担，才确认冗余。给出可删范围、应保留的信息及阅读收益；错误声明不能因可删而免责。总结与重复本身不自动违规，必要的回顾可能帮助读者。

有价值的失败路线、边界消歧、严格证明和直觉说明保留；不因否定、谨慎措辞或篇幅长就判防御性。没有问题直接通过，不强求删改。

对确认的局部表达障碍，可比较最小的删除、合并、移位或替换是否更顺畅并保留全部条件。仅改变个人文风不算必改。缺定义或关键推理时指出准确缺口，不借“局部改写”替作者补条件、补核心证明或重写解法。

## AIGC 倾向：说明判断，不重复扣分

多类明显的机械化表达共同出现并贯穿讲解时，在具体缺陷之后明确写：**“本文大概率由 AI 生成。”** 紧接列举支持这一倾向的原文，例如反复自辩、同义重复、无信息的叙事拖延及语义失联，并说明这是基于文本迹象的概率判断，创作来源未核实。不虚构检测器、概率百分比或生成记录。

只有单处错字、一个重复句、普通分节、长文章或高级算法，不足以作此判断；迹象不足时写“未发现足够的 AIGC 迹象”，不能每篇机械贴标签。表达自然、数学完整的文章不因假定来源受罚。

实际扣分依据具体数学、覆盖、表达或内容缺陷，AIGC 倾向本身不另扣一项。同一原文同时表现为车轱辘话、防御性表达及理解障碍时，按同根因最高级别一次处理。已证实的来源资格问题另按[内容核验](verification.md#全文图片与来源)取证，不能将本节的概率判断升级为已证实使用 AI。
