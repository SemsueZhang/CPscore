# 洛谷评分规范

评分规范：`cpscore-difficulty-luogu-v2.0.0`。直接预测洛谷原生 1～8 档。标签名称沿用仓库已核对的 2026 洛谷体系，输出统一使用 ASCII `-`。

| level | label |
| ---: | --- |
| 1 | 入门 |
| 2 | 普及- |
| 3 | 普及 |
| 4 | 普及+/提高- |
| 5 | 提高 |
| 6 | 提高+/省选- |
| 7 | 省选/NOI- |
| 8 | NOI/NOI+/CTS |

这些档位是平台目标，不是等距能力刻度。0/暂无评定表示未知，不是第九档。

以目标选手从题面出发完成整条可靠路线的困难为依据。给出最主要的发现、推导、证明、知识或实现障碍即可，不需要逐项评分。纯思维题可以由一个很难发现的观察主导，复杂结构也可能只是已有模板的直接应用，必须解释具体原因，不能由这些描述预设档位。

比较其他解法时，核对满分复杂度、正确性、实现条件和模板背景。选择整体更容易的完整路线，不跨路线拼接最轻的知识、思维和实现部分。不能因为题解省略了推导就断言观察容易，也不能因文章很长就断言困难。

只使用与当前路线条件相符的已确认专家经验。未经确认的经验、已知题的原生标签和 CF/AT 换算不参与主评分。无法区分相邻档时仍给主档，在理由中说明判断边界和缺口，不编造统计置信度。

机器输出固定为 `id, level, label, reason` 四个字段。`id` 原样绑定输入，`level` 是整数，`label` 必须与数字一致，`reason` 是非空简洁说明，可以包括不确定性。单题允许 `level=0,label=未知`，明确要求全题作答时只接受 1～8，全题覆盖。
