# 选手表现预测

读取题面、约束、子任务、可行解法、选手背景和比赛条件，独立完成预测。缺少条件时写明具体假设，不默认比赛或编造选手水平。此技能的规则可在本文件内完整表达，无需加载其他 Reference 或技能。

## 预测边界

赛前预测不检索或使用目标比赛的实际榜单、通过人数、提交记录、奖牌线和赛后反馈反推结果。混合材料仅取题意与数学解法。已知本场结果须标明暴露，材料回放不能作为独立预测准确率验证。

不进行盲测，不编造通过率、排名百分位、选手反馈或实测记录。读过题解后的路线重建不是首次解题实测，分析区间不是统计置信区间。

## 分析

1. 按用户指定选手或有意义的层次，结合先修知识及题内线索，重建初始尝试、障碍、关键转折、可达部分分与满分路线。以具体路线支撑判断，不用算法标签代替。
2. 估计首次发现和完成时间，计入读题、失败尝试、证明、编码、调试及切题。多题分析各层完成一组题后的剩余时间与下一步，区分共享观察和独立障碍，考虑三人分工与共享电脑。
3. 比较顺利、通常及关键尝试受阻的可达范围，优先补齐可能承担过渡作用的未知解法，不把未知视为不可达。检查排程在总时长内可执行、单题得分不超过满分，不将未必同时可达的上界相加为保证总分。

## 交付

默认在对话输出 Markdown，仅用户要求保存时写报告，不创建中间记录或给出质量评级。

先说明目标选手、赛制、时长和假设，再按层次与题目给出“路线—障碍—时间—得分—依据”，多题补充整体策略及不同情形下的变化。可用表格，推导就地说明。按需用宿主文件与检索工具，不把工具缺失写成题目缺点或引用未读材料。
