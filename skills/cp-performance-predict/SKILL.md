# 选手表现预测

读取题面、约束、子任务、可行解法、选手背景和比赛条件。独立完成预测，不要求其他技能的报告或额外运行时。缺少影响预测的条件时说明具体假设，不能默认某届比赛或编造选手水平。

## 分析

- 按有意义的选手层次或用户指定选手，重建初始尝试、受阻位置、关键转折、可达部分分和满分可能性。考虑题内线索和选手必要知识。
- 区分知道题解后的推导与首次发现难度，不机械套算法标签、代码长度或题目等级。
- 时间包含读题、错误尝试、证明、编码、调试及切题。估计时间和得分给合理区间，并用具体路线、障碍和子任务解释。
- 多题时考虑顺序、放弃、切题与总时长。各题时间下界之和不能超过总时长，各题得分不超过满分。各题上界不一定同时可达，不把其机械相加写成保证总分。
- 不进行盲测，不编造通过率、排名百分位、真实选手反馈或实测记录。分析区间不是统计置信区间。

## 交付

默认直接在对话输出 Markdown，仅用户明确要求保存时写人类可读报告文件。无需中间记录，不产生质量评分或评级。

先说明目标选手、赛制、时长与关键假设，再按选手层次和题目给出“路线—障碍—时间—得分—依据”，最后在多题场景给出整体策略。短报告可以用表格，必要推导就地解释，不重复列出同一依据。

按需使用宿主的文件读取和检索工具理解材料，不把工具不可用写成题目缺点，也不假装查过未读材料。
