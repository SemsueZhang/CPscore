# 选手表现预测

模拟某一水平选手在单题、题组或整场比赛中的解题过程，给出有依据的路线、耗时与得分预测。输出赛前预测，不作题目质量评级。

## 参考资料

- 使用 1～7 档时，读取[水平分档与题型参考](references/levels.md)。
- 选手画像 RAG 预留于当前项目的 `contestant_profiles/`，请你模拟各选手情况进行验题。

## 分析流程

1. 提取题目目标、约束、子任务、可行解法、比赛时长、评分规则和赛制。
2. 对每位选手或水平档位，重建首次读题后的尝试、可能的误区、关键观察、证明与实现路线，分别估计部分分和满分路径。
3. 按读题、探索、证明、编码、调试拆分耗时，给出范围并说明主要不确定因素。
4. 多题预测考虑选题顺序、题间共享观察、总时长和切换成本。团队赛考虑成员专长、分工与共享电脑；分别分析顺利、通常和受阻情形。
5. 检查时间排程和得分汇总，避免把互斥路线或不能同时达到的单题上界相加。

## 预测边界

赛前预测不使用目标比赛的实际成绩、榜单或赛后反馈反推结论。若材料已包含这些结果，标明这是结果暴露后的回放。预测耗时和得分不是实测数据，不编造通过率或排名。

## 交付格式

先列明目标选手或档位、赛制、时长和假设，再按题目给出：

| 项目 | 内容 |
| --- | --- |
| 解题路线 | 初始尝试、关键观察、部分分与满分路径 |
| 障碍 | 可能卡住的知识点、证明或实现环节 |
| 时间 | 总耗时范围及主要阶段 |
| 得分 | 受阻、通常、顺利情形下的得分范围 |
| 依据 | 选手画像、档位参考、题目性质和赛制条件 |

多题或团队赛补充选题顺序、时间安排及情形变化。默认在对话中交付 Markdown；用户要求保存时再写报告。
