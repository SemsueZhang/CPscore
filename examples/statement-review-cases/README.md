# 题面审核方法小案例

维护日期：2026-11-13。这里只记录本轮规则推演与有限核验，不作为审核准确率证据。

case-01～11 为本轮新增的自足合成材料。每份均明确采用自有训练平台，本次不套用洛谷特有的格式要求，以单独检查规格、阅读与修订判断。真实平台规范另按 Skill 核验，不能从这些案例推断格式审核已经通过。

| 材料 | 本轮规则推演裁定 | 证据与修订复核 |
| --- | --- | --- |
| [case-01](case-01.md) | 题面无确认缺陷，10；附加题解冲突 | “从左到右扫描”已明确原地顺序。$n=3$、序列 $1,1,1$ 得到 $1,2,3$，附加题解给出 $1,2,2$。不能因题解而判题面缺规则，应修题解。 |
| [case-02](case-02.md) | 一项 Fatal，0 | “一轮更新”未确定同时或顺次，$n=3$、序列 $1,1,1$ 分别得到 $1,2,2$ 与 $1,2,3$；原样例不能消歧。分别给“右端均使用更新前的值”和“按下标递增原地更新”的条件性句子，两者均保留输入范围及原样例，须作者选择。 |
| [case-03](case-03.md) | 无确认缺陷，10 | $n=6$ 时 $2,4,6$ 均合法，不能因自算输出不同判错；$n=1$ 的无解输出已规定。 |
| [case-04](case-04.md) | 一项 Fatal，0 | 合法输入 $a=1,b=0$ 使除法无定义。若本意排除零，应修改范围并说明输入域变化；若保留零，须作者定义该情形。不能擅自规定答案。 |
| [case-05](case-05.md) | 无确认缺陷，10 | $b=0$ 被明确排除，不能复用上一案例的非法反例；$a=0,b=1$ 答案为 $0$。 |
| [case-06](case-06.md) | 无确认缺陷，10 | 有限实数及绝对误差标准明确，$x=0$ 有定义；合法浮点输出无需唯一。 |
| [case-07](case-07.md) | 无确认缺陷，10 | 初始输入、询问、刷新、回复、次数及终止完整；询问 $1$、必要时询问 $2$ 可识别三个隐藏值。无静态样例及最终回复不构成缺漏。 |
| [case-08](case-08.md) | 无确认缺陷，10 | 后文明确“传给”是复制，顺序与样例一致，不能强行解释成移动或同时赋值。 |
| [case-09](case-09.md) | 无确认缺陷，10；可选移位 | 例外紧邻输出段且有明确指向，未定位显著回读负担。可建议合并到输出段，不能强行扣分。 |
| [case-10](case-10.md) | 一项 Fatal，0 | 正式样例 $1+2+3=6$，输出 $5$ 错误。只将该样例输出改为 $6$ 即消除冲突，不改变输入域或目标。 |

阅读正例见 [case-11](case-11.md)：树上任一边是桥，全局有序点对互达保证推出每条线路双向。它不是已证实的方向歧义，但核心方向字段须经非平凡论证补全，依现有协议属于 Major 的说明负担，8/10。可在方向说明处加“由保证可知，每条线路均双向运行”，不改变合法输入或样例。

本轮由当前宿主智能体逐例推演以上裁定，并用极小计算复核更新顺序、零值、多解、交互可行性和样例算术。没有额外调用独立模型或开展盲评，以上不是审核效果、准确率或跨宿主能力的验证。首次阅读负担、真实歧义解释的合理性、多语言同步修订及复杂样例仍需真实题面和独立审核复测。

评分协议迁移对照：保留 Fatal −10、Major −2、Minor −1、负分、9～10/6～8/≤5 三档、独立根因取最高一次、疑点不扣分，以及未完成时暂定6～10分档次待定、已确认≤5可判不合格。题面与题解现有的明确格式违规下限和平台适用边界也予以保留。单题总评仍取最低档，比赛仍按整体否决与严格大于40%的合格占比判定，新颖度仍为 A/B/C/C+/D/F，表现预测不产生评级。

## 验证范围

本轮本地执行通过 `sh .github/scripts/check-skills.sh`、`python3 .github/scripts/test-retrieval.py` 和现有本地 `sh tests/check.sh`。前者覆盖四宿主模拟复制、独立安装、更新、卸载与入口/Reference 检查；检索辅助脚本的 7 项离线检查通过。逐文核对本仓库 Markdown 本地链接、Reference 可达性及 `git diff --check`。

`skill-creator` 的 `quick_validate.py` 在当前 Python 下因缺少 PyYAML 未运行成功，未安装依赖；Skill 前置字段和名称由仓库自带检查核验。复制模拟不证明真实宿主已加载技能。

独立复测时仅提供某个原始案例和该 Skill 的完整目录，不提供本说明或预期。尤其应另测真实题面的阅读负担、复杂样例、多语言版本与条件性修订，不从本组简单合成案例推断实际准确率。
