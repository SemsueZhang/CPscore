# 题面语义判断

以下材料说明局部语义判断。可调用 `$cp-statement-review` 审核对应文件，但下面的要点不代替完整内容与格式审核，也不提供整篇合并分数。

| 材料 | 判断要点 |
| --- | --- |
| [相邻更新](case-01.md) | 从左到右原地更新已确定使用更新后的前项。附加题解声称先复制原序列，与题面冲突，不能反过来认定明确题面有歧义。 |
| [批次更新](case-02.md) | 未明确使用旧值还是更新后的值。对 `[1,1,1]` 可得 `[1,2,2]` 或 `[1,2,3]`，两项样例不能消歧；接受条件不确定，属于规格 Fatal。 |
| [选择偶数](case-03.md) | 接受区间内任意偶数，样例输出 `4` 合法，不能因自己得到 `2` 而判样例错误。 |

逐例判断任务是否成立，再按现行 Reference 另查表达与格式。不要把语义成立自动写成全篇合规，也不要让附加材料替原题面补规则。
