## 题目摘要

给定严格递增的岛屿坐标 $x_1,\ldots,x_n$，两座岛屿间距离不超过 d 时可以直接飞行，每次飞行计一步。求有且恰有两条最短路径的岛屿对 $(u,v)$ 数量，其中 $u<v$。不可达的岛屿对不计入答案。

输入第一行为 c、t，分别表示测试点编号和数据组数。随后每组输入 n、d 和 n 个递增坐标。每组输出一个答案。

全范围满足 $1\le n\le2\times10^6$、各组 n 的和不超过 $2\times10^6$、$-10^{18}\le x_1<\cdots<x_n\le10^{18}$、$1\le d\le2\times10^{18}$。原比赛时限为 1 秒，内存限制为 1024 MiB。

## 给定题解

### 双指针与最短路分层

令 $r_i$ 为满足 $x_{r_i}-x_i\le d$ 的最大下标。坐标递增使 $r_i$ 单调不减，可以用双指针在 O(n) 时间求出。为统一边界，约定 $r_k=0$，其中 $k\le0$。

从较小下标到较大下标的最短路径必然严格向右。若路径存在方向折返，则出现局部极值，其前后两座岛屿之间的距离不超过 d，可以直接连接并缩短路径。

从某个起点出发按最短距离分层。若当前层最右端为 i，则下一层是 $(i,r_i]$。同一层内，目标下标越大，其上一层前驱集合越小，因此最短路径数单调不增。

下一层的每个顶点都能从当前层最右端到达。如果当前层最右端的路径数已经至少为 3，之后也不会产生路径数恰为 2 的目标。

### 状态定义

`f[i]`、`g[i]`、`h[i]` 都统计当前层右端为 i 时，后续各层中路径数恰为 2 的目标数。三种状态的当前层路径数分布如下。

| 状态 | 当前层末尾的路径数分布 |
| --- | --- |
| `f[i]` | 末尾至少两个顶点的路径数为 1 |
| `g[i]` | 只有最后一个顶点的路径数为 1，其他顶点至少为 2 |
| `h[i]` | 最后一个顶点的路径数为 2，其他顶点至少为 2 |

这里 i 表示层的右端点。状态还依赖上述路径数分布，不能将其直接理解为从岛屿 i 出发的答案。

### 转移与依赖顺序

设 $j=r_i$，并计算

$$
a=r_i-\max(i,r_{i-1}),
$$

$$
b=\max\bigl(0,r_{i-1}-\max(i,r_{i-2})\bigr).
$$

a 表示下一层只有最右一个前驱的顶点数，b 表示恰有最右两个前驱的顶点数。边界中的 i 会排除上一层更早的顶点。

处于 f 状态时，这 a 个顶点的路径数为 1，这 b 个顶点的路径数为 2，其余顶点的路径数至少为 3。因此

$$
f_i=b+
\begin{cases}
f_j,&a\ge2,\\
g_j,&a=1,\\
h_j,&a=0,\ b>0,\\
0,&a=0,\ b=0.
\end{cases}
$$

处于 g 状态时，只有最右一个前驱的顶点路径数为 1，加入其他前驱后至少为 3。本层没有新增的双路径目标，后继满足

$$
g_i=
\begin{cases}
f_j,&a\ge2,\\
g_j,&a=1,\\
0,&a=0.
\end{cases}
$$

处于 h 状态时，只有最右一个前驱的 a 个顶点路径数为 2，其余顶点至少为 4。因此 a>0 时 $h_i=a+h_j$，a=0 时 $h_i=0$。

j=i 时后续不可达，三个状态均为零。其余转移读取 j>i 的状态，所以必须从 n 到 1 倒序计算，使依赖已经求出。

### 答案汇总与复杂度

固定起点 u，第一层为 $(u,r_u]$，其中每个顶点都只有一条最短路径。

- $r_u=u$ 时，贡献为零。
- $r_u=u+1$ 时，第一层只有一个顶点，后续贡献为 $g_{r_u}$。
- $r_u\ge u+2$ 时，第一层至少有两个顶点，后续贡献为 $f_{r_u}$。

第一层自身的路径数均为 1。对所有起点累加上述贡献，每对 $u<v$ 恰好统计一次。

双指针、倒序 DP 和答案汇总各为 O(n)，每个输入文件总时间为 O(N)，其中 N 是各组 n 的和。一个 `int` 数组和四个 `long long` 数组约占 $36(n+1)$ 字节，最大 n 时约为 68.7 MiB。

坐标差不超过 $2\times10^{18}$，答案不超过 $n(n-1)/2=1,999,999,000,000$，均可用 `long long` 存储。

## 受审 std · 单一人工变体

```cpp
#include <iostream>
#include <cstdio>
#include <algorithm>
#include <vector>
using namespace std;
using i64 = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int c, t; // c 表示本次输入的数据组数。
    cin >> c >> t;
    while (t--) {
        int n;
        i64 d;
        cin >> n >> d;
        vector<i64> x(n + 1);
        for (int i = 1; i <= n; i++) {
            cin >> x[i];
        }
        vector<int> r(n + 1);
        for (int i = 1, j = 1; i <= n; i++) {
            j = max(j, i);
            while (j < n && x[j + 1] - x[i] <= d) {
                j++;
            }
            r[i] = j;
        }
        // f[i] 表示以岛屿 i 为起点的双径终点数量。
        vector<i64> f(n + 1), g(n + 1), h(n + 1);
        for (int i = 1; i <= n; i++) {
            int j = r[i];
            if (j == i) continue;
            int a = r[i] - max(i, r[i - 1]);
            int b = max(0, r[i - 1]
                           - max(i, i >= 2 ? r[i - 2] : 0));
            f[i] = b;
            if (a >= 2) {
                f[i] += f[j];
                g[i] = f[j];
            } else if (a == 1) {
                f[i] += g[j];
                g[i] = g[j];
            } else if (b > 0) {
                f[i] += h[j];
            }
            if (a > 0) {
                h[i] = a + h[j];
            }
        }
        i64 ans = 0;
        for (int i = 1; i <= n; i++) {
            if (r[i] == i) continue;
            if (r[i] == i + 1) {
                ans += g[r[i]];
            } else {
                ans += f[r[i]];
            }
        }
        cout << ans << "\n";
    }
    return 0;
}
```

## CPScore · 标程审核

**评分：−3/10 — 不合格，存在重大问题**

三项独立缺陷各扣 Fatal −10、Major −2、Minor −1，$10-10-2-1=-3$。

### [Fatal −10] DP 改为正序，读取了尚未计算的状态

题解要求从 n 到 1 倒序计算，因为 j=rᵢ>i 时，当前转移依赖 `f[j]`、`g[j]` 或 `h[j]`。受审源码第 32 行却使用 `for (int i = 1; i <= n; i++)`。

以下输入满足题目约束，包含两组数据。

```text
0 2
5 3
0 3 4 5 7
1 1
0
```

正确输出为

```text
2
0
```

受审程序实际输出为

```text
1
0
```

第一组的双径岛屿对为 (1,5) 和 (2,5)。从 1 到 5 的两条最短路径是 $1\to2\to3\to5$ 和 $1\to2\to4\to5$，从 2 到 5 的两条是 $2\to3\to5$ 和 $2\to4\to5$。

该输入的 r 数组为 $(2,4,5,5,5)$。计算 i=2 时 a=2，应有 `g[2] = f[4]`。正序循环读取的 `f[4]` 仍为零，之后才被算成 1，漏掉 (1,5)，因此判为 Fatal。恢复从 n 到 1 的 DP 顺序即可修正。

### [Major −2] 核心状态被解释成起点答案，与题解冲突

受审源码第 30 行写道“f[i] 表示以岛屿 i 为起点的双径终点数量”。题解定义的 fᵢ 以当前最短路层的右端 i 为参数，还附带“末尾至少两个顶点的路径数为 1”这一前提。

在上面的第一组数据中，`f[3]` 的值为 1，而从岛屿 3 出发到更大下标岛屿均可一步直达，双径终点数量为零。这直接说明该注释的含义与状态不符。

这条注释误导了对全部 f 转移及答案汇总的理解。读者可能据此把 `f[r[u]]` 当成更换起点后的答案，无法沿题解理解分层状态的复用，因此属于核心说明错误。

修正应说明 f 的层边界含义和路径数分布前提。该注释错误独立于循环方向问题，判为 Major。仅修正循环顺序时，这项误导仍存在。

### [Minor −1] 将测试点编号 c 注释成数据组数

题目输入格式定义 c 为测试点编号，t 为数据组数。源码第 12 行却注释“c 表示本次输入的数据组数”。实际循环仍使用 `while (t--)`。

读者对照输入格式时会遇到局部含义冲突，通过后续循环可以定位错误。修正应把 c 的注释改为测试点编号，数据组数对应 t。它影响局部阅读，判为 Minor。

## 实际核验

本机以 `-std=c++14 -O2 -Wall -Wextra` 编译文中的受审变体，编译成功，无诊断。上述 `1`、`0` 为该变体的实际执行输出。

独立参考程序在无向图上逐起点 BFS 并统计最短路径数，确认正确输出为 `2`、`0`，第一组双径岛屿对为 (1,5)、(2,5)。Fatal 同时有状态依赖分析与实测反例支持。
