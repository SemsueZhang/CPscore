# CPScore · 题解审核

**评分：7/10 — 尚可，值得打磨**

## 扣分项

**1. [Major −3] 缺少最少种数的下界证明**

系统等价只证明方案可行，还没有证明任何等价系统都不能使用更少面额。算法本身正确，缺少的是核心最优性依据。

设扫描时保留面额 $c$。它不能由更小的原面额组成，否则也能由已保留面额组成，与保留条件矛盾。若某等价系统不含 $c$，其对 $c$ 的表示只用小于 $c$ 的正面额。将这些面额展开为原系统的表示，就会用更小的原面额组成 $c$，矛盾。因此每个保留面额都是任何等价系统的必选项，保留种数达到下界。

## 修改建议

将上述必选性证明接在等价性证明之后，再得出种数最少。完全背包的标准更新不必另作长篇展开。
