# 题面审核

提供完整题面、约束、样例和必要附件，注明目标读者与投稿规范。题解审核还需原题面。

```text
$cp-statement-review 审核 statement.md，给出评分、依据和修改建议。
$cp-statement-review 审核 statement.md，并检查格式规范。
```

默认审核正确性与阅读质量。用户明确要求格式审核，或要求依含格式项目的外部评分表评分时，增加格式任务。报告注明实际范围，给合规结论、10 分制评分和档次，按“内容问题”“格式问题”列已确认缺陷，文风归入内容。覆盖记录保留在内部，未完成范围如实说明。

## 执行与覆盖

先按章节、主要段落和重要声明建立带原文位置的对象，再分别完成内容、阅读及已启用的格式任务。内容核验任务规格、约束、输入输出、操作、数学声明与样例。只依原文重建合法输入域与接受关系，逐步手算样例和操作序列，静态核对附件代码。题面以明确规则与接受条件为目标，无解法、发现动机或证明义务。

按[覆盖协议](../skills/cp-statement-review/SKILL.md#审核对象与记录)为各对象的适用检查项保留状态和具体依据。覆盖检查发现缺失任务、文本范围、未填写结果或未核实候选时，定向补查后合并。候选的撤销和改级须有原文证据，已有拒绝理由仍查其余适用项。

```sh
python3 skills/cp-statement-review/scripts/check_coverage.py /tmp/review.json
```

覆盖工具使用 Python 3.8+ 标准库，核对 ID、源文件摘要、原文位置与摘录、任务范围、结果字段和未完成状态。有扫描结果时用 `--format-scan` 加入格式候选检查。无 Python 时按同一字段核对。它能发现记录遗漏，重要对象识别、原文依据和数学／语义正确性由宿主 LLM 核验。任务可按需委派，也可顺序完成，按实际执行记录范围。

## 阅读与评分

按[文风与阅读问题](../skills/cp-statement-review/references/writing.md)检查防御性表达、同义反复、循环说明、信息倒置、叙事拖延、空泛过渡、模块堆叠、无意义转述、助手残留、详略不当及主线不突出。对可疑章节执行主旨提取、删除测试和局部改写比较，指出应保留的核心、遮蔽重点的内容及具体调整方法。篇幅本身不作扣分依据。

局部阅读障碍 Minor −1，显著负担 Major −2，关键规则或方法须重新发现重要联系或重组核心内容才能理解时 Fatal −10。同根因扣一次，级别按[评分协议](../skills/cp-statement-review/references/rubric.md)确认。平台的 AI 辅助创作资格与披露义务仅按适用规定及直接证据核验。

每项缺陷给类别、位置、短摘录、实际影响、级别／扣分和具体改法。正常清楚的文章可无缺陷，剩余未核验范围使审核标为未完成，暂计已确认问题的分数。只审核时保留原稿，重审说明结论变化。

## 按需格式审核

```sh
python3 skills/cp-statement-review/scripts/format_lint.py statement.md
```

启用后逐项裁定候选，按[格式协议](../skills/cp-statement-review/references/format.md)逐类补查全文并记录独立位置。同类已确认 1～2 处 Major，至少 3 处 Fatal。保留静态／LLM 证据，未验证项转为补查，工具或模型执行失败不扣稿件分。源码静态检查与页面实际渲染分别说明。
