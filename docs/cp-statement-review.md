# 题面审核

`cp-statement-review` 检查读者能否只凭题面确定任务，以及规则、样例、语言和排版是否妨碍理解。报告给出问题位置、依据、分级和可直接采用的局部修订。

## 材料与调用

提供完整题面、约束、正式样例与相关附件。涉及多语言一致性时提供各版本，涉及资源裕量时提供参考程序和目标环境。题解或 std 可用于交叉核对，但不代替独立阅读题面。

```text
$cp-statement-review 审核 statement.md，结合附件核对样例，给出评分与局部修改建议。
```

## 如何理解结果

采用[材料评分](README.md#材料评分)。审核先重建任务规格，再核验语义疑点、正式样例和阅读障碍，最后按独立根因汇总。

- **Fatal −10**：影响任务或接受关系的必要规则缺失、矛盾、歧义或正式样例实质错误等，具体范围见评分协议。
- **Major −2**：规则虽可确定，但存在显著理解负担、重要内容或适用规范问题。明确格式违规至少按此级别判断。
- **Minor −1**：已确认的局部文字、符号、指代或阅读问题，且不构成更高等级。

报告区分扣分项、可选建议、未决疑点与未核验范围，并列出真实 token 开销。宿主没有提供用量时注明不可得，不估算。

## 案例与已有评测

[题面方法小案例](../examples/statement-review-cases/README.md)展示更新顺序、零值、多解、交互和阅读负担的判断，是规则推演与有限核验材料。

[真实调用评测](../tests/statement/README.md)保存了新旧 Skill 版本对照及 [CPScore 与直接审题对照](../tests/statement/results/harness-vs-direct/README.md)。后者使用同一 Codex 宿主与请求模型，两组各完成 108 次主审核。部分结果为：

| 指标 | CPScore | 直接审题 |
| --- | ---: | ---: |
| 语义、样例与文字根因检出 | 29/29 | 29/29 |
| 重复审核核心集合众数一致性 | 60/60 | 58/60 |
| 有效修复（固定 20 个目标） | 19/20 | 17/20 |
| 主审核输入 tokens（含缓存） | 9,135,032 | 5,936,099 |

本轮观察到少量稳定性、规范执行与修复保持性收益，非格式根因检出率相同，输入 token 约为直接组的 1.54 倍。检测指标使用共同已裁定的 53/56 个正式题面，未决问题和修复定义见原报告。

这些结果来自合成题面，Gold 与语义裁定未经人类专家确认，生成者与被测模型未建立独立性。被测 CPScore 为冻结提交 `5af3cda`，不代表最新工作区版本或其他技能的效果。
