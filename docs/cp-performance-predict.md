# 选手表现预测

根据选手背景与赛制，预测单题、题组或整场比赛的路线、卡点、耗时和得分。提供题面、约束、子任务、可行解法、时长、计分与选手经验；团队赛补充成员专长和电脑条件。

```text
$cp-performance-predict 按 3 档和 5 档选手分别分析 statement.md，结合 editorial.md，估计三小时内的路线、卡点、耗时与得分。
```

报告说明目标选手与假设，估计读题、探索、证明、编码和调试时间，以及受阻、通常、顺利情形的可达范围。多题考虑切换、共享观察和剩余时间，团队赛核对分工与共享电脑排程，不能把互斥路线的上界相加。

随包[1～7 档水平参考](../skills/cp-performance-predict/references/levels.md)描述选手能力，与洛谷题目难度分别判断。实际画像由用户提供，不作必过保证。

耗时与得分是预测，不是实测或统计置信区间。赛前分析不使用本场实际结果反推结论；结果已暴露时标为回放。本 Skill 不评价题目质量。
