# 选手表现预测

`cp-performance-predict` 根据选手背景、题目与比赛条件，重建可能的尝试、卡点和关键观察，估计完成时间与得分范围。它用于理解选手的可达路线，不给题目质量评级。

## 材料与调用

提供题面、约束、子任务、可行解法、比赛时长和计分规则，以及选手的知识、训练、实现经验或明确水平档位。团队赛还需说明成员专长、分工和电脑条件。

```text
$cp-performance-predict 按 3 档和 5 档选手分别分析 statement.md，结合 editorial.md，估计三小时内的解题路线、卡点、时间与得分。
```

## 如何理解预测

报告先说明目标选手、赛制、时长和假设，再按题给出：

| 项目 | 内容 |
| --- | --- |
| 路线 | 初始尝试、关键观察、部分分与满分路径 |
| 障碍 | 可能卡住的知识、证明或实现环节 |
| 时间 | 读题、探索、证明、编码和调试的耗时范围 |
| 得分 | 受阻、通常、顺利情形下的可达范围 |
| 依据 | 选手背景、水平参考、题目性质和比赛条件 |

多题预测补充选题顺序、题间共享观察、剩余时间和切换成本，不能把互斥路线或无法同时达到的上界相加。团队赛还要核对共享电脑的时间排程。

时间和得分区间是分析结果，不是实测数据或统计置信区间。赛前预测不使用目标比赛的实际成绩和赛后反馈反推结论，已暴露结果时标为回放。

## 水平参考与资料状态

随包提供[1～7 档水平参考](../skills/cp-performance-predict/references/levels.md)，从入门到顶尖，附 CF、AtCoder Algorithm 和常见题型锚点。档位先作为整体参照，再按选手的知识熟练度、建模、证明、编码和调试表现修正，不转换成必过保证。

这些是选手水平档位，与题目难度的 K/T/I、0～7 总档分别判断。项目本地的 `contestant_profiles/` 是选手画像 RAG 的预留位置，当前尚未填充，现有预测仍依据用户提供的背景和随包水平参考。

整套路线与团队排程的分析形式可参见[西安区域赛案例](../examples/contest-review-xian-2026.md)，该例已暴露赛后结果，不作为本技能独立预测准确率的验证。
