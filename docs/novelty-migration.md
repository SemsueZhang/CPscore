# 新颖度技能迁移记录

日期：2026-11-09。按用户要求，从Auto-Insight的“判题”中提取新颖度判断，加入CPscore为第四个技能`cp-novelty-review`。本次范围为技能、检索证据工具及项目安装集成，没有新增网页应用、模型服务或公开题库，也没有发布到远端。

## 职责与接口

新技能保留A–E标准、原场题的来源与评审时点、CPRet／arXiv／普通网页覆盖、完整60条与组内成员、原文方法对应、关键缺口和按需停止。E仍需有简短的正面质量依据。常规只读SKILL.md，参数和排错手册按需读取。

报告独立保存为`novelty.md`及证据附件，由用户最终裁决。采用、赛制、难度和做题预测留在原有完整审题流程；新颖度不作为正确性10分制的scope、扣分或总分字段。原三个正确性技能和评分代码未改。

`search.py`迁为`cpscore/novelty_search.py`，内容保持一致。证据工具迁为`cpscore/novelty_evidence.py`，改为包内导入并拆出CLI参数注册，检索、候选、缓存、正文及usage核心逻辑保持原实现。所有工具通过`python3 -m cpscore novelty ...`或已安装技能的共享薄入口调用，无原工作区路径依赖。

三个宿主目标均部署四个技能，共享运行时和`.cpscore/novelty.md`各一份。新安装manifest为格式2；仍接受格式1的旧三技能安装用于检查、卸载和升级。重装前仍核对原文件所有权和哈希，用户改动不被覆盖。`check`列出实际安装的技能，文件安装与真实模型调用保持分开。

## 本地验证

执行`python3 -B -m unittest discover -s tests -v`，共**89项：84项通过，5项明确跳过**。跳过项是未启用的真实容器集成用例，不记为通过。

新增19项覆盖：

- 第25名及组内候选、必要URL参数和完整证据恢复，摘要按需展开，未知ID拒绝。
- 相同查询缓存、参数区分、过期与刷新、partial和来源失败重试。
- 数学内容、长文本分页、关键词续读，缺失和中断usage保持未知。
- 源码及安装入口的索引、展开、读取与用量汇总，搜索CLI在缺省60条深度复用成功缓存。
- 三宿主获得四技能、共享工具仅一份，目标项目整体移动后通过`python -I`运行，无源码或pip路径依赖。
- 格式1的检查、升级、卸载和用户改动保护，格式2不能遗漏新颖度共享资产。
- 原正确性报告仍只有statement、solution、editorial三个对象。

新技能通过skill-creator的frontmatter与命名检查。此前70项回归也包含在总数中，原有评分、版本证据、路径与安装保护保持通过；检查源码见[证据工具回归](../tests/test_novelty_evidence.py)和[入口与升级回归](../tests/test_novelty_integration.py)。

本次测试使用本地构造的检索记录、缓存与模拟响应，未向CPRet或arXiv新增联网检索，也未调用任何模型。没有迁入用户PDF、未公开题目、个人绝对路径、原始聊天或模型登录材料。原先Auto-Insight的模型试跑不是本技能在CPscore中的真实Harness验证，不把它们计作当前准确率或费用证据。

尚未进行新技能的真实模型加载、评级准确率、费用收益或Linux／Windows实机验证。宿主中的普通网页工具仍由用户环境提供；无法覆盖时必须按技能规则保留缺口或待定。现有适配器的路径和格式支持不替代这些实际调用结果。
