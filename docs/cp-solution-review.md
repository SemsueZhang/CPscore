# 标程审核

对照题面与给定题解，检查 std 的实现正确性、资源开销和表达质量。提供约定版本的题解、完整源码、编译器与语言标准、时空限制和读写协议。

```text
$cp-solution-review 对照 statement.md 和 editorial.md，审核 std.cpp 的正确性、复杂度与实现表达。
```

报告给出 10 分制评分与档次，每项说明级别、题解概念与代码位置、失败条件或理解障碍、依据及修正建议。正确性、核心状态与依赖说明、局部阅读问题按实际影响区分，具体见[评分协议](../skills/cp-solution-review/references/scoring.md)。

缺题解或版本不明时可继续程序核验，但不作题解对应性判断。具体疑点可作必要受限检验，实测注明环境、源码和覆盖；有限检查不等于全范围正确。只要求审核时不修改源码。
