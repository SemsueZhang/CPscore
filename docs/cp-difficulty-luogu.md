# 洛谷难度预测

根据同一道题的题面、约束和完整正确解法，预测洛谷原生 1～8 档难度。必要时提供实现、语言、模板和目标选手背景。

```text
$cp-difficulty-luogu 根据 statement.md、editorial.md 和 std.cpp 预测洛谷难度，简述独立完成的主要障碍。
```

核对材料一致性，理解完整可通过路线及实质更容易的替代路线，判断独立发现、证明与实现的主要障碍，再直接给出数字、档名和简洁依据。K/T/I 仅作内部分析视角，不要求三个数值或综合公式。

默认对象是未见本题及直接先例、允许常用模板的个人选手。看懂题解不等于独立发现；算法名称、代码长度和新颖性不能直接定档。材料不足时给 0（未知）及缺口，0 不作为有效难度标签。机器输出见[评分规范](../skills/cp-difficulty-luogu/references/rubric.md)。

只应用条件和局限明确、经过人工确认的专家经验，不能把题目标签当通用规则。当前未附加蒸馏经验库。评分时不查询目标题的真实标签；已知题目记忆可能影响判断，不能把公开旧题结果当作未见题泛化证明。

直接由宿主 LLM 调用，无需 Python。预测准确性需要独立评测验证。
