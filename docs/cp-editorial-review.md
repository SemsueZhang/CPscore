# 题解审核

提供原题面、完整题解、约束、样例和必要附件，可注明目标读者。CPScore 只按[本技能的审核标准](../skills/cp-editorial-review/SKILL.md#审核标准与范围)给出结论和评分。

```text
$cp-editorial-review 审核 editorial.md，给出评分、依据和修改建议。
$cp-editorial-review 审核 editorial.md，并检查格式规范。
```

默认只审核内容，跳过代码。审核前会询问尚未明确的文风和格式选项，分别按答复启用。可直接指定所需项目，也可明确要求静态核验代码。报告注明实际范围，给合规结论、10 分制评分和档次，按“内容问题”“格式问题”列已确认缺陷，文风归入内容。覆盖记录保留在内部，未完成范围如实说明。

## 执行与覆盖

先为章节、主要段落和重要声明建立带原文位置的对象，再分别完成已启用的任务。内容核验声明、推导、输入覆盖、复杂度、数值与样例。部分分按声明范围判断，超时、卡常和附录方案仍检查数学与成本。逐步手算正文举例，正向从条件推到结论，逆向从结论反查前提。启用代码审核时再静态对照实现。

按[覆盖协议](../skills/cp-editorial-review/SKILL.md#审核对象与记录)为各对象的适用检查项保留状态和具体依据。覆盖检查发现缺失任务、文本范围、未填写结果或未核实候选时，定向补查后合并。候选的撤销和改级须有原文证据，已有拒绝理由仍查其余适用项。

```sh
python3 skills/cp-editorial-review/scripts/check_coverage.py /tmp/review.json
```

覆盖工具使用 Python 3.8+ 标准库，核对 ID、源文件摘要、原文位置与摘录、任务范围、结果字段和未完成状态。有扫描结果时用 `--format-scan` 加入格式候选检查。无 Python 时按同一字段核对。它能发现记录遗漏，重要对象识别、原文依据和数学／语义正确性由宿主 LLM 核验。任务可按需委派，也可顺序完成，按实际执行记录范围。

## 按需文风审核与评分

启用文风审核时，按[文风与阅读问题](../skills/cp-editorial-review/references/writing.md)检查防御性表达、同义反复、循环说明、信息倒置、叙事拖延、空泛过渡、模块堆叠、无意义转述、助手残留、详略不当及主线不突出。先逐节或按主要段落提取核心与新增信息，对可删并、重组的部分执行删除测试和局部改写比较，指出应保留的核心、遮蔽重点的内容及具体调整方法。篇幅本身不作扣分依据。

局部阅读障碍 Minor −1，显著负担 Major −2，关键规则或方法须重新发现重要联系或重组核心内容才能理解时 Fatal −10。同根因扣一次，级别按[评分协议](../skills/cp-editorial-review/references/rubric.md)确认。

每项缺陷给类别、位置、短摘录、实际影响、级别／扣分和具体改法。正常清楚的文章可无缺陷，剩余未核验范围使审核标为未完成，暂计已确认问题的分数。只审核时保留原稿，重审说明结论变化。

## 按需格式审核

```sh
python3 skills/cp-editorial-review/scripts/format_lint.py editorial.md
```

启用后逐项裁定候选，按[格式协议](../skills/cp-editorial-review/references/format.md)逐类补查全文并记录独立位置。同类已确认 1～2 处 Major，至少 3 处 Fatal。保留静态／LLM 证据，未验证项转为补查，工具或模型执行失败不扣稿件分。源码静态检查与页面实际渲染分别说明。
