# 比赛总评

`cp-contest-review` 分析一套题放在同一场比赛后，能否形成合理区分度、可持续的做题机会和良好体验。默认依据赛前材料，结合逐题档次和整套影响给出推荐、合格或不合格。

## 材料与调用

提供完整题面、参考解法、已有评审，以及目标选手、比赛时长、团队人数、共享电脑和计分规则。缺少现场成绩是赛前评价的正常条件。

```text
$cp-contest-review 按五小时、三人一机的 ICPC 赛制，审核 contest/ 中的整套题，分析目标选手的路线、梯度与做题体验。
```

## 如何形成结论

逐题根据实际考点、可发现性、证明与实现负担、解题反馈和题位作用分为推荐、合格、不合格。材料分数和题目质量等级是分析证据，仍需结合本场使用场景判档。

质量等级 A+、A、B+ 面向正式比赛，B、C 面向训练，D、F 不推荐作为原创赛题，S 单列为研究问题。训练赛可评估复用题的训练价值。旧版新颖度报告保留原协议含义，不能按字母直接转换。

整套判断同时检查各层选手可能完成的题组、后续路线、剩余时间和瓶颈。团队赛考虑分工、共享电脑和切题，未知解法不能直接当作不可达。

设共 N 题，推荐 R 题、仅合格 Q 题、不合格 U 题，R+Q+U=N。整套按以下顺序判断：

1. 存在不合格题，或有具体依据预测整体区分度不佳、做题体验极差，判不合格。
2. 没有否决情形，但仅合格题占比 Q/N 严格大于 40%，判合格。
3. 没有否决情形且 Q/N 不超过 40%，同时区分度好、做题体验优秀才判推荐，否则合格。

Q 不含推荐题，占比不按题目分值加权。正好 40% 按第三步处理。结论仍需说明具体的路线、负担和组合影响，不能只凭占比或局部缺点判断整套。

## 赛前分析与复盘

只有明确要求复盘时，才使用本场实际成绩、榜单和赛后反馈。已接触这些结果的材料回放注明暴露情况，不能作为独立赛前预测准确率证据。
