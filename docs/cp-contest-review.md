# 比赛总评

赛前分析整套题的区分度、持续做题机会与组合质量。提供完整题面、参考解法、已有评审、目标选手、时长、计分和团队电脑条件。

```text
$cp-contest-review 按五小时、三人一机的 ICPC 赛制，审核整套题，分析目标选手的路线、梯度与做题体验。
```

报告给出推荐、合格或不合格的总评，以逐题档次、分层可行题组、剩余时间、瓶颈和不同情形的排程为依据。材料分或质量等级只是证据，仍需结合本场题位与目标选手判断。

先检查整套否决条件，再结合仅合格题占比和整体体验判定，阈值与证据要求见[整套判定](../skills/cp-contest-review/references/assessment.md)。未知解法不能直接当作不可达，也不能为凑齐占比强行定档。

默认不用本场实际成绩、榜单或赛后反馈。只有明确要求复盘时使用；已暴露结果的分析标为回放。没有现场成绩是赛前评价的正常条件。
