# 题目质量评分

以人类题解为起点，检查替代解法并检索先例，评价考点原创性与算法设计质量。提供完整题面、约束、人类题解及已知相关来源；没有足以支持评价的完整路线时暂不定级。

```text
$cp-quality-review 依据 statement.md 和人类题解 editorial.md，检索先例并评价考点原创性与算法设计质量。
```

输出 A+、A、B+、B、C、D、F 或 S，附用途、核心考点、先例对应和决定性设计理由。A+、A、B+ 面向正式比赛，B、C 面向训练，D、F 不推荐作为原创赛题；S 是严重不适合竞赛的研究问题。边界见[评级协议](../skills/cp-quality-review/references/rubric.md)，不按观察数量或分项平均定级。

以给定解法为起点，主动检查可能改变评级的朴素方法、步骤简化及其他路线，不要求从零求解或穷举。候选须核实完整算法、正确性、全范围复杂度和实现条件，才能纳入评价；据此重新判断核心考点是否可被绕过，多解本身不加减分。

另解影响等级或决定性设计理由时，在报告开头、质量等级之前说明路线、核实依据及影响。具体候选尚待核实但可能改变结论时，前置说明待核实状态与条件性结论，不按猜测升降级。

检索覆盖 CPRet、arXiv 和普通网页，阅读接近来源核对条件；论文重合须同时满足重要性和赛时难以独立推导的门槛，不按命中数量降级。无网络或来源不可访问时说明实际范围，不宣称完成查重。

可选[检索脚本](../skills/cp-quality-review/scripts/retrieve.py)负责候选索引、原文缓存和分段读取，不负责评级。[检索说明](../skills/cp-quality-review/references/retrieval.md)提供调用与回退方式；没有 Python 时直接使用宿主工具。
