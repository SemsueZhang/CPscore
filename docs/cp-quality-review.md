# 题目质量评分

`cp-quality-review` 以人类题解为依据，通过先例检索评价算法竞赛题目的考点原创性与算法设计质量。智能体理解题解中的算法和观察，进行必要核对，不独立解题或探索额外算法。

## 材料与调用

输入完整题面、约束、人类题解和已知相关来源。题解须足以理解主要算法、关键观察、数学转化及复杂度；缺少核心信息时，报告具体缺口，暂不确定评级。多种给定解法可分别理解和比较。

```text
$cp-quality-review 依据 statement.md 和人类题解 editorial.md，检索先例，评价考点原创性与算法设计质量。
```

## 如何理解等级

| 等级 | 含义 | 用途 |
| --- | --- | --- |
| A+ | 大部分重要核心观察具有独立创新性，设计优秀。 | 正式比赛，优先推荐 |
| A | 大部分重要核心观察具有独立创新性，设计合理。 | 正式比赛 |
| B+ | 多数观察已有先例，仍有实质独立亮点，设计优秀。 | 正式比赛 |
| B | 大部分观察已有类似做法，保留少量有价值的独立亮点。 | 训练题 |
| C | 核心观察基本已有先例，价值主要在组合与应用。 | 训练题 |
| D | 已有方法经常规调整即可直接套用。 | 不推荐作为原创赛题 |
| F | 与已有题目实质相同，主要是背景、名称或普通参数变化。 | 不推荐作为原创赛题 |
| S | 高度原创且有独立研究价值，但严重不适合算法竞赛。 | 研究问题 |

S 是独立分类，不是更高的 A+。A+ 与 B+ 共用优秀设计标准：考点清晰、发现路径自然、推导循序渐进、技术依赖合理、思考收益与负担协调；区别在原创性程度。A、B 不要求达到加号标准。

评价按关键观察的重要性判断，不数新旧观察的数量，也不按五项平均打分。人类题解的表达文风与算法设计分别处理；高级技术、长证明、高难度和多解本身不判差。具体边界见[评级协议](../skills/cp-quality-review/references/rating.md)。

## 检索辅助与案例

每题检索 CPRet、arXiv 和普通网页，阅读相关题面、题解或论文，核对条件与方法的对应。检索用于确认人类给定解法的先例关系，不扩展为独立解题；未发现先例仅表示本轮未核实到实质先例。

保留随包的 Python 3.8+ 标准库辅助脚本，用于候选索引、原文缓存和分段读取；不可用时回退到宿主工具。详见[检索说明](../skills/cp-quality-review/references/retrieval.md)。

[CSP-S 2026 全卷评审](../examples/novelty-review-csps2026.md)是旧版 `cp-novelty-review` 的历史报告，保留原评级，未按本次八档协议复评。本地离线检查覆盖技能封装、复制安装和检索脚本行为，尚无新版质量评级的准确率评测。
