# 轻量化重构与验收

## 修改前的产品审查

2026-11-11，源码工作区干净，共识别八个 Skill。以下是维护者依据实际文件和使用路径作出的产品审查，不是第三方用户反馈。

| 视角 | 现有偏差 | 最简处理 |
| --- | --- | --- |
| 首次使用者 | 看懂用途后还要安装运行时、创建记录、运行校验和报告命令 | 复制所需 Skill，直接在宿主对话中调用 |
| 独立安装者 | 七个技能直接或间接依赖共享协议或运行时，单独复制规则不完整 | 每个 `SKILL.md` 自带任务、判据、评分和交付说明 |
| 出题人 | 正确性审查的分析有价值，但报告暴露覆盖字段、流水号和多份中间产物 | 保留数学分析和证据要求，默认给人类可读意见 |
| 出题人 | 算法错误、证明漏洞、普通省略需要明确区分 | 保留已有分级，明确公认结论、文风和未证实疑点不扣分 |
| 维护者 | 同一规则分散在协议、技能、代码、Schema、测试预期中 | 必要规则直接维护在各技能中，允许少量重复 |
| 维护者 | 为固定扣分和排版维护了完整软件包、迁移、安装清单和容器执行平台 | 删除框架，使用宿主原有文件、搜索、执行或正式评测工具 |

## 模块取舍

| 原模块 | 真实用途 | 处理及影响 |
| --- | --- | --- |
| `skills/` | 评审方法和决策标准 | 保留全部八个技能，改为独立使用 |
| 评分器、CLI、报告生成器 | 校验记录、计算和排版 | 删除，模型按明确规则计算并直接回复，取消机器强制校验 |
| Schema、迁移和安装器 | 管理内部格式及运行时分发 | 删除，技能按宿主标准目录复制，无历史格式兼容负担 |
| 搜索、来源读取、用量脚本 | 获取先例和整理工具记录 | 删除专用实现，保留检索和正文核对方法，使用宿主工具 |
| 容器运行器、数据套件执行器 | 执行候选和记录实测 | 删除平台实现，保留原集实测、反例核实和正式计分要求 |
| Python 测试、打包及原 CI | 验证被删除的框架 | 删除，保留少量材料和无需额外依赖的安装验收 |
| 人工构造的评审材料 | 校准错因、等级和合理省略 | 转成人可读验收案例，预期与盲测输入分离 |
| 已有真实评审证据 | 记录旧流程的实际输出 | 保留原始字节，归档且不作为新工作流依赖 |

没有增加替代语言运行框架。各技能默认回复 Markdown，仅用户明确要求时保存报告。必要代码执行可以使用临时文件，但不自动创建内部审核记录。

## 实际验收

2026-11-11，使用本机 `codex-cli 0.167.0-alpha.3.2` 和已有配置中的 `gpt-6.1-sol` 运行首轮24项盲测，其中两项复用相同原稿，共22份独立材料。根据发现的问题进行12项定向复测，再单独验证第19项的未完成措辞，共37次验收调用。每次使用新的临时工作目录，只提供该技能与原始材料。预期保留在调用端，模型请求包含技能名、材料位置和任务，没有预期评分或此前结论。

37次调用均正常结束，模型直接回复Markdown。工作目录的前后文件清单一致，用户材料经核对保持原样。需要执行的案例使用宿主现有工具完成验证。调用端显式保存请求、当时的技能和材料、原始输出及执行轨迹，存放在本地 `reports/refactor-20261111/`。

### 发现及修正

- 题面案例13首轮得到10分。模型证明方向唯一后，遗漏了读者必须结合多个全局保证才能补全关键规则的说明负担。技能现分别判断语义唯一性和理解成本，复测得到Major、7分。普通符号和清楚完整的题面仍得10分。
- 程序案例05、07、08首轮在完整证明之外追加了1023或4095个输入集合的穷举。技能现以数学分析和代码核对为主，执行用于裁定具体疑点。复测保留正确性论证与应有评分，以静态核验结束这些案例。
- 未完成案例19在一次复测中使用了“优秀分档”。四个评分技能现明确将暂定高分的档次写为待定。最终复测首行是“暂定评分10/10，审核未完成，档次待定”，没有确认扣分，也没有给推荐结论。
- 地铁材料原先的“往返步行时间”存在额外解释负担，已明确为两个方向的单程费用。一般网络案例03还给出了同一输入答案为4或6的三站环反例，证明旧Minor预期错误，应为Fatal。修订依据是可独立手算的反例，具体推导见验收材料。
- 数据案例20发现文档把第二个实际输入 `n=2，5 4` 描述为 `n=4，5 4 3 2`。已同步描述，原输入和答案保持原样。复测确认候选在原集获得2/2分、在独立合法反例失败，合并为一个Fatal。
- 材料标题及代码注释中的变异提示已去除，使当前输入只呈现待审核内容。首轮和复测原件均保留，能核对每次实际使用的版本。

## 安装与运行检查

- 读取Agent Skills规范及Codex、Claude Code、OpenCode、DeepSeek官方文档。安装采用目录复制，路径、调用及系统差异见[安装说明](install.md)。
- `sh tests/check.sh` 在macOS通过。动态扫描八个当前技能，在三个宿主的临时全局及项目级目录验证单个、全部、更新和卸载，并用第九个临时技能检查未来新增技能的发现。带空格路径也通过。验收中修正了BSD `cp` 对源目录末尾斜线的处理差异。
- 仅向PATH提供所需系统文件工具，再运行同一检查，六个目标全部通过。技能运行入口为Markdown指令，没有需要安装的语言软件包。
- 七个技能实际通过项目级调用，表现预测技能实际通过Codex全局调用。Codex原生技能列表在测试期间返回对应的 `repo` 和 `user` 作用域，且均已启用。临时全局技能完成后已移除，重新加载的列表确认其消失。
- 本机C++17执行验证了数据候选在两点原集的输出和独立反例，模型调用也复现了实际漏网。数据候选及参考程序保存在 `tests/data/`。
- 八个技能的前置信息、独立复制、相对链接与已删除依赖已检查。新颖度的“等级判定”“错误定位与解法核验”“C+与F的合适度、质量核验”三段与重构前逐字一致。
- 重构前记录的328份既有历史文件摘要核对无变化。两份从 `tests/history/` 移至 `archive/previous-reviews/`，本地已有报告和材料沿用原有忽略规则保存。

本地 `reports/refactor-20261111/batch-1/` 保存首轮24项，`regression/` 保存12项复测，`pending-check/` 保存最终未完成案例。每项包含实际使用的材料、技能、请求、原始回答和执行轨迹。Codex发现列表另保存在同级目录。所有验收材料均由本次任务显式保存。
