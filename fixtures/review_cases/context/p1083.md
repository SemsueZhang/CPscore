# 借教室受限摘编

来源模型：[洛谷 P1083 / NOIP 2012 借教室](https://www.luogu.com.cn/problem/P1083)。本文件是人工编写的自足受限版本，不是官方题面全文。

接下来 n 天的可用教室数为 r[1..n]。m 个订单按输入顺序处理。订单 (d,s,t) 占用闭区间 [s,t] 内每天 d 间教室。如果该区间任一天剩余教室不足 d，立即停止，返回这份订单的编号（从 1 开始）。所有订单都成功则返回 0。每天可以使用不同的教室。

输入第一行 n,m，第二行 n 个 r 值，随后 m 行 d,s,t。满足 1<=n,m<=20，1<=r_i,d_j<=100，1<=s_j<=t_j<=n。若全部成功输出一行 0，否则输出两行，第一行 -1，第二行首次失败订单编号。

样例输入：
```text
1 1
1
2 1 1
```
样例输出：
```text
-1
1
```
样例中唯一一天只有一间教室，首份订单需要两间，因此首份订单失败。
