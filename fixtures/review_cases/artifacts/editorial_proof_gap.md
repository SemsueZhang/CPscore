# 货币系统题解

审查上下文为 ../context/p5020.md。设 M=max(a)。从小到大扫描所有面额，维护保留面额能表示的所有 0..M 金额。初始只有0可表示。如果当前面额可表示则跳过，否则保留它。保留面额 c 时按金额递增顺序更新 reachable[s] |= reachable[s-c]，这是标准完全背包。

每个删去的面额都能由保留面额组成，因此任何原系统金额都可用保留面额组成。反过来，保留面额来自原系统，因此两个系统等价。

还需说明种数最少。任意等价系统能表示相同金额，所以其最大公约数相同。因此任意等价系统的面额种数也相同，我们给出的系统就是最少的。此处算法仍使用前述排序完全背包，并非只保留 gcd。

排序 O(n log n)，背包 O(nM)，数组空间 O(M)。逐组重新初始化背包。
